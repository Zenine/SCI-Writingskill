## 核心主张(3–7 条,自己的话)

1. **草稿语言按英语水平二选一,但逻辑先于语言。** 英语好:中文思考→英文写→先改逻辑再改语言;英语不自信:中文思考→按本书结构原则写中文→机器翻译→重点清理术语误译、非学术词、动词、副词位置。两条路都要求"逻辑满意后才碰语言",且最后要全体合著者(最好同处一室)一起通读。
2. **投稿前检查分三层:学术风格、结构、其他。** 风格 18 条是逐句可搜索的操作(删缩写、删 can/could、换懒动词、拆 which、删 there is、时态规则等);结构 4 条对应摘要、结果段、方法、讨论结尾;其他 3 条是致谢完整、题目众筹、cover letter 不复制摘要。
3. **每个部分都有固定"结构元素 + 动词 + 时态"三件套。** 摘要五元素、引言三元素、方法两类(实验步骤 vs 系统描述)、结果三元素、讨论四元素(含结论回答五问和可选模型);时态原则统一为:现在时=事实与图表,过去时=自己做过的事和自己的结果,现在完成时=领域积累。
4. **摘要是一条主线,不是结果罗列。** 六块:面向普通读者的引入→面向专家的细节背景→缺口/问题→方法→结果→结论与更广意义;结论要把背景"放大"回去。
5. **弱化词要"够用即止"。** 引导动词、情态动词、概率形容词/副词、频率副词、数量形容词共七类;证据充分时删,一句里不叠两层弱化(如 suggests…may、indicate…most likely)。
6. **非正式表达有系统替换表。** 连接词(so/besides/meanwhile/in a word…)、短语动词与懒动词(get/make/do/have/look at/find out…)、口语程度词(huge/a lot of/a little bit/some…)、人称(you/I/they/泛指 we)、直接疑问句,各有一到几个学术替代。
7. **短语库要自己建。** 附录四推荐 Manchester Academic Phrasebank 按论文部分和功能分类查短语,但强调应从本领域文献里积累自己的短语库,而不是直接套用通用库。

## 结构模型 / 模板(用自己的话描述流程、步骤、判断标准)

### A. 草稿语言决策(附录一)

- 判断点:能否用英文直接组织逻辑?能→策略一;不能→策略二。
- 策略一流程:中文构思→英文写作(先结构后句子)→通读改逻辑→按本书常见错误清单改语言→对风格/逻辑/语法/中式英语各做一轮重写→合著者满意→投稿。
- 策略二流程:中文构思→按本书组织原则写中文→通读改逻辑→高质量翻译工具→清理中式英语→专项检查:术语是否被误译(翻译工具不是为学术训练的)、非学术词、动词、副词位置→全体合著者同读→重复→投稿。

### B. 投稿前快速检查表(附录二,共 25 条,我按可执行动作重述)

**学术风格(18 条)**
1. 删所有缩写形式(don't→do not 等)。
2. 删 can/could(改为陈述或换更精确动词)。
3. 非正式/懒动词(get、let、make、do、have、be)换学术动词。
4. 非正式连接词(so、besides、meanwhile、in a word、in a nutshell、all in all)换正式连接。
5. 含 which 的长句拆成两句,第二句以 This/The + 名词开头。
6. 删句首悬挂式修饰语(As for X / With X / For X…)。
7. 复合名词平均 2 个名词,不要 5–8 个名词堆叠。
8. 非必要不把动词名词化。
9. 总结与结论处动词后接 that(findings suggest/indicate/demonstrate/show that…)。
10. 除方法节外用主动语态。
11. 用逻辑连接手段(-ing 分词表因果、This + 名词、As a result)。
12. 超过 4 行的句子拆开。
13. 句首 And/But/Or 换 In addition/Furthermore/However/In contrast/Alternatively。
14. 歧义的 with/for/of 换动词短语(如 protein with enzyme activity → protein exhibiting enzyme activity)。
15. 少用 it/them,换实际名词。
16. 查主谓数一致。
17. 删 there is/are 并重组句子。
18. 时态:现在时=事实与图表,过去时=过去行为与自己结果。

**结构(4 条)**
- 摘要含背景、科学问题、结果、结论。
- 每个结果段含目标句(为什么做)、结果句(图表显示什么)、总结句(合起来说明什么)。
- 方法用过去时或被动。
- 讨论结尾含结论:推进了什么理解、读者为何关心、局限或下一步。

**其他(3 条)**
- 致谢感谢所有人,不只资助方。
- 题目与合著者讨论,每人给 5 个候选。
- Cover letter 传递兴奋点,不复制摘要。

### C. 各部分结构元素与时态(附录三)

| 部分 | 元素(顺序) | 时态与语态 |
|---|---|---|
| 摘要 | 背景(由一般到具体)→科学问题(However…)→方法→结果(Here we show that…)→结论 | 过去时=我们做了什么;现在时=事实与我们的主张 |
| 引言 | 背景主题 1–3(由一般到具体,直到"未知")→目标(Here we set out to…)→一句总结 | 过去时=某项以往研究;现在完成时=领域积累;现在时=仍不清楚/已确立的事实;主动优先 |
| 方法 | 目标(为了研究 X 我们做了 Y)→ 2a 实验步骤(First/Second/Next/Lastly,被动)或 2b 系统描述(Part 1 does…,现在时主动) | 过去时被动=实验;现在时=机制、公式、系统 |
| 结果 | 目标→结果摘要(As shown in Fig.;In addition;Furthermore)→总结(Together these results suggest/indicate/demonstrate…) | 过去时主动优先;现在时=事实;被动仅在需要突出两名词关系时 |
| 讨论 | 一句总结→逐条讨论(我们的结果 1 与以往报道比较;结果 2 与…一致)→局限(While our study established…, limitations remain. First/Second/Third)→ 4a 结论回答五问(读者为何读、推进了领域什么、加深了什么理解、潜在应用、谁受益)→ 4b 可选模型(基于发现我们提出…) | 现在时=主张;过去时=引用具体研究 |

### D. 摘要六块清单(附录五)

1. 面向普通读者的一般引入 1–2 句。
2. 面向专家的细节背景 1–2 句(More specifically / In particular)。
3. 目的/问题/缺口 1 句(While X is well documented, it remains unclear whether…)。
4. 方法 1–2 句(To…, we performed…)。
5. 结果 1–2 句(Here we show that… / We found that…)。
6. 结论与更广视角 1–2 句 + 1–2 句(In summary… provides new insights into…)。
判断标准:六块连成一条主线,而非结果堆砌。

### E. Cover letter 模板结构(附录六)

日期 → 编辑称呼(尽量全名)→ 段 1:投稿题目、文章类型、期刊 → 段 2:研究揭示了什么,可总结为 (1)(2)(3) → 段 3:发表将推动什么探索,对贵刊广泛读者有重要意义 → 可选:推荐 3 位审稿人;因利益冲突请求回避 → 声明:全体作者已读并同意;未在他处发表或投稿;无利益冲突;(可选)已经专业语言润色 → 感谢考虑,期待回复 → 落款:姓名、学位、职务、单位、地址、电话、邮箱。

### F. 利益冲突声明两种(附录七)

- 无冲突版:声明不存在可能被视为影响研究公正性的利益冲突。
- 有披露版:除已披露事项外,与任何对本稿主题有财务利益或冲突的机构无其他关联或财务往来。

### G. 替换表的分类逻辑(附录八至十一)

- **连接词(附录八)**:口语总结词(all in all / in a word / to sum up / in a nutshell)→ In summary / In conclusion / In brief;口语递进(and / besides / what's more)→ In addition / Furthermore;口语转折(but)→ However;口语因果(so)→ Therefore / As a result / Together(结果段末);口语时间(meanwhile / nowadays / in the end)→ Simultaneously / Currently / Finally;主观词(in my opinion / in fact / as we all know)→ 删除或改 It is well established that;there is/are → 删并重构。
- **动词(附录九,约 100 对)**:短语动词→单词学术动词(look at→examine;find out→determine;get rid of→remove;put together→link;keep→retain;go up→rise;make less→reduce;look for→search;figure out→realize;double-check→verify 等);口语动词→精确动词(get→obtain/yield;do→conduct/perform;have→possess/contain;say→state;need→require;try→attempt)。
- **风格(附录十)**:人称(you/your→改陈述;I/my→This paper…;泛指 they/we→It is well established that);程度词(huge→considerable;a lot of→considerable / a number of;a little bit→little;amazing→unexpected / consistent;quite→a large number of;bigger and bigger→is increasing);直接疑问句→陈述(Several studies have investigated why… / It is necessary to consider how… / We wondered whether…)。
- **弱化词(附录十一)七类**:引导动词(seem/tend/appear/indicate/suggest)、情态动词(can/could/may/might/would)、词汇动词(believe/assume)、数量形容词(some/many→a number of)、概率形容词(likely/possible)、概率副词(perhaps/probably/apparently)、频率副词(sometimes/usually/often)。

## 语法与语言要点

- 时态三分法:现在时=公认事实、图表、机制、公式;过去时=自己的实验行为与结果;现在完成时=领域累积的研究。
- 语态:方法节被动为常态;其他节主动优先;被动只在需要把受事放主语位置以承接前文时用。
- 报告动词后接 that 从句(suggest/indicate/demonstrate/show that);主谓一致;删 there is/are;删 can/could;删缩写。
- 弱化不叠加:一句里 indicate + may、suggest + most likely 视为双重弱化。
- 复合名词以 2 个名词为常态;歧义介词换成分词(possessing/exhibiting/containing)。

## 高频通用短语(英文,按功能分组,每组 ≤ 8 条)

以下为我自拟的功能短语,不照抄附录原句。

**指出缺口**
- Despite extensive work on X, its role in Y remains poorly understood.
- Whether A contributes to B has not been tested directly.
- Existing studies have largely overlooked ….
- The mechanism underlying this effect is still unresolved.

**陈述目标与方法**
- To address this gap, we combined A with B.
- We therefore asked whether ….
- Here we set out to quantify ….
- Using a cohort of N participants, we examined ….

**汇报结果**
- Here we report that ….
- As illustrated in Fig. 2, X rose sharply after ….
- Consistent with this, Y was also elevated.
- Taken together, these observations point to ….

**解释与比较**
- This pattern agrees with earlier reports of ….
- In contrast to previous findings, we observed ….
- One possible explanation is that ….
- These differences may reflect ….

**局限与结论**
- Several limitations should be noted.
- Our sample was restricted to …, which may limit generalisability.
- In conclusion, our findings provide direct evidence that ….
- These results offer a starting point for ….

**替代口语连接**
- In addition / Furthermore(替代 and, besides)
- However / In contrast(替代 but, on the contrary)
- Therefore / As a result(替代 so)
- In summary / In brief(替代 all in all, in a word)
- Currently / At present(替代 nowadays)
- Finally / Lastly(替代 in the end, last but not least)

## 可直接转化为 skill 规则的条目(每条一句,可检查)

1. 用户英语不自信时,允许先写中文,但要求中文稿已按"背景→问题→方法→结果→结论"组织,再翻译并做术语核对。
2. 全文搜索并删除缩写形式(n't、's 作 is、'll 等)。
3. 全文搜索 can/could,逐处判断是否可删或换精确动词。
4. 检测 get/make/do/have/let 作主要动词的句子,提示换学术动词。
5. 检测句首 And/But/So/Besides/Meanwhile/Nowadays/In a word,提示替换。
6. 检测 there is/are/were 开头,要求重构。
7. 连续名词 ≥ 4 个的复合名词,要求拆分。
8. 含 which 且超过 4 行的句子,拆成两句。
9. suggest/indicate/demonstrate/show 后若缺 that,补 that。
10. 方法节以外的被动句需给出保留理由,否则改主动。
11. 一句内出现两个弱化词(如 may + suggest),删一个。
12. 出现 you/your/I/my,改陈述式;泛指 we/they 改 It is well established that 式。
13. 出现直接疑问句,改为陈述式研究问题。
14. huge/a lot of/a little bit/amazing/quite 等程度词,换学术量词或删除。
15. 每个结果段检查是否有目标句、结果句、总结句三件套。
16. 讨论结尾检查是否回答:推进了什么理解、读者为何关心、局限或下一步。
17. 摘要检查六块是否齐全且成一条主线。
18. 输出 cover letter 时按附录六结构分段,并附利益冲突声明的两种可选版本。
19. 致谢若只含基金,提示补人员与机构。
20. 时态自检:事实与图表用现在时,自己的实验与结果用过去时,领域积累用现在完成时。

## 疑问 / 与书A可能冲突处

- **"除方法节外用主动语态"是否过强。** 书A 在结果与讨论中也接受被动作为信息流手段(把已知信息放主语位置)。规则 10 已加"给出保留理由"作缓冲,合成时应以书A 的信息流原则为准。
- **删 can/could。** 附录二要求删,但书A 和附录十一都把情态动词视为合法的谨慎表达。合理口径是:表能力的 can 换精确动词或删;表谨慎推断的 may/might 保留但不叠加。
- **"复合名词 2 个"是均值不是上限。** 规则 7 用 ≥ 4 作触发阈值是我的操作化选择。
- **"超过 4 行拆句"依赖排版。** skill 里改用词数(约 35–40 词)更可检查。
- **弱化词表把 indicate/suggest 列为引导动词。** 与附录二第 9 条要求用 suggest/indicate that 并不矛盾:一句用一个即可,矛盾只在叠加时出现。
- **替换表的英式/美式拼写**(analyse/analyze)书中混用,skill 应统一为按目标期刊选择。
- **附录九动词表约 100 对**,本笔记只收代表性 20 余对并重新归类,完整词表不入库。
