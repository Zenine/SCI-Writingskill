# 书B 第8章 中国作者的常见写作错误

> 来源:书B 第8章(书页 176–208,PNG bookB-190–222)

## 核心主张(3–7 条,自己的话)

1. 本章按「语言 → 语感 → 观念 → 母语溢出」四层递进:8.2 口语化与模糊词,8.3 语法正确但读起来别扭的「语感」问题,8.4 错误的写作观念(名词化、长句、炫词),8.5 中文语法直译进英文的结构性问题。越靠后的层次越难被语法工具发现,越需要人工/规则扫描。
2. 不存在「非学术词 → 学术词」对照表;唯一可靠的积累方式是带着语言意识去读本领域论文,建立自己的语料库。skill 能做的是给出「症状清单」而不是「替换词典」。
3. 学术写作的读者无法随时向作者追问,所以一切要读者「猜」的写法(模糊介词、模糊代词、无动词主题短语、发明的名词串)都算错误,哪怕语法上无懈可击。
4. 「显得高深」与「写得清楚」是两回事。抽象名词、长句、同义词轮换都源于中学作文式的写作观念;学术写作只有精确、清晰、简单、有逻辑四个评价维度,与句子长短和词汇量无关。
5. 母语溢出的共同机制:中文靠「主题统领 + 名词并置 + 多重谦辞」传递信息,英文靠「动词驱动 + 显式逻辑连接 + 单一避险词」传递信息;按中文句序翻译必然产生主题短语、重复主语、名词串、多重 hedging。
6. 小错误有大代价:单复数、词性、between/among 这类「低级错误」会让编辑和审稿人怀疑实验本身也草率,可能在送审前就被拒。提交前必须请合著者或同事通读。
7. 8.3 节的多数条目(语感类)修改前后都无绝对语法错误,是「更准确」而非「对/错」;skill 落地时应区分 error 与 warning 两个等级。

## 结构模型 / 模板

**结果段落中「目的—动作—方法」三段式**(用于替代双重目标句):

```
To <总目标动词> ...,   ← 只允许一个 to-不定式,且主语必须是研究者
we <具体动作动词(主动语态过去式)> ...   ← measured / analyzed / quantified
using / by <方法或工具(-ing 或名词)>.   ← using RT-PCR / by applying ...
```

**长句拆分的结果段标准序**:目的句(In order to ...)→ 图表结果句(As shown in Fig. X, ...)→ 解释/发现句(We found that ..., while ...)。拆分不是简单切句,而是按这个功能顺序重新分配信息。

**主题短语并入主句**:`介词 + 名词短语, 主句(代词重复主语)` → 把名词短语做成主句的主语或宾语,删除代词。
`For <X>, its <Y> is ...` → `The <Y> of <X> is ...`

## 语法与语言要点

以下每条:错误模式 → 修正原则 → 一个自己写的英文对比例。

### 8.2 语言层

**1. 口语化 / 谈话式开头**
- 错误模式:So / Well / Let me explain / actually / basically 等谈话标记进入正文。
- 修正原则:删掉全部谈话标记,直接陈述事实;详见第 7 章。
- Before: `So basically, the attention module actually helps the model focus on lesions.`
- After: `The attention module directs the model toward lesion regions.`

**2. 模糊介词 with / of / for**
- 错误模式:用 with/of 连接两个名词,关系(结合?伴随?属于?导致?)靠读者猜;或一句里出现 3 个以上 with。
- 修正原则:把介词换成表明关系的分词或动词(associated with / bound to / affecting / derived from);连续 with 改用 between ... and / and。
- Before: `The features with the tumor region of the CT scans were compared with those with the healthy region.`
- After: `Features extracted from the tumor region of each CT scan were compared with those extracted from healthy tissue.`

**3. 模糊代词 it / they / them / their**
- 错误模式:it 指代上一整句或多个候选名词;they 与先行词单复数不一致(Molecule T ... they)。
- 修正原则:用「this/these + 概括名词」或直接重复名词短语替换;they 必须有明确的复数先行词。合法的 it 只有形式主语(It is essential to ...)。
- Before: `The model was trained on two centres' data. It improved the AUC. However, they differed in scanner type.`
- After: `The model was trained on data from two centres and improved the AUC. However, the two centres differed in scanner type.`

### 8.3 语感层

**4. which 指代不明**
- 错误模式:which 前有两个以上名词,或 which 指代整句。
- 修正原则:移动 which 使其紧跟唯一先行词;表因果时改为 `thus/thereby + -ing`;能不用 which 就不用。
- Before: `The encoder compresses the slices into embeddings, which reduces memory use.`
- After: `The encoder compresses the slices into embeddings, thereby reducing memory use.`

**5. 无信息形容词 / 副词**
- 错误模式:carefully / robust / plausible / sophisticated / dramatically 等只表态度不加信息的修饰词。
- 修正原则:问「反义词成立吗」——如果没人会写 implausible model,那 plausible 就是废词;只保留改变操作含义的修饰(如为避免损伤而「小心」转移)。
- Before: `We carefully designed a robust and novel pipeline that dramatically improved sensitivity.`
- After: `The pipeline increased sensitivity from 0.71 to 0.86.`

**6. 错置修饰语**
- 错误模式:过去分词或比较级形容词硬贴在名词前(educated mice / superior performance than / identical conformation with),读者读不出「被谁 released」「比什么 superior」。
- 修正原则:修饰语必须与被修饰名词相邻且带出其补语:`N + -ed by ...`、`superior to that of ...`、`identical to that of ...`。
- Before: `The trained model with federated data showed superior accuracy than the baseline.`
- After: `The model trained with federated data showed accuracy superior to that of the baseline.`

**7. among / between 误用**
- 错误模式:按「两个用 between、多个用 among」的中学规则选词。
- 修正原则:between 用于彼此可区分的实体(不限于两个);among 用于「在一群中/被包围」,后接复数或集合名词。拿不准时把抽象名词改成动词,绕开介词。
- Before: `The distinction among the three scanners was significant.`
- After: `The three scanners differed significantly.`

**8. 双重目标句**
- 错误模式:`To A, X was used to B` / `In order to A, we did B to C`——一句里两个 to-不定式,目标—方法—方法的目标缠在一起。
- 修正原则:一句一个 to-目标;顺序改为 目标 → 主动动作 → using/by 方法。另一类:主语不是研究者(蛋白、酶、基因)时不能用 to + 动词表目的,改为 resulting in / that + 动词 陈述因果。
- Before: `To assess model drift, a holdout set was used to compare predictions to evaluate calibration.`
- After: `To assess model drift, we compared predictions on a holdout set and evaluated calibration.`
- Before(非研究者主语): `The transporter accumulates at the membrane to import glucose.`
- After: `The transporter accumulates at the membrane, resulting in increased glucose import.`

**9. 单复数 / 主谓一致**
- 错误模式:动词与最近的名词一致而不是与真正的主语一致(The region connecting the two domains are ...);中文无数的形态所以容易漏。
- 修正原则:找到名词短语的中心词再定动词;提交前专项扫描一遍;请他人通读。
- Before: `The set of hyperparameters selected by the two validation folds were fixed.`
- After: `The set of hyperparameters selected by the two validation folds was fixed.`

**10. 从句堆叠**
- 错误模式:主信息被两三个从句或状语隔开,句首连接副词离主句很远。
- 修正原则:主信息前置并紧邻连接副词,让步/背景信息用 despite / especially 推到句尾。
- Before: `Similarly, in the setting of low-dose CT, although noise is usually higher, there is no consensus on the optimal reconstruction kernel.`
- After: `Similarly, no consensus exists on the optimal reconstruction kernel, despite the higher noise typical of low-dose CT.`

**11. 同词根不同词性 / 近形词混用**
- 错误模式:In consistent with(形容词当名词);administrate vs administer;on the contrary vs in contrast;consistently 表示「与前人一致」。
- 修正原则:
  - 表「与前人一致」用 in agreement with / in line with,不用 consistently。
  - 描述两个对象的差异用 in contrast / in comparison;on the contrary 只用于反驳同一对象的前述判断。
  - on the one hand / on the other hand 只用于同一对象的两个相反特征。
  - 给药、施加处理用 administer,不用 administrate。
- Before: `Consistently, the ensemble was better. On the contrary, the single model overfitted.`
- After: `In agreement with previous reports, the ensemble performed better. In contrast, the single model overfitted.`

### 8.4 观念层

**12. 名词化误当学术化**
- 错误模式:用抽象名词(distinction / relation / determination / incorporation)承载核心信息,动词退化为 indicate / show + 名词。
- 修正原则:让动词做句子的引擎:`indicate + that + 主谓句`;抽象名词还原为动词(distinction → differ;relation → correlate with)。技术术语和专有名词除外。
- Before: `Our findings indicate the association of scanner type with model degradation.`
- After: `Our findings indicate that model performance degraded with certain scanner types.`

**13. 长难句 / 连续语句(run-on)**
- 错误模式:一句超过两行、含多个从句或多个 of,靠逗号 + which / but / and then 无限延长。
- 修正原则:「一句一个想法」;逗号后出现 which / but / and then / and as a result / therefore 就是句号候选点;用连接短语在句间保留逻辑(见第 5 章)。
- Before: `We observed that the segmentation masks were fragmented in the apical slices, and as a result the volume estimates were biased, and so we introduced a post-processing step, therefore the bias decreased.`
- After: `Segmentation masks were fragmented in the apical slices. As a result, volume estimates were biased. We therefore introduced a post-processing step, which reduced the bias.`

**14. 炫词 / 同义词轮换**
- 错误模式:同一概念在文中换用 depict / illustrate / display / demonstrate,或对同一术语引入多个变体。
- 修正原则:一个概念一个词,选最准确、最简单的(show)并全篇坚持;没有论文因为重复用词被拒,却会因为术语漂移被质疑。
- Before: `Figure 2 depicts the ROC curves, Figure 3 illustrates the calibration plots, and Figure 4 demonstrates the confusion matrices.`
- After: `Figure 2 shows the ROC curves, Figure 3 shows the calibration plots, and Figure 4 shows the confusion matrices.`

### 8.5 中文语法溢出

**15. 主题化(句首无动词介词短语)**
- 错误模式:As a ... / For ... / With ... / By ... / In ... + 名词短语,开头「设定话题」,与主句无逻辑连接,读者猜关系。
- 修正原则:遇到「介词 + 名词短语 + 逗号」开头就停下问「它与主句什么关系」;能并入主句就并入;表目的改 In order to + 动词;表方法放到句尾 using ...。
- Before: `With the transformer backbone, the small lesions were detected. By ablation experiments, the attention head mattered.`
- After: `The transformer backbone detected small lesions that the CNN missed. Ablation experiments showed that the attention head accounted for most of this gain.`

**16. 重复主语**
- 错误模式:主题短语给出名词后,主句再用 it / its / their 重复一次(For X, its Y is ...)。
- 修正原则:把主题短语中的名词直接做主语或作定语,删除代词。
- Before: `For the validation cohort, its sample size was too small to detect the effect.`
- After: `The validation cohort was too small to detect the effect.`

**17. 名词堆叠 / 发明复合名词**
- 错误模式:四个以上名词并置(tumor patient survival prediction model),或自创无缩写、无出处的术语串。
- 修正原则:领域已有缩写的固定术语可保留;否则用 of / for / that + 动词 解开,把逻辑关系写出来;不要为自己的发现发明新名词串,除非它就是核心贡献。
- Before: `We built a multi-centre CT lung nodule malignancy risk stratification pipeline.`
- After: `We built a pipeline that stratifies malignancy risk of lung nodules on CT scans from multiple centres.`

**18. 多重避险(hedging 过度)**
- 错误模式:we believe + suggest + it is likely + may possibly + although we are not sure 叠加,源于中文的谦辞习惯。
- 修正原则:一个结论一个避险词;按证据强度在 prove / demonstrate / suggest / indicate / may 中选一个。
- Before: `We believe these results may possibly suggest that it is likely that the biomarker could be related to recurrence.`
- After: `These results suggest that the biomarker is associated with recurrence.`

**19. 平行 / 选择结构误译**
- 错误模式:「都不」译成 both ... did not 或 X or Y were not;「既/又」译成 or;多选项用 with ... and ... respectively 拼接。
- 修正原则:两者皆否 → neither ... nor;两者皆是 → both ... and;真实互斥选项 → either ..., ..., or ...;避免 respectively 承担列举功能。
- Before: `Both augmentation and dropout did not improve the AUC; the gain came from pretraining or fine-tuning.`
- After: `Neither augmentation nor dropout improved the AUC; the gain came from both pretraining and fine-tuning.`

## 高频通用短语(英文,按功能分组)

**替换模糊介词的关系词**
- associated with / bound to / derived from
- affecting / that affects
- resulting in / leading to
- between A and B(可区分实体)
- differ depending on ...

**指代替换(代替 it / they / which)**
- this finding / these observations / this approach
- this increase / this reduction
- the former / the latter(仅两项时)
- thereby + -ing / thus + -ing(替代表结果的 which)

**一致性与对比**
- in agreement with / in line with previous reports
- in contrast / in comparison
- on the contrary(仅反驳同一对象)
- on the one hand ... on the other hand(仅同一对象的两面)

**目的—动作—方法**
- To assess / To determine / To establish whether ...
- we measured / quantified / compared ...
- using / by applying / by means of ...

**避险(一处一个)**
- these results suggest / indicate that ...
- ... is likely to / may ...
- these data demonstrate / show that ...

**平行与选择**
- neither X nor Y
- both X and Y
- either X, Y, or Z
- X as well as Y

## 可直接转化为 skill 规则的条目(中国作者错误清单,逐条扫描稿件)

1. 出现 So / Well / OK / Let me / actually / basically 等谈话标记 → 删除。
2. with 连接两个名词且关系不明 → 换成 associated with / bound to / containing 等显式关系词。
3. 一句内 with ≥3 次 → 改写,至少一处换 between ... and / and。
4. 两名词间 of 表「携带/影响/来自」等非所属关系 → 换成 affecting / derived from 等。
5. it 指代上一整句或 ≥2 个候选名词 → 换成 this/these + 概括名词或重复名词短语。
6. they / them / their 无明确复数先行词或先行词为单数 → 改名词或改 it。
7. which 前有 ≥2 个名词 → 移动 which 或改 -ing 分词。
8. which 表结果/因果 → 改 thereby/thus + -ing。
9. 修饰词无反义可能(plausible / robust / careful / novel / sophisticated)→ 删除;dramatically 一律删。
10. 过去分词或比较级形容词前置且缺补语(released N / superior N than / identical N with)→ 改 N released by / superior to that of / identical to that of。
11. among 后接可区分的两三个具体实体 → 改 between 或改写为动词句(differ / vary)。
12. 一句内 ≥2 个 to + 动词表目的 → 保留一个,其余改主动动词 + using/by。
13. 主语非研究者(基因/蛋白/装置)+ to + 动词表目的 → 改 resulting in / that + 动词。
14. 动词数与主语中心词不一致 → 修正;每个含后置修饰的主语必须核对中心词。
15. 主句信息被 ≥2 个从句/状语隔开,或连接副词与主句相距 >10 词 → 主句前置。
16. In consistent with → In agreement with;consistently 表「与前人一致」→ in agreement with / in line with。
17. on the contrary 用于比较两个不同对象 → in contrast / in comparison。
18. on the one hand / on the other hand 用于两个不同对象 → 改 in contrast 或删除。
19. administrate 表给药/施加 → administer。
20. indicate / show / reveal + 抽象名词(distinction / relation / importance / correctness / possibility)→ 改 + that + 主谓句。
21. 「动词 + the + 名词化 + of」(perform the determination of)→ 还原为动词(determine)。
22. 单句 >2 行,或含 ≥3 个 of,或逗号后接 which / but / and then / and as a result / therefore → 拆句。
23. 同一概念在全文用 ≥2 个动词/名词表达(depict/illustrate/demonstrate 轮换)→ 统一为最简单的一个。
24. 句首「介词 + 名词短语 + 逗号」且无动词、与主句关系不明 → 并入主句、改 In order to + 动词、或移到句尾 using ...。
25. 主题短语中的名词在主句里被 it / its / their 重复 → 删代词,名词直接做主语。
26. 连续 ≥4 个名词并置且非领域公认缩写术语 → 用 of / for / that + 动词 解开。
27. 作者自创的复合名词串无缩写、无引用 → 拆写为句子;只有核心贡献才允许命名。
28. 一个结论句内 hedging 词 ≥2 个(believe / suggest / likely / may / possibly / not sure)→ 保留一个。
29. both X and Y + 否定 → neither X nor Y;X or Y + 否定 → neither X nor Y。
30. 两项皆成立却用 or → both ... and;互斥多选项用 respectively 拼接 → either ..., ..., or ...。
31. 以上第 7–11、15、24 条为 warning 级(修改前后无绝对语法错误);其余为 error 级。

## 疑问 / 与书A可能冲突处

- **hedging 的度**:书B 强调中国作者 hedging 过度,主张一句一个避险词;书A 的 Discussion 单元通常鼓励充分使用 hedging 以避免过度声称。两者不矛盾——书A 说「要有」,书B 说「别叠加」;references 中应写成「每个结论一个避险词,强度与证据匹配」。
- **among / between**:书B 依据韦氏与剑桥词典给出「可区分性」标准,与多数中学教材相反;书A 若沿用「两个/多个」口径需以书B 为准并注明来源。
- **which 的态度**:书B 主张「能不用就不用」,偏保守;书A 的定语从句用法可能更宽松。skill 建议采用书B 的可检查标准(which 前只能有一个候选名词),但不禁止 which。
- **名词化**:书B 8.4.1 反对「无用名词化」,但书A(以及许多期刊惯例)在 Methods 中接受 `analysis was performed` 类被动名词化。应限定为:Results/Discussion 的核心结论必须动词驱动;Methods 中的固定流程可保留名词化。
- **第 8 章无「常见问题答疑」节**(仅小结、训练题、参考文献),任务描述中的「答疑」不适用于本章;第 7 章 7.11 的答疑已在 ch-07 记录。
- **训练题 8.7 的 10 句**全部是名词化 + 名词堆叠混合病句,可作为 skill 样例的灵感来源,但须自写新句,不得照搬。
- 书B 说 on the contrary 与 in contrast 混淆出现在「约 80% 的中国作者论文」中,这是作者经验判断而非统计数据,skill 中不要引用该数字。
