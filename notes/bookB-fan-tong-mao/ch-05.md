# 书B 第5章 搭建逻辑之桥

> 来源:书B 第5章(书页 93–118,PNG bookB-107–132)

## 核心主张(3–7 条,自己的话)

1. 论文的"研究逻辑"(从模糊到清晰的探索过程)和"行文逻辑"(方便读者理解的呈现顺序)不是一回事;写作时要站在读者一侧,把前者翻译成后者。
2. 段落层面有四种可复用的逻辑模型:General-Specific(普遍↔特殊)、Old-to-New(旧信息→新信息/从古到今)、Problem-Solution(问题→方案)、Process(步骤过程)。每种模型对应论文中固定的位置,选模型前先问"这一段在论文的哪个部位、要让读者产生什么反应"。
3. 模型是脚手架不是模板:一段最好只用一种模型;整篇可以混用(引言用 G-S、讨论用 S-G、摘要 G-S → P-S → S-G),熟练后可以自由组合。
4. 句子之间的逻辑必须显式化。母语作者可以靠语感隐含逻辑,非母语作者应该主动用连接词、重复、时间状语、-ing 从句、this + 概括名词等手段把关系"钉"在句子上;这样做不会显得不专业,"清晰、明了"是学术写作的目标,"优雅"不是。
5. 用连接词前先确定要表达的关系是"补充/对比/因果/让步/解释/举例/强调"中的哪一种;含义模糊的连接词(meanwhile、句首的 and/but/though、无逻辑的 and)会让读者猜不出两句之间是并列、递进还是因果,应替换或删除。
6. 学术写作允许并鼓励对同一对象使用同一个词或"动词过去分词+名词"的重复形式来承接上句,不要像散文那样追求词汇变化。
7. 中式英语中连接词误用的根源是先写中文再翻译:中文的"和""同时""所以"含义很宽,直译成 and / meanwhile / so 就变成没有信息量的连接。补救办法是翻译完先保证内容准确,隔一天再做一轮"读者视角的内部审稿",逐段问:这段用的是什么模型?两句之间的逻辑是什么?

## 结构模型 / 模板(用自己的话描述每种模型的适用场景、步骤、判断标准)

### 模型 1:General-Specific(G-S)与 Specific-General(S-G)

- **适用位置**:G-S 出现在摘要开头、引言开头、部分讨论/结论;S-G 出现在摘要结尾、结论与讨论的收尾。
- **G-S 四步**:①一句普遍陈述(领域重要性 / 公认判断)→ ②对该陈述的解释 → ③补充更具体的细节或论据 → ④把观点与更广的问题挂钩,引出本文要谈的具体对象。
- **G-S 开头的三种写法及选择依据**:
  - 铺垫普遍事实与判断:读者背景不一、需要交代趋势和研究背景时用;目的是引起广泛共鸣。
  - 概念界定(下定义):读者是同行、需要一个公认的严谨范畴来框定研究对象或方法时用;定义本身就代表领域共识。
  - 用震撼性数据:现象可以用数字凸显严重程度或变化趋势时用;目的是勾起好奇。
- **S-G 四步**:①具体或特殊事实 → ②对该特殊情况的解释 → ③逐步过渡到更广的领域 → ④用普遍性观点收束。用途是告诉读者本文对更大领域的贡献或借鉴意义。
- **判断标准**:开头句能否被"不做本研究的同行"直接认同?能 → 是合格的 general 句;结尾句是否超出了本文数据、指向了更广的领域?是 → 是合格的 S-G 收尾。

### 模型 2:Old-to-New(旧信息到新信息 / 从古到今)

- **适用位置**:引言与文献综述。
- **步骤**:从已知的、较早的研究起笔 → 过渡到前沿发现 → 引出本文研究问题。
- **实现手段**:时间状语打头(Since 1990s, …;Over the past decade, …);"像此前所有版本一样 / 受益于 N 年积累"之类的承接语;引文注释按年份递进排列,让读者同时看到研究对象的演变和同行关注点的转移。
- **判断标准**:把段落里的年份/引文年份抽出来,应呈单调递增;每句的主语应是上一句已经出现过的信息或它的延伸。

### 模型 3:Problem-Solution(问题到解决方案)

- **适用位置**:研究发现(Results)与讨论;有时也用于摘要和引言。适合分析性段落或对某一事实/观点做评价。
- **三种表达手段**:
  1. -ing 从句把"现象 → 表现 → 后果"压缩进一句话,让多个结果共用一个前提(见 5.3.5)。
  2. 间接疑问句(whether / what / how + 陈述语序)用来交代研究目的或引出议题,例如 "we conducted a survey to determine whether …"。
  3. 中间位置的"转折副词 + 时态"组合:先用 However / Nevertheless / Despite this 指出问题仍存在,再用"现在正在被测试 / 一种方法是 / 有两条路径,第一…第二…"引出方案;结果段开头也可用"主动语态 + 过去时"(we employed / we performed)体现研究者主导的操作。
- **判断标准**:段内能否明确指出"问题句"和"方案句"各在哪里;两者之间是否有一个转折或因果连接词把它们钉在一起。

### 模型 4:Process(过程)

- **适用位置**:研究方法为主,有时在结果部分。
- **步骤**:按实验实际顺序,用 First / Second / Then / Next / Finally 逐步铺陈;方法部分默认"被动语态 + 过去时";结果部分主动被动皆可,可用 then 强调前后承接。
- **判断标准**:每个步骤动词都是具体可操作的(drawn / tuned / solved / embedded / repeated),没有模棱两可的说法;读者按此顺序能复现。

### 模型混用规则(来自常见问题答疑)

- 一段一模型;整篇可以混用。
- 引言各小节按 G-S,方法与结果各小节也按 G-S;讨论各小节可用 S-G;有时出现 G-S-G(类似"总-分-总")。
- 摘要作为论文迷你版:前 2–3 句 G-S,中间 2–3 句 P-S,最后 2–3 句 S-G。

## 语法与语言要点

本章重点在段落逻辑,语法点集中在六种句间连接手段,按「错误模式 → 修正原则 → 自写对比例」整理。

### 5.3.1 连接短语与三组易混辨析
- 错误模式:随手用一个"差不多"的连接词,读者无法判断是补充、对比还是因果。
- 修正原则:先定关系类型,再按类型选词(见下节短语表);in contrast 用于比较两个不同对象,on the contrary 用于同一问题上与他人观点相反;meanwhile 不用于学术写作,表并列对比用 while;while 放句首时读者一开始就知道要比较,放句中则读到一半才意识到,按强调需要选位置。
- 对比例:✗ The CNN reached 0.91 AUC, meanwhile the transformer reached 0.88. → ✓ While the CNN reached an AUC of 0.91, the transformer reached only 0.88.

### 5.3.2 and / but / though 的口语化用法
- 错误模式:and / but / though 放句首;两个没有逻辑关系的事实用 and 硬连。
- 修正原则:句首 but → However / In contrast / Unexpectedly;句首 and → In addition / Furthermore / Importantly;though → 只能作从句连词跟在逗号后(…, even though …);无关事实之间要么拆句,要么换成能说明作者态度的副词(Interestingly / Notably)。
- 对比例:✗ The model generalized well to the external cohort, and the inference time was 40 ms. → ✓ The model generalized well to the external cohort. Notably, inference took only 40 ms per case.

### 5.3.3 适当重复
- 错误模式:为了不重复,用 in which / which 引导长从句或换一个新名词指代同一对象,读者需要回头找指代。
- 修正原则:把上句的被动动词改成"过去分词 + 名词"放到下句主语位置(was trained → This trained model),形成钩子;学术写作允许并鼓励这种重复。
- 对比例:✗ A segmentation network was pretrained on public scans, after which it was fine-tuned on our cohort. → ✓ A segmentation network was pretrained on public scans. This pretrained network was then fine-tuned on our cohort.

### 5.3.4 时间状语
- 错误模式:方法/结果段落按顺序写了多个步骤,却没有任何顺序标记,读者分不清先后。
- 修正原则:在步骤句首加 First / Second / Then / Next / Finally / Once …;标记数与实际步骤数一致。
- 对比例:✗ Images were resampled to 1 mm. Intensities were normalized. Patches were extracted. → ✓ First, images were resampled to 1 mm isotropic voxels. Next, intensities were normalized to zero mean. Finally, 64 × 64 patches were extracted.

### 5.3.5 因果关系的 -ing 从句
- 错误模式:两个有因果关系的短句各自独立,或一句里塞了两个以上 -ing 从句。
- 修正原则:主句陈述原因,用 ", thus + -ing" 引出结果;-ing 之前必须有 thus / thereby 之类标记体现主语关系;每句只允许一个 -ing 从句,一句只表达一个观点。
- 对比例:✗ Label noise inflates the loss. The optimizer overfits to outliers. → ✓ Label noise inflates the training loss, thus driving the optimizer to overfit to outliers.

### 5.3.6 this + 概括名词
- 错误模式:单独用 This / These 指代上句整件事,指向不明。
- 修正原则:this / these 后面必须紧跟能概括上文的名词或动名词(this process / this decrease / these findings / this shift)。
- 对比例:✗ The recall dropped sharply after month six. This suggests drift. → ✓ The recall dropped sharply after month six. This decline suggests distribution drift in the incoming data.

## 高频通用短语(英文,按功能分组,每组 ≤ 8 条)

**补充 / 递进**(替代句首 and、besides、what's more)
- In addition, …
- Furthermore, …
- Moreover, …
- Importantly, …
- In addition to X, …

**让步 / 转折**(替代句首 but、though)
- However, …
- Nevertheless, …
- Despite this, …
- Although / Even though + 从句
- Despite / In spite of + 名词
- Unexpectedly, … / Surprisingly, …

**对比**(替代 meanwhile、on the contrast)
- While / Whereas + 从句
- In contrast, … / In contrast to X, …
- On the other hand, …
- Conversely, …
- Unlike X, …
- On the contrary, …(仅用于反驳同一观点)

**因果 / 结果**(替代 so、句首 because)
- Therefore, … / Thus, … / Hence, …
- As a result, … / Consequently, …
- Because of / Due to / As a result of + 名词
- As / Since + 从句
- …, thus + -ing / …, thereby + -ing

**解释 / 举例 / 强调**
- In other words, …
- That is, … / i.e.
- For example, … / For instance, …
- In fact, …(慎用,多数情况可删)

**时间与过程顺序**
- First, … / Second, … / Third, …
- Then, … / Next, … / Subsequently, …
- Once X was completed, …
- Finally, … / Lastly, …

**总结收束**(替代 all in all、in a word、to sum up、last but not least)
- In summary, …
- In conclusion, …
- Briefly, … / In brief, …

**Problem-Solution 常用句式骨架**(自写骨架,非书中原句)
- However, the question of X remains open.
- One approach currently under investigation is to …
- Two strategies have been proposed to address this issue: the first …, the second …
- A fundamentally different design is needed to overcome this limitation.
- Recent work has made considerable progress toward …
- We therefore adopted … / We performed … to determine whether …

**概括性指代**
- This process / This procedure
- This decrease / This increase / This shift
- These findings / These observations
- This limitation / This discrepancy

## 可直接转化为 skill 规则的条目(每条一句,可检查)

1. 摘要按"前 2–3 句 G-S → 中间 2–3 句 Problem-Solution → 末 2–3 句 S-G"排布,每段落只用一种逻辑模型。
2. 引言开头第一句必须是同行不做本研究也能认同的普遍陈述、公认定义或有出处的关键数据;不能直接从本文方法起笔。
3. 引言/综述中的文献按时间由旧到新排列,引文年份单调递增;每句主语承接上句已出现的信息。
4. 讨论或结论的收尾段必须出现一句超出本文数据、指向更广领域的 general 句。
5. Methods 段落步骤 ≥ 3 时必须使用 First / Then / Next / Finally 等顺序标记,标记数与步骤数一致。
6. Results 段可用"主动语态 + 过去时"(we performed / we employed)起句,以体现研究者主导的操作。
7. 每个句间连接词都必须能归入"补充 / 让步 / 对比 / 因果 / 解释 / 举例 / 强调 / 顺序"之一;归不进去的连接词删除或改写。
8. 禁止 and / but / so / though 位于句首;分别替换为 In addition·Furthermore / However·In contrast / Therefore·As a result / …, even though。
9. 禁止 meanwhile;表并列对比用 while / whereas,表真正同时发生用 simultaneously。
10. on the contrary 仅用于反驳同一议题上的他人观点;比较两个不同对象一律用 in contrast;不得写 on the contrast。
11. and 只能连接有逻辑关系的成分;两个独立事实之间应拆句,并按作者态度选 Interestingly / Notably / In addition 之一。
12. 承接上句时优先用"过去分词 + 名词"重复(This trained model …),不用 in which / which 长从句,也不换新名词指同一对象。
13. -ing 因果从句前必须有 thus / thereby;每个句子最多一个 -ing 从句。
14. this / these 作主语时后面必须紧跟概括名词(this process / these findings);单独的 This 视为错误。
15. 删除或替换口语化和主观连接语:in my opinion、as we all know、in fact、actually、in a nutshell、in a word、last but not least、nowadays(→ currently / at present)、that is(→ in other words)、there is/are(删除或改写)。
16. 汉译英稿件必须经过一轮"读者视角审稿":逐段标注所用模型和句间逻辑关系,缺失处按本章手段补齐。

## 疑问 / 与书A可能冲突处

1. **because 的地位**:本章表 5.3 把 because 列为"不恰当表述"并建议改 as;但书A 与通行用法均接受 because 引导的从句(尤其句中位置)。建议 skill 采用折中:句首 Because 从句允许,但优先用 As / Since / Given that;不把 because 一律判错。
2. **in fact / on the contrary 的双重身份**:表 5.1 把 in fact / as a matter of fact / on the contrary 列为"强化"类合法连接词,表 5.3 又建议 in fact 直接删除。skill 中按"可删则删,保留时只用于强化前句"的口径处理,不作硬禁。
3. **Results 时态与语态**:本章说结果段可"主动 + 过去时"起句,与第 6 章"结果段既可现在时也可过去时"及书A"报告自己的数据用过去时、指图表用现在时"需统一;合成 reference 时以书A 的可检查表述为准。
4. **there be 的处理**:本章表 5.3 建议"删除或改写",第 6 章更严格地要求避免;但书A 的模板句里偶见 there is a need for …。skill 采用第 6 章口径(默认禁止),并在 Problem-Solution 骨架里用 "X remains open / few solutions exist" 替代。
5. **连接词密度**:本章鼓励非母语作者主动多用连接词,书A 的示例段落连接词较少、更依赖信息流(旧→新)承接。两者不矛盾,但 skill 应写明上限,避免每句都以连接词开头;建议规则:同一段落中以连接副词起句的比例不超过一半。
6. **"一段一模型"与书A 的段落结构**:书A 按"功能步(moves)"拆分引言/讨论,本章按逻辑模型拆分;两套框架可并行使用(moves 决定内容顺序,模型决定句序),合成时需说明对应关系(例如引言 move 1 = G-S 开头,move 2 = Problem 句,move 3 = 本文方案)。
