# 书B 第7章 学术论文的写作风格

> 来源:书B 第7章(书页 155–175,PNG bookB-169–189)

## 核心主张(3–7 条,自己的话)

1. 学术风格不是「装高级」,而是服务四个硬指标:清晰、精确、合逻辑、简洁。绝大多数风格规则都能追溯到这四条,判断一个写法可不可以,先问它是否让读者少猜。
2. 中国作者的口语化倾向有结构性原因:十几年的英语训练都在写记叙文、邮件、创意写作,养成的是「说话式」词汇;学术词汇(拉丁语源为主)只能靠有意识地读论文积累,没有捷径。
3. 凡是要求读者「自己补全」的表达都要清除:run-on 结尾(etc./and so on)、缩写、含糊的代词、习语隐喻、句末孤零零的副词。共同点是作者省事、读者受累。
4. 风格问题不该在初稿阶段纠结。先把故事线、主线索、核心发现写清楚,再专门做一轮「语言与风格改写」;初稿可以用英文直接写,拿不准的动词副词先放一个有把握的。
5. 综述类文章风格更灵活(可用直接疑问句、主观判断),本章规则主要针对实证研究论文;但综述仍是学术文本,不能像新闻评论那样自由。
6. 已发表论文不都是范本,尤其是低影响因子期刊上的;不要以「我在文献里见过」为理由保留不规范表达。
7. 语言问题的终极解法是「读、读、读」并做对比练习:同一研究的科普推送 vs 原文摘要;自己先写摘要再对照原文。

## 结构模型 / 模板

本章不涉及论文章节结构;但给出一个「直接疑问句 → 间接疑问句」的分节改写模型,可视作研究问题在全文中的三种落位:

| 落位 | 句式骨架 | 功能 |
|---|---|---|
| Introduction | `Several studies have investigated how/whether ...` | 交代已有工作 |
| Introduction 末 / Discussion | `It is important to understand how/whether ...` | 提出研究意义 |
| Discussion / Conclusion | `It remains unclear how/whether ...` | 指出缺口或局限 |

同一研究问题只需换引导短语,就能在三个章节各司其职;直接疑问句做不到这一点,因为它会打断段落的逻辑推进。

另附「去缩写两步法」:先把缩写展开(don't → do not),再把否定动词结构换成带否定含义的动词或量词(did not yield any → yielded no;did not give much → allocated little)。

## 语法与语言要点

以下每条:错误模式 → 修正原则 → 一个自己写的对比例。

### 1. 口语化词汇替代

- 错误模式:用 a lot of / really / get / big 等日常词表达程度和动作。
- 修正原则:换成拉丁语源的学术词(considerable / substantially / obtain / increase),并优先选能带出具体含义的动词。
- 对比例:
  - Before: `We got a lot of good data from the sensors, and the error got smaller and smaller.`
  - After: `The sensors yielded a substantial volume of valid data, and the error decreased progressively.`

### 2. Run-on 结尾(etc. / and so on / and so forth / the like)

- 错误模式:列举几项后用「等等」收尾,把补全类别的任务丢给读者。
- 修正原则:三选一——(a)列表前加 `including`/`such as` 表示不完整;(b)结尾换成一个概括性短语 `and other + 类别名`;(c)全部列出时用 `namely`。
- 对比例:
  - Before: `The model was tested on lung nodules, liver lesions, kidney cysts, etc.`
  - After: `The model was tested on several lesion types, including lung nodules, liver lesions, and kidney cysts.`
  - 或全列出:`The model was tested on three lesion types, namely lung nodules, liver lesions, and kidney cysts.`
- 附注:`et al.` 是允许的缩写,只用于作者列表。

### 3. 缩写(contractions)

- 错误模式:don't / it's / there's / can't 等出现在正文。
- 修正原则:一律展开;展开后若出现 `did not + 动词 + any/much`,进一步改为 `动词 + no/little/few`。所有格撇号(the manufacturer's protocol)保留。
- 对比例:
  - Before: `The classifier didn't give us many false positives.`
  - After: `The classifier produced few false positives.`

### 4. 副词位置

- 错误模式:副词挂在句首(Actually, ...)或句尾(... successfully.),句中有多个动词时读者要猜它修饰谁。
- 修正原则:副词紧贴被修饰的动词——主动语态放动词前;被动语态放助动词与分词之间(was originally developed);时间副词 then/subsequently 同样进入句中。
- 对比例:
  - Before: `Then the images were segmented and the features were extracted automatically.`
  - After: `The images were then segmented, and the features were automatically extracted.`

### 5. 代词惯例

- 错误模式:用 you 指读者(You can see in Figure 2 ...);用 we 指「大家」(As we all know ...);单作者论文硬用 I。
- 修正原则:
  - you 在论文中基本不存在,改被动或以图表做主语(Figure 2 shows ...)。
  - we 只指作者团队,且用于主动语态陈述作者的动作或发现;不能代表读者或全人类。
  - 单作者不想用 I 时,用 `This paper / This study / This review + 动词` 作主语。
- 对比例:
  - Before: `As we all know, you can improve accuracy by adding more training data.`
  - After: `Accuracy generally improves with larger training sets [refs]. This study tests whether the same holds for low-resource clinical data.`

### 6. 直接疑问句 → 间接疑问句

- 错误模式:正文中出现带问号的句子(Why does the model fail on small lesions?)。
- 修正原则:改为陈述句,用 `investigate/assess/test/ask + how/whether/why` 或 `it remains unclear whether` 引导;被动直接疑问句转间接时注意语序恢复(does X cause → whether X causes)。计算机、社科领域在引言末列研究问题时允许直接疑问句,按目标期刊惯例。
- 对比例:
  - Before: `Does the pretrained encoder help on small lesions?`
  - After: `We tested whether the pretrained encoder improves detection of small lesions.`

### 7. 习语、隐喻、俚语、双关

- 错误模式:用 a double-edged sword / the tip of the iceberg / in a nutshell 这类比喻;或用某领域已流行的隐喻(gold standard)而不确认其通用性。
- 修正原则:一律换成字面表达;拿不准的短语先到本领域数据库检索,只有少数作者用的就不用。
- 对比例:
  - Before: `Data augmentation is a double-edged sword for small datasets.`
  - After: `Data augmentation improves robustness on small datasets but can also introduce unrealistic samples.`

### 8. 经济用词(economic use)

- 错误模式:There are some ... that ...;materials of inorganic origin;in the process of;have been shown to be very promising indeed。信息少而占空间多。
- 修正原则:删空转开头(There are/It is ... that)、删「of + 抽象名词」改形容词、删无信息强化语(very / indeed / it is worth noting)。目标是一句话一个事实。
- 对比例:
  - Before: `There are a number of deep learning methods that have been proposed in the field of medical imaging that are really promising.`
  - After: `Several deep learning methods show promise for medical imaging.`

### 9. 句子过长

- 错误模式:一句里用 thus / resulting in / leading to / suggesting that 串起四五个动作,逗号极多,朗读会断气。
- 修正原则:按「结果 → 结论」切成 2–3 句,句间用逻辑连接词(As a result, / Together, these data suggest ...);一句话只放一个事实。
- 对比例:
  - Before: `The lesion count rises with age, thus increasing reading time, resulting in radiologist fatigue, leading to more missed findings, suggesting that automated triage is necessary.`
  - After: `The lesion count rises with age, which lengthens reading time. As a result, radiologist fatigue increases and more findings are missed. Together, these observations argue for automated triage.`

## 高频通用短语(英文,按功能分组)

**把口语程度词换成学术词**
- is an integral part of / plays a central role in
- for nearly / approximately
- has been considerable / substantial
- we performed a number of / a series of
- we obtained / observed
- is increasing / has risen steadily

**替代 run-on 结尾**
- ..., including A, B, and C
- ..., such as A and B
- A, B, and other + 类别名
- ..., namely A, B, and C(全列出)
- ... and similar + 类别名 + requiring ...

**间接疑问句引导语**
- We investigated / assessed / tested whether ...
- We asked how / why ...
- It remains unclear whether ...
- It is important to understand how ...
- A central question is whether ...
- Little is known about how ...

**单作者或不想用 we 时的主语**
- This paper discusses / argues / proposes ...
- This study aims to ...
- This review concludes that ...
- The present analysis shows ...

**否定的学术化写法**
- yielded no ... / produced no ...
- has few / allocated little ...
- little research has been conducted on ...
- failed to detect ...

## 可直接转化为 skill 规则的条目

1. 正文不得出现 etc. / and so on / and so forth / the like;列举不完整用 including/such as 或 `and other <类别>` 收尾,完整列举用 namely。
2. 正文不得出现动词缩写(don't/it's/can't/there's);所有格 's 允许。
3. 展开缩写后若出现 `did not + verb + any/much/many`,改写为 `verb + no/little/few`。
4. 副词不得孤立于句首或句尾;主动语态放动词前,被动语态放 be 与分词之间;句中含 ≥2 个动词时必须检查副词归属。
5. 正文不得出现代词 you;改被动或以图表/研究作主语。
6. we 只能指作者团队,用于主动语态陈述作者的动作/发现;`As we all know`、`we can see` 类泛指一律删除。
7. 单作者论文可用 `This paper/study/review + 动词` 代替 I。
8. 实证研究正文中不得出现问号句;改为 `investigate/test/assess + how/whether` 或 `it remains unclear whether`。计算机/社科类引言末列研究问题为例外,按期刊惯例。
9. 不得使用习语、隐喻、俚语、谚语、双关;疑似隐喻性的领域短语需在本领域数据库确认为通用后才可用。
10. 删除空转开头:There are/is ... that、It is ... that(非强调时)。
11. 删除无信息强化语:very、really、indeed、quite、rather、of course、obviously。
12. `of + 抽象名词` 可改形容词时改形容词(materials of inorganic origin → inorganic materials)。
13. 一句话只承载一个事实;一句中出现 ≥3 个 thus/resulting in/leading to/suggesting that 类连接时必须拆句。
14. 单句逗号数 ≥5 视为过长信号,触发拆句检查。
15. 出现 a lot of / lots of / big / get / really 时替换为学术等价词。
16. 风格改写在初稿完成后作为独立一轮进行;初稿阶段不因风格问题阻塞内容写作。

## 疑问 / 与书A可能冲突处

- 书B 明确「we 只指作者团队,主动语态优先」,并把 `It was found ...` 改为 `We found ...`;书A 传统上在 Methods 部分更倾向被动语态。两者不矛盾但需分章节说明:Methods 描述步骤可被动,Results/Discussion 陈述发现时用 we + 主动。
- 书B 对直接疑问句留了学科例外(CS/社科引言末),书A 是否有类似说明需在合成 references 时核对;建议规则写成「默认禁止,期刊惯例可覆盖」。
- 书B 说 among/between 等语感问题「不是绝对语法错误」;skill 中此类条目应标为 warning 级而非 error 级,以免误伤。
- 「gold standard」被书B 视为可接受但不鼓励的隐喻;医学影像领域该词极常见,skill 应把它列为白名单而非一刀切禁止。
- 书B 建议英文直接起草而非中译英;这一点与本仓库 samples 中「中文方法段 → 英文 Methods」的测试流程方向不同,属工具用途差异,不是规则冲突,但 skill 说明中可提示用户长期应转向英文起草。
