# 书B 第1章 从学术伦理开始
> 来源:书B 第1章(书页 1–19,PNG bookB-015–033)

## 核心主张(3–7 条,自己的话)

1. 学术诚信不是写作的附加项,而是写作的起点:一篇论文的可信度先由"是否造假、是否可复现、是否如实披露"决定,其次才是语言和结构。
2. 违规的代价分三层递增:个人(撤稿、荣誉收回、职业终结)→ 学科共同体(整个国家在该领域的信誉受损,例如期刊被 SCI 剔除)→ 社会(医学领域造假直接危及患者)。书中用三个真实撤稿案例分别对应这三层。
3. 利益冲突(conflict of interest,COI)本身不是"错",而是一种需要管理的状态。正确姿势是"申报披露",不是"否认"或"断绝合作"。作者要主动让读者知道谁资助了研究、谁持有股份、谁担任顾问,以便读者自行判断结果可信度。
4. 引用的本质是给读者画一张"学术地图":标出边界(高度相关)、内容准确(概括原意而非截取有利片段)、视角多元(不只引支持自己的)、来源权威且时效(既尊重奠基者也跟进最新进展)。引用一手文献、不为凑数而引、不为迎合期刊而引。
5. 伦理合规在时间上有硬顺序:伦理审查批件必须在研究开始之前拿到,投稿时无法补办;署名安排要在合作开始之前谈好,不能等到投稿前再争。
6. 论文写作全流程有四个伦理检查点:写作前(伦理声明)→ 写作中(规范引用)→ 完成后(利益冲突声明)→ 投稿前(查重)。
7. 数据处理的底线是"按研究设计报告":删异常值、换统计方法、挑选成功批次都属于事后操作,若不在文中说明并给出正当理由,就是筛选数据(cherry-picking),属典型学术不端。

## 结构模型 / 模板(用自己的话描述方法、步骤、判断标准,不抄例文)

### 1. 四阶段伦理检查流程

| 阶段 | 要做的事 | 判断标准 |
|---|---|---|
| 写作前 | 确认伦理审查 | 涉及人/动物的研究,批件日期早于数据采集日期;国际合作项目要核对每个子活动(如访谈)是否单独覆盖 |
| 写作中 | 规范引用 | 每条引用可追溯到一手来源;引文服务于自己的逻辑线而非堆砌;先梳理自己的故事线再补他人观点 |
| 完成后 | 利益冲突声明 | 列出每位作者与资助方/企业的关系(资助、顾问、股权、差旅);确无冲突则用标准否定句式 |
| 投稿前 | 查重 | 用 Turnitin / PaperPass 等工具;只上传引言和文献综述部分(方法、结果、结论原创度高且有泄露风险,通常不必送检) |

### 2. 利益冲突声明的写法模型

- 逐位作者列出:与哪家机构、什么关系(资助/顾问委员会/差旅/咨询费/雇员/持股)。
- 最后一句收束:其余作者声明无竞争性利益。
- 若完全没有冲突,用一句标准声明说明"不存在可能被认为影响研究公正性的利益冲突"。
- 判断是否要写:凡是"次要利益"(经济收益、学术声望、人情、职位晋升)可能影响"主要利益"(患者福祉、结果有效性)的专业判断,就要披露。

### 3. 学术地图式引用的四条尺子

- 明确:所引文献与本研究高度相关,不引无关文献。
- 准确:概括原文整体观点,不断章取义。
- 多元:呈现同一问题的不同视角,包括反对自己的证据。
- 权威与时效:引最早报告该现象的作者,也引最新进展。

### 4. Roig 28 条写作规范(按主题归并成 6 组,自己的话)

- **来源标注**(准则 1–7):逐字引用必加引注;转述和概述也必须标来源;不确定是否常识就引;转述要用自己的词汇和句法重现原意,前提是完全读懂原文。
- **自我重复**(准则 8–13):重复使用自己已发表的文字必须告知读者或按规范引用;一项复杂研究拆成多篇时要透明说明数据关联;能作一篇完整报告的不要切成"香肠论文";已在会议、预印本、其他期刊传播过的数据要向编辑说明。
- **引用核查**(准则 14–19):正文引注与参考文献一一对应;引文要素(作者拼写、卷号、页码)取自原文而非二手转引;不为操纵影响因子而引无关文献;引已出版版本,引未出版版本时确认未被更正或撤回;只读过二手概述就不要装作引了原文。
- **诚实报告**(准则 20–23):大量借用同一来源时要让读者分清哪些是自己的、哪些是引的;有义务报告与自己观点相反的证据;引用的支持证据若有方法或统计缺陷要指出;任何可能影响独立复现的方面都要报告;所有事后数据操作要写明并给理由。
- **署名**(准则 24–27):合作开始前按 ICMJE(国际医学期刊编辑委员会)等指南谈好署名;只有实质性贡献者才能署名;师生合作同样标准,导师不能给贡献不足的学生署名,也不能剥夺有贡献学生的署名权;不接受代笔(ghost authorship)。
- **利益冲突**(准则 28):意识到并尽力披露所有实际或潜在的利益冲突(持股、赞助方等)。

### 5. 常见问题答疑中的判断规则

- 期刊要求"引本刊文章可加快处理":这是低质量期刊的信号,文章质量好就另投;但编辑基于读者匹配度建议引本刊相关文献是可接受的。
- 一稿多投的定义:同时向多家期刊提交同一稿件。会议论文、学位论文、专著、预印本与期刊论文的关系不算一稿多投,但要向编辑说明先前传播情况(对应准则 12)。拒稿后再投另一家是正常流程。
- 署名与致谢的分界:没有通用的量化比例。原则是合作一开始就定,写成书面共识并让所有人签字。
- 同一文献多次引用:每处都要标。整段都在讲一篇前人研究时,可在段首段尾标注,段中用"该作者指出/他们发现"指代。
- 作者排序:各国各学科惯例不同(常见:做主要实验和写作的研究生/博士后为第一作者,导师或项目负责人为末位/通讯作者;有的按字母序;跨国合作常用共同第一/共同通讯)。遵循所在团队和学科惯例,提前问清。

## 可直接转化为 skill 规则的条目(每条一句,可检查)

1. Methods 中涉及人体或动物数据时,必须有伦理批准声明,写明审批机构与批号,且批准日期早于数据采集日期。
2. 涉及人的访谈、问卷、样本采集,必须写明已获得知情同意(informed consent)。
3. 投稿稿件必须包含 Declaration of interests 段落;有冲突则逐位作者列出关系,无冲突用标准否定句式。
4. 必须写明资助来源(Funding);接受企业资助时在声明中说明,并确认作者有独立发表权。
5. 正文中每一处非自己观点、发现、论证的句子都要有引注;整段综述单篇文献时至少在段首和段尾标注。
6. 参考文献表与正文引注必须双向一一对应:正文引的都在表中,表中列的都被引过。
7. 引文要素(作者、年份、卷、页)必须核对原始文献,不从二手来源转抄。
8. 引用必须与内容直接相关;不为迎合期刊、提升影响因子或凑数而引用。
9. 对同一研究问题,应同时引用支持性证据和相反证据;所引证据有方法学缺陷的要指出。
10. 任何事后数据处理(删除异常值、剔除设备故障时段、更换统计方法、挑选批次)必须在 Methods 中写明并给出理由。
11. 复用自己已发表的文字必须引用或告知读者;拆分发表的数据要说明与已发表论文的关系。
12. 数据、评审意见或结论若已在会议、预印本、其他期刊传播,投稿信中必须说明。
13. 稿件不得同时投给多家期刊;被拒后方可另投。
14. 署名只给实质性贡献者;署名顺序在合作开始时书面确定并经全员同意;不接受代笔。
15. 推荐审稿人时必须提供真实的机构邮箱,不得提供由作者控制的邮箱。
16. 投稿前对引言和文献综述部分做查重;方法、结果、讨论部分不上传第三方查重系统。
17. 转述他人研究时,必须用自己的词汇和句法结构重写,并保留原意;不得只替换个别词。

## 疑问 / 与书A可能冲突处

1. 书B 建议"先梳理自己的故事线,再补他人观点";书A 的 Introduction 模型是从"已有研究 → 缺口 → 本文"顺序推进。两者不冲突(一个是写作顺序,一个是成文顺序),但 skill 里要说清:构思时先定自己的主张,成文时按书A 的漏斗结构排布引用。
2. 书B 给出的"只上传引言和综述部分查重"是基于国内工具泄露风险的建议;若期刊自带 iThenticate 全稿查重,则全文都会被检,skill 中应提醒作者全文自查而不是只查一部分。
3. 书B 说"机理不明时实验至少复现三次"——这是经验法则而非通用标准,不宜作为 skill 的硬规则,可作为审稿视角的提示。
4. 书B 关于"同一段落讲一篇文献时段首段尾标注即可"的做法,与某些期刊要求每句标注的规范可能不一致;skill 应以目标期刊规范为准,书B 的做法作为默认下限。
5. 书B 的 28 条准则译自 Roig 的指南,部分条款措辞是原文直译(如准则 6 "全面掌握原文语言"),本笔记已按主题重组,后续 references 中应避免按原编号逐条复述。
6. 书A 未讨论伦理与署名问题(待读书A 笔记确认),本章内容可能是 `11-ethics-and-readers.md` 的唯一来源,需结合 ICMJE 公开指南补充可检查项。
