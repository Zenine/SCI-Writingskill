# 书B 第6章 动词作为写作的支柱

> 来源:书B 第6章(书页 119–154,PNG bookB-133–168)

## 核心主张(3–7 条,自己的话)

1. 动词是句子的"发动机":一句话是否清晰、准确、简洁,首先取决于动词选得对不对。中国作者的通病是迷信抽象名词、复杂句法和修辞,把动词"藏"进名词和介词里,结果读者只能猜。
2. 学术论文里的专业术语已经是名词密度极高的信息,句子的其余部分应尽量用简单、精准的动词把术语串起来,而不是再叠加更多名词。
3. 时态只有两个主用法:**现在时讲被学界接受的"事实"**(教科书式陈述、机器如何工作、图表展示了什么),**过去时讲"写论文之前做过的事和观察到的现象"**(方法步骤、自己的实验结果、前人某项具体研究)。现在完成时用于"长期以来被认为/此前工作一直受限"这类跨时段的陈述。
4. 语态的决定比时态简单:**除方法部分外一律优先主动语态**(用 we);方法部分的过程描述按惯例用被动+过去时,只有主宾关系天然需要被动时才用被动。"学术写作不能出现 we"是 19 世纪的旧观念,当代期刊已不坚持。
5. 学术写作与创意写作的动词逻辑相反:创意写作鼓励换词避免重复,学术写作要求**找到最准确的动词然后一直重复它**;换同义词会让读者怀疑"作者是不是想表达不同意思"。
6. 五类"偷懒"写法要主动清理:there be 句型、to be/to do/to have 三个懒惰动词、名词化(determination 而非 determined)、模糊介词 of/by/with、双重不定式 to…to…。它们的共同后果是动作主体和逻辑关系被隐藏,读者被迫推测。
7. 中式英语的根源是先用汉语逻辑(重主题、多名词、多"能")组织观点再翻译。悬垂修饰语、错误动名词搭配、can/could 滥用、层层叠加的委婉表达都来自这一步;修正办法是回到"主语+动词"结构,并通过大量阅读本领域论文建立动词语感。

## 结构模型 / 模板(用自己的话描述每种模型的适用场景、步骤、判断标准)

### 模型 A:时态选择的"两问法"

- 问 1:这句话说的是"被学界接受的事实/规律/图表内容"还是"某人在某时做过/观察过的事"?前者现在时,后者过去时。
- 问 2:如果是"观察",这个观察是长期一直成立、跨越到现在(has long been viewed / has been limited)吗?是则现在完成时。
- 按论文分段的默认值:引言=现在时为主(学术常识),引述前人具体工作=过去时或现在完成时;方法=过去时(过程)+ 现在时(描述系统/设备如何工作);结果=过去时(我们观察到)+ 现在时(图表展示、被接受的解释);讨论=混用,视"事实"还是"本研究发现"而定;进行时偶见于引言与讨论(描述一段时间内正在发生的趋势)。
- 判断标准:同一段内,凡是"我们做了"的动作不能用现在时(即使某些已发表论文这么写,也不宜模仿)。

### 模型 B:语态选择的"先主动、再看是否需要被动"

1. 默认主动:明确写出谁做了什么(we investigated / a recent study demonstrated)。
2. 方法部分的过程描述改为被动+过去时,因为读者已知操作者是作者,被动能把注意力聚焦到实验设计本身。
3. 只有当主语本身就是动作承受者且施动者不重要时才在其他部分用被动(溶液被泵送、蛋白被分离)。
4. 自检:句中若出现 it was found / it needed to be… 这类无主语被动,问一句"谁发现的?"——若上下文回答不了,改主动并补主语。

### 模型 C:动词"去懒"四步清理法

1. 扫描 there be、is/are/was、have/has、do/did、名词化词尾(-tion/-ment/-ing/-ity/-ness)和介词串 of/by/with/in/at。
2. 对每一处问:动作是什么?主体是谁?
3. 把动作还原为一个精确动词,把主体放回主语位置;介词能换成分词或动词短语(using / containing / characterized by / derived from / located at / issued by)就换。
4. 否定形式优先用带否定含义的动词(fail to / lack / yield no / allocate little),而不是 did not + 懒惰动词;确实需要 did not 时保留(如"我们没有测 A,而是测了 B")。

### 模型 D:目的句的单不定式结构

- 结果段落开头常用"To + 动词, we + 动词"说明后续实验目的。规则:一句只能有一个表目的的 to;方法手段移到句末用 using / by + -ing 表达。
- 三个以上不定式时,把最终目的留作 to,主句改为主动动词,其余变成 by -ing / in the presence of。

### 模型 E:动词 + that 的"指示 vs 汇报"

- 指示类:说图表/表格在哪里(shown in Fig. / listed in Table / Table 3 provides)。
- 汇报类:交代事实或发现,必须紧跟 that 引导完整从句(show that / indicate that / confirm that / suggest that / demonstrate that / report that)。
- 判断标准:如果动词后面跟的是名词短语(indicated the distinction / confirm the roles),读者会以为你在指某处,应改为 that 从句并补齐"谁怎么样"。

### 模型 F:强度阶梯与委婉的"单点选择"

- suggest / indicate(弱)< strongly suggest / clearly indicate < show / display(强)< demonstrate < prove(极强,除数学证明外基本不用)。
- 一句话只选一个强度点,不再叠加 possibly / might / perhaps / putative / we believe;动词自带强度,副词与形容词通常是多余的。

## 语法与语言要点(每个小节一条「错误模式 → 修正原则 → 一个你自己写的英文对比例」)

### 6.2.1 时态
- 错误模式:把写论文前做过的步骤写成现在时。
- 修正原则:动作发生在写作之前 → 过去时;规律性事实 → 现在时。
- 对比例:✗ We train the classifier on 800 scans and evaluate it on 200. → ✓ We trained the classifier on 800 scans and evaluated it on 200. (但:The classifier outputs a probability map. 现在时,因为这是系统固有行为。)

### 6.2.2 语态
- 错误模式:为"显得客观"而全篇被动,施动者不明。
- 修正原则:方法过程用被动+过去时;其他部分主动,明确主语。
- 对比例:✗ It was decided that the threshold should be lowered. → ✓ We lowered the threshold because the initial recall was below 0.8.

### 6.2.3 主谓一致
- 错误模式:动词跟着离它最近的名词变化,而不是跟着真正的主语。
- 修正原则:先找出主语中心词(去掉 of / with 引导的修饰),再定单复数;拼写检查工具能抓一部分。
- 对比例:✗ The set of validation images were annotated twice. → ✓ The set of validation images was annotated twice.

### 6.3.1 非学术动词
- 错误模式:口语化的短语动词(get / look for / find out / carry out 一类)。
- 修正原则:换成来源于拉丁/法语的单词动词(obtain / identify / determine / perform);具体用哪个看本领域论文的高频用法。
- 对比例:✗ We looked for markers that could tell apart the two groups. → ✓ We identified markers that discriminated between the two groups.

### 6.3.2 there be
- 错误模式:用 there is/are 起句,再挂一个抽象名词。
- 修正原则:删掉 there be,让承载动作的名词变回动词并找回主语。
- 对比例:✗ There was a significant reduction of false positives after calibration. → ✓ Calibration significantly reduced false positives.

### 6.3.3 不必要地更换动词
- 错误模式:为避免重复,同一动作轮流用 shows / depicts / illustrates / displays。
- 修正原则:同一含义用同一个动词,重复是准确性的体现。
- 对比例:✗ Table 1 lists…; Table 2 presents…; Table 3 depicts… → ✓ Table 1 lists…; Table 2 lists…; Table 3 lists…

### 6.4.1 过度名词化
- 错误模式:把动词/形容词改成 -tion / -ment / -ity 名词,再用 of 串起来。
- 修正原则:找到名词里藏的动作,还原为动词并给它主语。
- 对比例:✗ The improvement of segmentation accuracy was achieved through the utilization of attention. → ✓ Attention improved segmentation accuracy.

### 6.4.2 懒惰动词 to be / to do / to have
- 错误模式:用 is / has / was done 描述关系或数值,含义模糊。
- 修正原则:换成描述具体关系的动词(range from / contain / constitute / exhibit / perform);否定式用 fail to / lack / yield no。
- 对比例:✗ The model has a high sensitivity but does not have good specificity. → ✓ The model achieves high sensitivity but lacks specificity.

### 6.4.3 "is + 形容词"是合理例外
- 错误模式:用 people / researchers / scientists must… 泛指人群。
- 修正原则:若本领域不习惯以人群作主语,用 it is essential / vital / critical / paramount to… 替代。
- 对比例:✗ Clinicians must have a way to verify model outputs. → ✓ It is essential to verify model outputs before clinical use.

### 6.4.4 模糊介词 of / by / with(以及 in / at)
- 错误模式:名词 1 + with + 名词 2,读者无法判断 with 是"使用""含有"还是"伴随"。
- 修正原则:用分词或动词短语明确关系:using / containing / characterized by / combined with / derived from / located at / provided by。
- 对比例:✗ We built a pipeline with three encoders with different resolutions. → ✓ We built a pipeline containing three encoders that operate at different resolutions.

### 6.4.5 双重不定式
- 错误模式:To assess…, X was used to measure… to compare…
- 修正原则:一句只留一个目的 to;手段移到句末用 using / by -ing。
- 对比例:✗ To assess robustness, noise was added to test whether accuracy would drop. → ✓ To assess robustness, we measured accuracy after adding noise to the inputs.

### 6.4.6 动词 + that
- 错误模式:汇报类动词后跟名词短语(indicated the difference / confirm the role)。
- 修正原则:汇报事实必须 that + 完整从句;指示图表位置才用无 that 的结构。
- 对比例:✗ These results confirm the benefit of pretraining. → ✓ These results confirm that pretraining improves accuracy on small datasets.

### 6.5.1 悬垂修饰语
- 错误模式:句首 As / For / With / By… 短语没有动词,与主句主语无逻辑联系,读者误读为条件或因果。
- 修正原则:给修饰语加动词并确保它修饰主句主语,或把信息并入主句。
- 对比例:✗ With limited labeled data, transfer learning was adopted in this study. → ✓ Because labeled data were limited, we adopted transfer learning.

### 6.5.2 动名词搭配
- 错误模式:按汉语搭配直译(learn knowledge / discover the contribution / obtain spectroscopy)。
- 修正原则:方法类名词搭配 perform / conduct,贡献类搭配 identify / investigate / analyze;通过阅读和语料库工具核对。
- 对比例:✗ We discovered the contribution of each module. → ✓ We quantified the contribution of each module by ablation.

### 6.6.1 拐弯抹角
- 错误模式:we believe + possibly + might + putative 层层叠加。
- 修正原则:只用一个弱动词(suggest / indicate)承担委婉,其余修饰全部删除。
- 对比例:✗ We believe these data might possibly suggest a potential role of X. → ✓ These data suggest that X contributes to Y.

### 6.6.2 can / could 滥用
- 错误模式:把汉语"能/能够"直译成 can;或用 could 表示过去发生的事。
- 修正原则:观察到的事实用简单时态;can 只在"存在明确可选项"时用;若有条件限制就写明条件,而不是靠 can 暗示。
- 对比例:✗ The model can detect nodules smaller than 5 mm. → ✓ The model detected nodules smaller than 5 mm in 92% of cases.

## 高频通用短语(英文,按功能分组,每组 ≤ 8 条)

**替代非学术/懒惰动词的精确动词**
- obtain / acquire (data, samples)
- perform / conduct (an assay, an experiment, an analysis)
- identify / determine / quantify
- constitute / represent / comprise
- exhibit / display (a property)
- contain / range from … to …
- yield / generate (results)
- lack / fail to

**汇报结果(必须接 that 从句)**
- Our results show that …
- These findings indicate that …
- The data suggest that …
- This analysis confirms that …
- Previous work demonstrated that …
- A recent study reported that …

**指示图表位置(不接 that)**
- … is shown in Fig. 2
- … are listed in Table 1
- Table 3 summarizes …
- Fig. 4 presents …

**表目的与手段(避免双重不定式)**
- To evaluate …, we measured … using …
- To test whether …, we compared … by -ing …
- We achieved … by -ing …

**替代模糊介词的分词/动词短语**
- using / employing
- containing / comprising
- characterized by
- derived from / obtained from
- located at / positioned at
- provided by / issued by
- combined with / together with

**"is + 形容词"替代人群主语**
- It is essential / critical / vital to …
- It is paramount to …
- It remains unclear whether …

**否定含义动词(替代 did not + 懒惰动词)**
- failed to yield / failed to support
- lacked convincing evidence
- yielded no significant difference
- allocated little / received few
- is contrary to / is inconsistent with

## 可直接转化为 skill 规则的条目(每条一句,可检查)

1. Methods 中的操作步骤用过去时+被动为主;描述设备/系统/算法固有行为用现在时。
2. 引言中陈述学界共识用现在时,引述某项具体前人研究用过去时,描述"长期以来/迄今为止"的状态用现在完成时。
3. 除 Methods 外的所有段落默认主动语态,允许并鼓励使用 we;出现 it was found / it is suggested 这类无主语被动时必须补出施动者。
4. 每个句子先定位真正的主语中心词再校对动词单复数;of / with 后的名词不决定动词形式。
5. 禁止 there is / there are 起句;改为"主语 + 精确动词"。
6. 同一含义的动作在全文使用同一个动词(如所有图表引用统一用 shows),不为避免重复而换同义词。
7. 检测 -tion / -ment / -ity / -ness / -ing 名词化并还原为动词;一句话中 of 超过两个时强制重写。
8. is / are / has / have / do / did 不得作为主要动词描述数值、关系或性质;替换为 range from / contain / constitute / exhibit / perform 等。
9. 否定陈述优先用 fail to / lack / yield no / little / few;仅在陈述"未做某事而做了另一事"时保留 did not。
10. 名词 + with / of / by / in / at + 名词的结构必须能被明确替换为 using / containing / characterized by / derived from / located at / provided by 之一,否则重写。
11. 一个句子只允许一个表目的的不定式 to;手段用 using / by -ing 放句末。
12. show / indicate / suggest / confirm / demonstrate / report 用于汇报发现时必须紧跟 that + 完整从句。
13. 句首以 As / For / With / By / Based on 开头的短语必须含动词或与主句主语明确对应;否则并入主句。
14. can / could 仅在列举明确可选项时使用;描述已观察到的事实用简单时态,有条件限制时写出条件。
15. 一句话只保留一个委婉层级:选一个动词(suggest / indicate / show / demonstrate),删除 possibly / might / perhaps / putative / we believe 的叠加。
16. prove 仅用于数学证明;经验研究结论最高用 demonstrate。
17. 动名词搭配对照本领域高频用法:方法/技术名词配 perform / conduct,贡献/作用名词配 identify / investigate / quantify。
18. 遇到口语化短语动词(get / look for / find out / come up with / set up / carry out)时替换为单词动词(obtain / identify / determine / propose / establish / perform)。

## 疑问 / 与书A可能冲突处

1. **主动语态与 we 的尺度**:本章强调"除方法外全部主动、鼓励用 we",并把"不能出现 I/We"归为过时观念;书A(Glasman-Deal)在 Methods 单元更倾向被动为主、在 Results/Discussion 中对 we 的态度较中性。合成 reference 时建议:Methods 被动为主(两书一致),其余段落"主动优先但不强制",并提示按目标期刊近三年论文核对。
2. **Results 的时态**:本章表 6.1 把"研究结果"同时列在现在时和过去时下,练习题也把"Results often use present tense"作为判断题;书A 更明确区分"报告自己的数据用过去时、指向图表用现在时"。skill 规则采用书A 的可检查表述(规则 1、2 的写法已按此处理),本章作为补充说明"被接受的解释可用现在时"。
3. **同一动词重复使用**:本章主张"一个动词用到底";书A 提供了大量同义动词表供替换。两者并不真正矛盾——书A 的词表是"按含义细分"而非"为了变化",合成时应明确"只在含义确实不同时换词"。
4. **can 的态度**:本章几乎禁用 can/could;书A 在 Discussion 单元把 can/could/may 作为常规委婉手段列出。建议 skill 采用折中:描述本研究观察到的事实不用 can;在 Discussion 推断普适能力时可用 can,但优先 may / is able to 并写出条件。
5. **"is + 形容词"与懒惰动词 to be 的边界**:本章既反对 to be 又允许 it is vital to…;需要在 skill 中明确"is + 评价性形容词 + to 不定式"是允许的固定结构,避免规则 8 被误用来删除它。
6. 本章多处依赖"阅读本领域论文建立语感",无法完全转化为可检查规则;skill 中可用"给出 3 篇目标期刊论文中的同类句"作为替代验证方式。
