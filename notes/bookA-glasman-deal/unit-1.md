# 书A 第1单元 怎么写引言

> 来源:书A 第一单元(PDF 页 40–138;其中 1.1–1.2 模板 42–61,1.3 验证 61–102,1.4 词汇 102–112,1.5 语言技巧 112–134,1.6 写作练习 134–138)

## 核心主张(3–7 条,自己的话)

1. **引言与讨论是镜像。** 全文结构像一个沙漏:引言由宽到窄(领域 → 问题 → 本文),讨论由窄到宽(本文结果 → 对领域的贡献 → 收尾)。引言里立下的问题或空白,讨论里必须回答"解决到什么程度"。
2. **引言的功能骨架跨领域高度稳定,可压缩为四组。** 依次是:① 确立主题重要性并给背景事实;② 综述已有研究,画出"研究地图";③ 指出空白/问题/动机;④ 介绍本文做了什么。几乎所有引言以①开头、以④结束,②③的显隐程度因文而异。
3. **模板记录的是"句子在做什么",不是"句子说了什么"。** 逆向工程时描述功能(如"作者指出关键研究"),不能带内容词(如"聚合物"),否则模板无法迁移。识别功能变化的最快线索是主要动词的时态变化。
4. **时态是功能标记,不是语法义务。** 过去时、一般现在时、现在完成时三者的取舍取决于作者想让读者如何看待这条信息:当时的发现 / 永久事实 / 与现状仍相关。时态一换,信息功能就换;不要随意切换。
5. **文献综述不是阅读清单,而是通向本研究动机的叙述。** 只收与本文动机直接相关、能显示问题演化的研究;要有组织模式(一般到具体最常见;按方法/理论分类;按时间),要用连接语把研究串起来,避免"however / on the other hand"来回打乒乓。
6. **开头先给读者一个"集合点"。** 第一句通常是宽泛而公认的事实或重要性声明,不要一上来就抛具体问题(读者没有足够背景消化);背景信息宁多勿少,尤其面向跨学科读者时;开头几句之间的信息跨度不能太大。
7. **句与句、段与段的连接决定可读性。** 句间的"空白"是危险区,作者要用重叠、指代替换、分号、信号词四种手段缩小它;段落有单一功能,首句预告段落走向,读者靠略读段首句获得全文"地图"。

## 结构模型 / 模板(用自己的话描述各步骤的功能与顺序、信息流、每步常用时态,不抄例文)

### 四组通用模板(可视为菜单,不必全用)

**第 1 组:进入领域(宽口)**
- 功能:(a) 说明主题为什么重要或有用;(b) 给出理解全文所需的背景事实;(c) 说明本领域当前的一般性问题或焦点。
- 信息流:从最多读者共享的知识起步,逐步收窄;每句都比上句更具体,但不能跳跃太大。
- 时态:重要性声明若带"近年来/过去十年"等时间短语用**现在完成时**;描述当前状态用**一般现在时**;背景事实一律**一般现在时**(公认事实的标志)。
- 引用:背景事实是否加引文取决于该事实在领域内被接受的程度,判断办法是查目标期刊近年用法,而非凭感觉。
- 变体:读者群很窄的专业期刊可以省略重要性声明,直接从关键术语定义或事实入手;不知从何下笔时,看关键词——目标文章多以哪个关键词的定义/事实/重要性开头,就照做。

**第 2 组:研究地图(已有与当前研究、贡献)**
- 功能:把一般性问题与已发表工作连起来;点出关键研究;让读者看到本文在领域地图上的坐标。
- 组织模式三选一:一般 → 具体(最常用);按途径/理论/模型分组(同类研究归堆,减少来回转折);按时间(适合政策、法规类主题)。
- 时态:三种都可能出现。某研究当时的发现用**过去时**;发现已被当作稳定事实用**一般现在时**(常带引文);对现状仍有直接影响、或紧接着要引出空白时用**现在完成时**。综述部分若只是概括当前知识状态,以一般现在时为主但仍可能需要引文。
- 引文位置:若引文只支持句子的一部分,把它放在该部分之后(句中),而不是统一堆在句尾——句尾引文会被理解为"整句都来自这些文献"。
- 篇幅:每一项被提及的研究都必须是理解本文动机所必需;多作者、长周期写作容易让这部分膨胀失焦。

**第 3 组:转向本文(窄口)**
- 功能:指出已有研究的空白、缺陷、矛盾,或提出本文动机、假设、研究机会。
- 典型信号:However / Although / Despite / while / nevertheless 引出转折;情态动词 may / might / could / would 表示"机会"而非断言。
- 表述方式:专业写作很少用问句抛出问题,通常把问题写成待验证的假设或建议;批评前人用客观、克制的措辞即可,不必回避。
- 时态:指出"至今仍未解决"的空白用**现在完成时**(尤其否定形式:little attention has been paid / few studies have ...);若用过去时,读者会理解为"当时没人管,现在可能已经解决"。
- 此处常需补第二轮背景(更具体的材料性质、设备细节等),以一般现在时插入。

**第 4 组:介绍本文**
- 功能:说明本文/本研究做什么,可选地提及目的、方法概要、主要结果、文章结构;常带正面评价词("happy words":novel、robust、simple、effective、first、significant)。
- 时态:描述论文/研究本身用**一般现在时**(This paper presents / This study focuses on);陈述研究目的常用**一般过去时**(The aim of this work was ...),因为目的在工作开始前就定了;若目标只部分达成,也可用一般现在时。
- 主语三选一:we/our;被动;非人称主语(This paper / This study / Section 2)。选择依据是目标期刊风格和指代是否清晰。
- 长度控制:方法和结果只点到为止,展开过多会让引言失焦。

### 写作前的规划清单
- 先按段落规划整篇引言,再写句子。
- 引言中立的问题/空白必须与讨论、结论一致。
- 开头不要从很宽泛跳到很具体;熟悉课题的作者最容易低估读者对背景的需求。
- 控制信息密度:用举例、分段、拆长句来让眼睛的阅读速度和大脑的处理速度匹配。
- 每段、每句的开头方式在敲键盘之前想好。
- 为读者写,不为同事写。

## 语法与语言要点

**1. 三种时态的取舍(1.5.1)**
- 过去时 vs 一般现在时:报告他人发现时,过去时=这是他们当时观察到的;一般现在时=作者相信这已是可靠的永久事实。许多现在时的背景事实,最初都是以过去时报告的发现,随着接受度提高逐渐"升级"。因此五年前论文的时态可能已过时,沿用会显得不了解领域现状。查现状的办法:在 Google Scholar 等工具中只看最新文献里该事实的写法。
- 过去时 vs 现在完成时:区别不在事件发生时间,而在与"现在"的相关度。现在完成时把一件事拉到当下,所以最适合引出本文要处理的空白;过去时则把它留在过去。
- 时态切换永远有含义;不确定时对照目标文章。

**2. 句子连接的四种方法(1.5.2)**
- **重叠**:下一句开头重复上一句结尾的词或概念。
- **替代指代**:This method / These systems / Such approaches 等指回前文;指代名词应与首次出现时用同一个名词(说了 a device 就写 this device,不要换成 this technique)。裸用 This / It / They 开头容易指代不清(This 指前一句的哪一半?They 指哪个名词?)。
- **分号**:两句关系极紧且其中一句很短时,用分号代替句号;但要检查合并后的总长度。
- **信号词**:therefore / however / moreover 等直接告诉读者本句功能;用错比不用更糟。Moreover 意味着本句与上句功能相同(上句给理由,本句也必须给理由);Therefore / Consequently 后面必须是读者能看出因果的结果,因果链若只在作者脑中,先补信息再用。
- 不必每句都以信号词开头,那样显得公式化且过度强调;优先用重复连接。

**3. 信号词按功能分类(仅收当前 STEMM 写作常见者,注意易混项)**
- 原因:because / since / as / due to (the fact that) / on account of / in view of。注意 as 也可表 when,since 也可表 from that time,有歧义时换词。
- 结果:therefore / hence / thus / consequently / as a result / so。
- 对比(不同):however / whereas / while / by contrast / in contrast / on the other hand / but。on the contrary 与 conversely 表示"恰好相反",不是一般的"不同",不可混用;while 也可表 at the same time,有歧义时用 whereas。
- 意外(让步):although / even though / though 接从句;despite / in spite of / regardless of / notwithstanding 接名词;nevertheless / nonetheless / even so / yet / however 接独立句。however 和 but 既可表对比也可表意外,要强调意外时选别的。
- 并列/列举:in addition / moreover / furthermore / also / secondly。besides 语气更强,留给论辩性更强的语境。
- 过渡:with regard to / with respect to / regarding / as to / as for / turning now to。

**4. 主动、被动与非人称主语(1.5.3)**
- 先查目标期刊。科技写作传统上偏被动(显得客观),方法节尤其如此,但跨学科和新兴领域越来越接受主动。
- we/our 的风险是指代漂移:同一篇里 we 可能是"本文作者"、"本领域所有人"、"泛指任何人"。若想表达泛指,改用 It is known / thought that ...。
- 第三条路是让论文或章节做主语:This paper describes / This study presents / Section 2 reviews。

**5. 分段(1.5.4)**
- 段落是强烈的视觉信号,读者一见新段就准备"换话题";一连串单句段落会滥用这个信号,超长段落则是作者忘了读者在"倾倒"信息。
- 研究论文段落平均约 150–170 词,少于 80 或多于 230 词的段落不应占多数。
- 段落有单一功能(给背景、比较技术、说明为何同意某观点、给详细例子……),段内每句都推动该功能。
- 首句是"入口句",承担段落主题/功能/目的;读者略读时只看段首句,所以段首句串起来应是全文地图。略读的常规顺序:标题 → 日期与作者 → 摘要/亮点 → 图表 → 小标题与各段首句 → 结论。
- 策略:列主题并排序 → 列每个主题下的要点并排序 → 估每个主题需要几段 → 检查每段有功能 → 确保功能对读者可见 → 用连接策略或明确的段首短语开段。

**6. 句长**
- 首读时约 90% 的读者能理解 20 词以内的句子,只有约 10% 能理解 40 词以上的句子;STEMM 论文平均句长约 23 词。用分号合并句子后要重新检查句长。

## 高频通用短语(英文,按功能分组,每组 ≤ 8 条,只收通用学术短语,不收书中例文的具体句子)

**确立重要性 / 开篇(常配现在完成时或一般现在时)**
- has attracted much attention in recent years
- has been extensively studied
- plays a key role in
- is widely used in
- is of growing interest
- a central problem in
- during the past two decades
- an emerging technology

**串联已有研究(研究地图)**
- were the first to
- a pioneering study by [ref] demonstrated
- a similar approach was used by [ref], who
- an alternative approach was proposed by [ref], who
- this approach was further developed by [ref]
- to address this issue, [ref]
- taken together, these studies suggest that
- it was later shown by [ref] that

**描述前人具体做了什么(替代 they did/showed/found 的精确动词)**
- investigated / examined / analysed
- developed / proposed / put forward
- demonstrated / established / confirmed
- measured / monitored / calculated
- identified / characterised / categorised
- evaluated / assessed / compared
- reported / described / reviewed
- predicted / modelled / estimated

**指出问题 / 缺陷(常由 however / although / despite 引出)**
- a major drawback of ... is
- suffers from
- fails to
- is limited by / is confined to
- is not sufficiently
- is time-consuming and costly
- remains controversial
- has been largely unsuccessful

**指出空白 / 研究机会(常配 may / might / could)**
- little is known about
- little attention has been paid to
- few studies have
- remains unclear / poorly understood
- has not been addressed
- to the best of our knowledge
- there is an urgent need for
- more work is needed to

**介绍本文(一般现在时;目的可用过去时)**
- in this paper, we present / propose / report
- this study focuses on
- the aim of this work was to
- to address this question, we investigated
- here, we describe
- this paper is organised as follows
- our approach enables
- we show that

**正面评价词("happy words")**
- novel / new
- robust
- simple and accurate
- effective / efficient
- promising / powerful
- the first demonstration of
- superior / unique
- fully integrated

**段首入口短语**
- an alternative approach is
- another key feature is
- on the basis of this finding
- in order to explore this
- this is important because
- these data suggest that
- turning now to
- with regard to

## 可直接转化为 skill 规则的条目(每条一句,可检查)

1. 引言必须能按顺序标出四组功能:重要性/背景 → 研究地图 → 空白/动机 → 本文;第一组必须在开头,第四组必须在结尾。
2. 引言第一段以宽泛的公认事实或重要性声明开头,不以本文要解决的具体问题开头。
3. 背景事实用一般现在时;带"in recent years / over the past decade"等时间短语的重要性声明用现在完成时。
4. 开头几句之间不得出现从"很宽"到"很窄"的跳跃;每句只比上句具体一步。
5. 若重要性声明依赖具体数字或"当前"状态,加上可识别年份(如 since 2018),避免几年后失效。
6. 报告某研究当时的发现用一般过去时;报告已被领域接受为事实的结论用一般现在时;引出仍未解决、与本文直接相关的空白用现在完成时。
7. 同一句内时态切换必须对应功能切换;检查方式:凡时态改变处,能说出"前后功能有何不同"。
8. 引言中每一项被引研究都要能回答"它如何通向本文动机";答不出的删除。
9. 文献综述必须采用明确的组织模式(一般到具体 / 按方法分类 / 按时间),同类研究归为一组,不允许逐句 however 来回转折。
10. 引文只支持句子一部分时,放在该部分之后,不统一放句尾。
11. 空白/问题用陈述句(待验证的假设或建议)表达,不用问句;例外仅当目标期刊惯例允许。
12. 空白句典型形式为否定+现在完成时(little attention has been paid / few studies have),并由 however / although / despite 等信号引出。
13. 介绍本文时,描述论文本身用一般现在时,陈述研究目的可用一般过去时;方法与结果在引言中只做一句概述。
14. 本文介绍句中至少含一个正面评价词(novel / robust / first 等),但强度须与结果匹配。
15. 主语策略三选一(we / 被动 / This paper 类非人称主语),全篇 we 的指代对象必须固定为"本文作者";泛指时改用 It is known that 等结构。
16. 每个句子开头必须与上一句显式相连(重叠、指代、分号或信号词之一);用 This / It / They 开头时其指代对象必须唯一。
17. 指代前文事物时使用首次出现的同一名词,不换同义词。
18. 使用 therefore / consequently 前,原因必须已在前文明示;使用 moreover / furthermore 时,本句功能必须与上句相同。
19. as、since、while 存在歧义(when / from that time / at the same time)时,替换为 because、whereas 等无歧义信号词。
20. on the contrary / conversely 只用于"恰好相反",不用于一般对比。
21. 句长目标:平均约 20–25 词,超过 40 词的句子应拆分。
22. 段落长度目标:约 80–230 词;不得出现连续的单句段落。
23. 每段只承担一个功能,首句预告该功能;检查方式:只读各段首句能否复述引言脉络。
24. 引言中提出的问题/空白必须在讨论或结论中被回应,两处措辞应可一一对应。
25. 写引言前先按段落列出功能清单,再写句子。

## 疑问 / 与书B可能冲突处

- **"重要性声明"是否必须。** 书A说几乎所有引言以此开头,但也承认窄读者群期刊可以省略;书B若对国内作者常投的期刊给出不同起手式(如直接从临床/工程问题切入),需两说并存,以目标期刊为准。
- **研究目的的时态。** 书A允许 "The aim of this work was ..." 用过去时,也允许现在时;许多写作教材统一要求现在时。规则 13 写成"可用"而非"必须",合成 references 时看书B是否有硬性要求。
- **主动 vs 被动。** 书A立场是"看期刊、看歧义",不偏袒任一方;书B(2024,面向中国作者)可能更明确鼓励主动语态。冲突时以"指代是否清晰"这一可检查标准为主,风格偏好为辅。
- **句长与段长数字。** 书A给出平均句长约 23 词、段落 150–170 词等经验值;书B若给出不同阈值,需在 references 中标注来源和两说。
- **空白不用问句。** 书A称专业写作很少用问句引空白,但其示例引言中就出现过"以下问题将被回答:(a)…(b)…"的列表式写法;这说明"列出研究问题"与"用问句引空白"是两回事,规则 11 需保留这个例外。
- **引言是否预告主要结果。** 书A第四组允许在引言末尾宣布主要结果并配正面评价词;部分期刊或书B可能要求引言只写目的、不写结果,以免与摘要重复。需要在 references 中标注"看目标期刊"。
- **"happy words" 的强度。** 书A鼓励大胆说自己的研究重要;书B或国内审稿文化可能更强调克制。规则 14 已加"强度须与结果匹配"作为折中,合成时再核对。
