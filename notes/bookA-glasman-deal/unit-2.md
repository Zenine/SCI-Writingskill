# 书A 第二单元 怎么写方法
> 来源:书A 第二单元(PDF 页 140–231;正文从 p142 起,p232 起为第三单元)

## 核心主张(3–7 条,自己的话)

1. 方法部分的名称五花八门(Methods / Materials and methods / Experimental / Methodology / Model / Simulations 等),但功能只有一个:给出足够细节,让同行能复现并得到相近结果。名称、篇幅、放正文还是放补充材料,一律以目标期刊的目标论文为准。
2. 实验记录是写给自己的,方法部分是写给读者的。读者不只要知道"做了什么",还要知道"为什么这样做";不解释理由,读者就可能不接受方法,进而不接受结果。
3. 先给整体框架再给细节("先展示整堵墙,再谈砖块"):以概述句或材料来源开头,避免一上来就抛高度具体的操作细节,否则每个读者会拼出不同版本的理解。
4. 方法部分并非纯客观描述,而带有说服成分:通过"理由语言"(in order to、to ensure)、"谨慎语言"(carefully、thoroughly)和"优势语言"(accurate、robust)让读者相信作者是称职、细心、可靠的研究者。
5. 方法与文献的比较是全文主线的一部分:方法可能与引用文献完全相同、相似或有本质差异;若差异是本文的关键贡献,必须明确指出差异在哪。
6. 问题与局限应在首次出现处(方法部分)就提及,再于文末回应;等到结论才第一次暴露问题会损害读者信心。提法上要淡化影响、降低责任、给出解决方向。
7. 无施动者被动语态 + 时态误用会造成"归属歧义":读者分不清是你做的、别人做的还是标准流程。写完必须逐句核查时态是否表达了想要的功能。

## 结构模型 / 模板

书 A 把方法部分归纳为 6 个组件。与引言不同,这 6 项是"菜单"而非必选序列,按研究类型和目标期刊惯例挑选组合;各组件之间可以交错出现,理由/谨慎/优势语言是贯穿全篇的"调味",而不是独立段落。

| 序号 | 组件功能 | 信息流作用 | 常用时态 |
|---|---|---|---|
| 1 | 方法总览/引入:概述做了什么、用了什么、目的是什么;或重述引言中的目标/空白;或先交代材料与设备来源 | 建立顶层框架,让作者与读者共享同一张"地图" | 一般过去时(做了什么);若重述目标可用过去时或现在时 |
| 2 | 材料与方法细节:参数、温度、顺序、设备型号,±理由,±谨慎措辞 | 主体,占篇幅最大;用精确的顺序词交代步骤先后与时长 | 一般过去时(无施动者被动为主,也可主动) |
| 3 | 描述/讨论图表内容(装置图、流程图、样本表等) | 把图像纳入叙述 | 一般现在时(图里"显示"什么) |
| 4 | 参照其他研究的材料与方法:相同 / 相似 / 有本质差异,并证明自己选择的合理性 | 把本文方法定位到文献地图上 | 描述别人已建立的方法用现在时;自己怎么改用过去时 |
| 5 | 背景事实信息:材料属性、设备原理、地区特征等,用于帮助读者理解或为选择辩护 | 支撑读者,填补读者可能缺失的知识 | 一般现在时 |
| 6 | 指出问题或困难 | 显示作者自知之明;为文末"未来工作"埋线 | 一般过去时;解决方向用 should/will |

三种常见开头方式:
- 列出研究参数做总览(测试数量、材料、设备、目的);
- 先给材料/设备的来源或背景属性;
- 回指前文(引言目标或待解决问题)。

对"何时该从材料细节直接开头"的判断:只有当期刊读者面窄、且所有可能读者都熟悉该方法时才可以;否则先引入。

段落层面:每个小节/段落通常以"段落输入句"(概述句,如 In all cases / Most of the tests)开头,再自上而下展开细节。

背景信息给多少:用两个问题判断——所有潜在读者都已知道这个方法吗?要理解我的具体做法他们还需要知道什么?答案来自目标论文,而非自己的感觉;考虑到搜索引擎带来的跨学科读者,宁多勿少。

引用已有方法的处理:众所周知的方法仍需给引用;但不能只丢一个引用就要求读者自己去查——常见做法是"按 [n] 进行,简述如下:..."。方法随着普及,引用频率会递减直至成为常识背景。引文位置要小心,放错位置会把工作误归给别人或误归给自己。

结尾:书 A 未给方法部分固定的结尾组件;常见做法是以最后一个流程步骤、数据分析/统计方法、或指出局限收束。

## 语法与语言要点

**1. 时态与"所有权"**
- 一般过去时 = 报告本研究做了什么;一般现在时 = 描述标准流程、设备工作原理、已建立的方法。两者在无施动者被动中形态仅差一个助动词,却决定了工作归属。
- 消除歧义的三招:改主动语态(we collected);加定位词(here / in this work / in our model / in their study);用"伪主语"(This procedure / The probe used in their study)。
- 若领域惯例整篇用现在时(如数学模型、算法描述),同样要用定位词或主动语态标明哪些是本文贡献。
- 图中所示的装置若是本文的,要写明(The setup used here is shown in Fig. 3),不能让读者猜。

**2. 顺序语言(8 组,按时间关系分类)**
then / next 只表先后,不表间隔时长,复现时信息不足。要按功能选词:
- 开始之前:beforehand, previously, prior to, in advance
- 起点/第一步:initially, at the start, firstly, to begin with
- 单纯先后:subsequently, followed by, after, afterwards
- 短暂间隔后:shortly after, soon, quickly
- 较长间隔后/接近末尾:eventually, later, in due course, towards the end
- 同时/紧接(可暗示因果):as soon as, once, when, while, simultaneously, immediately, at that point
- 序列结尾:finally, lastly, in the end
- 结束之后:afterwards, subsequently

**3. 介词**
- 介词改变含义:evidence of(信号已存在)vs evidence for(可能存在);substituted for vs substituted with 方向相反。
- 观察目标论文里"动词 + 介词"的固定搭配并自建列表;规律上 using 比 with 更常见,by 后面通常接 -ing 形式的过程描述。
- with 歧义最多(伴随/工具/意图/属性),by 表过程、无意图;"X was coated with Y"(Y 是涂料)与"X was coated by doing Y"(Y 是工艺)不同。
- 句首尽量用意义明确的词替代含糊介词(Using this estimation 优于 From this estimation)。
- 避免介词短语串联:一句话里多个介词短语会互相"污染"修饰对象;拆句,把条件、目的、防护措施分开写。"This is the first study to X over Y within Z at W" 这类句子让读者分不清新颖点在哪一层。

**4. 冠词(a/an、零冠词、the)**
- 单数可数名词必须带冠词;但可数性依用法而定(industry、steel 在专业语境中可复数)。不可数名词要计数须加量词(items of equipment, types of evidence)。
- a/an:首次提及的单数可数名词;泛指某一类;读者不知道具体指哪个。
- 零冠词:复数可数名词泛指;不可数名词;首次提及的复数/不可数名词。
- the:唯一可能;前文已提;读者凭共享知识能推出(提到 computer 后 the keyboard 不需先引入)。
- a vs the 有时改变含义:a cause of(多因之一)vs the cause of(唯一原因);a connection(可能有)vs the connection(已知存在)。有时不改含义但反映对读者知识的假设——宽读者面期刊首次提及关键术语宜用 a/an 并定义,窄领域期刊可直接用 the。

**5. 谨慎与理由语言**
- 谨慎副词/形容词(carefully, thoroughly, tightly, immediately, at least three times)传达"这项工作是认真做的"。
- 理由结构:in order to / so as to / to ensure / with the aim of / for the sake of simplicity / which allowed / thereby;加上"优势词"(accurate, robust, reliable, consistent)说明选择的好处。

**6. 引用文献的 by / of / in**
- by 和 of 后面接人名或团队(described by Smith;the protocol of Smith and co-workers),in 后面接作品或文献条目(described in [12];in Smith (2020))。

## 高频通用短语(英文,按功能分组,每组 ≤ 8 条)

**材料/设备/样本来源**
- was purchased from / was obtained from / was supplied by
- was provided by / was a kind gift from
- is commercially available
- was used as received / was used as supplied
- was collected from / was acquired from

**概述句与段落输入句**
- A three-step approach was used to ...
- In all cases, ... / In most cases, ...
- The majority of the tests were ...
- The experimental system consists of ...
- An overview of the procedure is given in Fig. 1

**空间关系与装置描述**
- was positioned / mounted / attached / installed ...
- adjacent to / in close proximity to / in the vicinity of
- parallel to / perpendicular to / aligned with
- upstream of / downstream of
- on either side of / equidistant from
- was embedded in / was enclosed in / was surrounded by

**理由与优势**
- in order to / so as to / with the aim of
- to ensure ... / to prevent ... / to avoid ... / to minimise ...
- for the sake of simplicity / for brevity / for convenience
- was chosen for its ... / was selected on the basis of ...
- which allowed ... / which enabled ... / thereby ...
- This approach offers the advantage of ...

**谨慎态度**
- carefully / thoroughly / precisely / rigorously
- Care was taken to ...
- at least N times / repeatedly / independently
- immediately after ... / freshly prepared
- randomly selected / separately

**顺序(选代表)**
- prior to ... / beforehand / in advance
- initially / to begin with / at the start
- subsequently / followed by / after which
- shortly after / immediately / as soon as / once
- until ... / at which point ...
- finally / in the end / afterwards

**与已有方法的关系**
- 相同:as described by/in ... / according to ... / following X et al. / in accordance with ... / using the method of ...
- 相似:based on ... / adapted from ... / a modified version of ... / essentially the same as ... / with some modifications
- 差异:instead of ... / unlike ... / with the following modifications: / a novel step was ... / loosely based on ...

**问题与困难(三种策略)**
- 淡化问题:negligible / minor / only approximate / not significant / slightly problematic
- 降低责任:inevitably / unavoidable / it was not possible to ... / limited by ...
- 强调好的方面/给出方向:acceptable / reasonably robust / Future work should ... / Future work will ...

## 可直接转化为 skill 规则的条目(每条一句,可检查)

1. 方法部分第一句必须是总览、目标回指或材料来源之一,不得以具体操作细节开头。
2. 每个小节/段落首句应为概述性"输入句",之后再展开细节(自上而下)。
3. 每个非显而易见的方法选择(材料、设备、参数、流程)至少附一个理由或优势说明(in order to / to ensure / because ...)。
4. 描述步骤顺序时不得只用 then / next;涉及时长或间隔的步骤必须用能表达时间关系的词(prior to, until, at which point, immediately, after N min)。
5. 报告本研究所做的事用一般过去时;描述标准方法、设备原理、材料属性用一般现在时;同一句内切换时态需有功能理由。
6. 使用无施动者被动语态的句子,若可能被误读为他人工作或标准流程,必须加 here / in this study / in our model 等定位词,或改为主动语态。
7. 凡引用他人方法,必须标明关系类型:完全相同(as described in)、相似(adapted from,并可选说明改动)、有本质差异(unlike / instead of,并必须说明差异)。
8. 引用文献的位置须紧贴被引用的方法或材料,不得笼统放句末导致本文工作被误归给他人。
9. 用引用替代完整描述时,仍须给出一句概要("... was performed as in [n]; briefly, ...")。
10. 方法中已知的局限、难点或妥协必须在方法部分提及,并用淡化/去责/给出解决方向三种策略之一措辞;不得留到讨论或结论才首次出现。
11. 材料、样品、设备、软件必须给出来源(供应商/厂家/型号/版本),并区分"购得/获赠/自制/按标准制备"。
12. 一句话内不得出现 3 个以上互相修饰的介词短语;超出则拆句。
13. 描述过程时优先 using + 工具、by + doing 的搭配;避免用 with 表达工具或过程。
14. 首次提及的单数可数名词用 a/an 或作定义;宽读者面期刊首次出现的关键术语不得直接用 the。
15. 图表若是本文的装置/流程,正文须明确写为本文所用(the setup used in this study),不得只写 "is shown in Fig. n"。
16. 单位、缩写、符号(如 mL vs ml)按目标期刊或 SI 现行版本统一。
17. 方法部分篇幅和正文/补充材料的分配比例向目标期刊近期同类论文看齐。
18. 写完后逐句核查:该句时态是否表达了想要的功能(本文所做 / 标准流程 / 图中所示 / 他人工作)。

## 疑问 / 与书B可能冲突处

1. **被动 vs 主动**:书 A 承认主动语态在研究写作中常见,但方法部分仍以无施动者被动为主,强调靠定位词消歧;书 B(强调动词与风格)可能更倾向主动语态、第一人称。skill 需给出可检查的折中:先看目标期刊惯例,默认被动 + 定位词,允许在归属易混淆处切换为 we。
2. **理由语言的量**:书 A 要求几乎每个选择都给理由;若书 B 主张简洁、少冗词,两者会在"要不要写 in order to"上冲突。建议规则:非显而易见的选择才需理由,标准操作不必。
3. **谨慎副词(carefully, thoroughly)**:书 A 把它们当作建立可信度的手段;书 B 若把此类副词归为"无信息量的修饰词"则冲突。折中:只在确实反映了操作差异(如洗涤次数、密封方式)时使用,不做空泛装饰。
4. **方法部分的时态"整篇现在时"**:书 A 提到某些领域(模型/算法)全篇用现在时;需在 skill 中作为领域例外注明,避免与"方法用过去时"的通用规则打架。
5. **Materials and Methods 的伦理声明、统计方法位置**:书 A 模板未单列;医学 SCI 通常要求伦理批准、知情同意、统计方法为独立小节,这是 skill 必须补充而书 A 未覆盖的内容。
6. **冠词章节的可操作性**:书 A 的冠词讨论以共享知识为核心,判断依赖语境,难以写成硬规则;skill 中只能收录几条可检查的子规则(见上),其余作为提示。
7. 书 A 引述的"每年约 300 万篇论文、10 年翻番"等数字是背景陈述,不必进 skill。
