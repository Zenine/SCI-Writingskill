# 书A 第三单元 怎么写结果
> 来源:书A 第三单元(PDF 页 232–297;正文从 p234 起,p298 起为第四单元)

## 核心主张(3–7 条,自己的话)

1. 结果 / 讨论 / 结论如何分合(Results + Discussion + Conclusion;Results and Discussion;等)由目标期刊和研究本身决定:初步结果影响后续结果时宜合写,多假设各自对应结果时宜分小节,想整体讨论时宜分开。书 A 为训练目的把三者分开讲。
2. "结果部分只写事实、不许解读、只用过去时"这类规定性建议与已发表论文的实际做法不符;逆向工程目标论文比遵守教条更可靠,而且随着方法越来越多地被移入补充材料,结果部分正在承担更多方法信息。
3. 数据和图表不会自己说话。结果部分不是结果的清单,而是一份"读结果的导览":作者要用评价性语言固定读者对数字大小、趋势方向、重要程度的理解,否则读者会得出与作者不同的解读,结论就显得突兀。
4. 不要按实验发生的时间顺序罗列结果;要按叙述逻辑组织,让读者与作者一起"发现"重要结果。先给整体模式或趋势的概述,再进入关键结果的细节。
5. 结果部分与文献的比较是全文主线的延续:与前人结果、与预测、与模型/模拟的比较,把本文定位在研究地图上,为讨论铺路。
6. 问题和缺口要在结果部分承认,并用淡化影响、暗示原因、指向解决方案的语言处理;这同时为讨论/结论中的"未来工作"提供素材。
7. 结果的"含义"几乎总会在结果部分被简短提及(suggest / indicate),完整展开留给讨论;提及含义时要把措辞放到"确定性连续统"上合适的位置。

## 结构模型 / 模板

书 A 的通用结果模板分 4 个层次,12 种句子功能。与方法模板一样,它是菜单,不是每篇都要全用;顺序上"回顾—展示—评论—含义"是主流的信息流。

| 层次 | 组件功能 | 信息流作用 | 常用时态 |
|---|---|---|---|
| 1 开场 | (a) 回顾文献/目的/预测/假设/研究空白;(b) 回顾或概述本研究方法;(c) 对结果整体模式的宽泛陈述;(d) 邀请读者看图并说明图里是什么 | 让跳读的读者(从标题/摘要直接跳到结果的人)与通读者站在同一起点;搭建看"砖块"前的"墙" | 回顾前人:过去时/现在完成时;本文方法:过去时;概述图内容:现在时(Fig. 1 shows) |
| 2 主体 | (e) 具体/关键结果 ± 评价性语言与评论;(f) 与其他研究结果比较;(g) 与模型/模拟/预测比较;(h) 用已知事实或方法细节解释结果是怎么得到的、为何如此 | 挑选重要结果重点写,其余略写,以此传达轻重;比较把结果定位到文献;解释限于对数据的直接说明 | 本文发现:过去时;图中可见:现在时;背景事实:现在时;归因于方法:过去时 |
| 3 问题 | (i) 结果中的问题/缺陷 ± 原因 | 显示作者掌控全局;埋下未来工作 | 过去时;去责/淡化词 |
| 4 收束 | (j) 结果的可能含义/应用,用积极词汇回应引言目标 | 把焦点从"报告"转向"讨论",打开通往讨论部分的路 | suggest / indicate + may/could;现在时 |

三种常见开头:
- 概述整体趋势(In general / Overall / In most cases)并引导看汇总图表;
- 重述研究目标或问题,为评估结果设置背景;
- 回顾方法要点——方法在补充材料中或很长时尤其常见。

图表的放置与叙述:
- 读者读到"Fig. 1 shows ..."会停下看图、形成自己的解释再回到文本,因此图的位置和它前后的叙述框架必须有意设计。
- 数据清晰无歧义时可先给图后评论;有多种解读可能时,先评论再请读者看图,以免读者先入为主。
- 先用基础性图表铺垫,再引出最重要的结果,比一开始就抛最激动人心的结果更有效。

轻重处理:
- 不要对所有结果同等详细;选关键结果展开并评论,其他略写。
- 可用 Importantly, / It is noteworthy that ... 等信号显式标记重要结果。
- 常见手法:先给一个总体判断,再用 for example 引出最佳/典型的具体数值。

小节与小标题:逆向工程目标论文——小节数量、长度、每段功能、小标题长度、小标题是否为完整句(有些期刊用陈述句式小标题直接概括该节结论)。

## 语法与语言要点

**1. 客观描述 vs 主观评价**
- 客观:higher / lower / increased / peaked / remained constant,以及数值本身。
- 主观:high / low / striking / marked / considerable / only / as many as。
- 区分口诀:说 A 比 B 高是事实,说 A 本身"高"是评价。
- 已发表论文里纯客观描述很少,几乎总带主观修饰(slightly lower、much lower 而非单独的 lower),因为纯描述对读者无增量。
- 同一数字可被推向两端:"in as many as 23% of cases" 与 "in only 23% of cases"。

**2. 数量评论的五组**
- 放大数量:considerable, substantial, as many as, numerous, upwards of, well over
- 缩小数量:only, barely, scarcely, as few as, marginal, minimal, hardly
- 强调程度(比较级前):considerably, markedly, substantially, far, even, exceptionally, well (over/under)
- 表示接近/相近:approximately, roughly, close to, nearly, virtually, practically, negligible
- 不想表态的中性词:some, somewhat, relatively, fairly, moderate, to some extent, in some cases

**3. 频率的十级刻度(从高到低)**
1. always / invariably / without exception / on every occasion
2. generally / usually / normally / as a rule / habitually
3. often / frequently / commonly / regularly / repeatedly
4. more often than not
5. as often as not(中性,发生与否概率相当)
6. sometimes / at times / on some occasions
7. occasionally / from time to time / now and then
8. rarely / seldom / infrequently
9. hardly ever / almost never / scarcely ever
10. never / not once / at no time / on no occasion

注意频率是相对预期而言的:前人认为不会发生的事在本研究 22% 出现,可称 frequent;前人认为必然发生的事只出现 22%,可称 rare。不带频率修饰词的"X occurred"让读者无法评估可靠性。

**4. 句首信号词**
- 长句中的转折/评价信号(However, Unfortunately, Interestingly, Notably)放句首,不放句末;放句末会迫使读者回读整句。

**5. 情感与惊喜的表达**
- 科研写作不用感叹号,用 striking / remarkable / dramatic / unexpected 等词表达"哇"。

**6. 时态**
- 图中可见的内容用现在时;图中数据如何获得用过去时,二者常交替。
- 解释结果的背景事实(材料属性)用现在时;归因于本研究方法用过去时。
- 过去时 = 本研究发现的事实;现在时 = 作者认为该发现可靠到可作永久事实(见下文连续统)。
- 比较句的时态会随时间演变:五年前写 "X has been found to occur [n]",今天可能写 "X occurs"。
- 有的领域(如描述模型如何运行)整段用现在时,以目标论文为准。

**7. 因果动词的强弱谱**
- 直接/强因果:cause, produce, be due to, result in, give rise to
- 部分原因:contribute to, be a factor in
- 因果过程:lead to, drive, initiate
- 因果链起点:originate in, arise from, result from
- 产出而非效果:produce, yield, generate
- 间接/弱/不指定方向:be related to, be linked to, be associated with, be connected to, accompany, correlate with
- 方向由动词决定:X produced Y(X 因 Y 果);X originated in Y(Y 因 X 果);X results from Y 与 X results in Y 方向相反。
- 冠词决定唯一性:a cause of / a result of 表示还有其他因素;the cause of / the result of 表示唯一。

**8. 确定性连续统(certainty continuum)**
结果部分要传达两种信心:(1) "我做的事导致了这个结果"有多确定;(2) "这个结果意味着什么"有多确定。作者需先定位自己的信心在连续统上的位置,再选择与之匹配的语言。书 A 给出四个可叠加的调节杠杆:

| 杠杆 | 强 → 弱 |
|---|---|
| 动词的因果强度 | causes → leads to → contributes to → is related to |
| 动词时态 | 现在时(永久事实:is related to)→ 过去时(本研究所见:was related to) |
| 降险短语(hedging) | 无 → appears to / seems to / tends to → it could be inferred that → there is evidence to suggest that → the evidence points to the possibility that |
| 情态动词与范围限定 | 无 → may / might / could;in some cases / in virtually all cases;频率与数量修饰词 |

从绝对确定到高度保留的示范梯度(自拟同结构句):
1. We found that A causes B.(强因果 + 无限定)
2. We found that A may cause B.(加情态)
3. We found evidence to suggest that A may be related to B.(降险短语 + 弱因果动词 + 情态)
4. It appears that, in some cases, A may have been related to the onset of B.(降险 + 范围限定 + 情态完成式)
5. The evidence points to the possibility that, in some cases, excessive A may have contributed to the onset of certain types of B.(多重限定叠加)

配套的"含义/解释"表达按强弱排列:
- 强:this provides strong evidence for ... / it is evident that ... / it may be concluded that ... / we have confidence that ...
- 中:this suggests that ... / these results indicate that ... / it is likely/probable that ... / this is indicative of ... / we propose that ...
- 弱:it appears that ... / it seems that ... / it would seem that ... / it could be inferred that ... / it is possible that ... / this may imply that ... / we speculate that ... / potentially / presumably / perhaps
- could 可换成 may / might,有时 can;具体情态动词用法见第四单元。

## 高频通用短语(英文,按功能分组,每组 ≤ 8 条)

**回顾与过渡(开场)**
- Previous studies have reported/found that ...
- As described in Section 2 / As outlined above, ...
- In the present study, X was measured using ...
- The aim of this experiment was to ...
- Overall, ... / In general, ... / In most cases, ...

**邀请看图表**
- Fig. 1 shows / illustrates / summarises / presents ...
- As can be seen in/from Fig. 1, ...
- Results are given/shown in Table 2
- ... is apparent from Fig. 1 / ... is clearly visible in Fig. 1
- (see Fig. 1) / (data not shown)
- Inspection of Fig. 1 indicates that ...
- 注:from 表示可从图中数据推断,in 表示图里直接可见。

**客观结果动词**
- increased / decreased / rose / fell / dropped
- peaked at ... / reached a maximum of ...
- remained constant / was unchanged / remained stable
- exceeded / preceded / coincided with
- was present / was absent / was obtained
- varied with ... / was identical to ...

**评价性评论与信号**
- Importantly, / Notably, / Interestingly, / Significantly, / Surprisingly,
- It is noteworthy that ... / It is important to note that ...
- Overall, / In fact, / Indeed,
- broadly / essentially / virtually / effectively
- striking / marked / pronounced / dramatic / remarkable
- subtle / minor / modest / negligible

**与其他结果/模型/预测比较**
- consistent with / in line with / in (good) agreement with / in accordance with
- comparable to / broadly similar to / essentially identical to / much the same as
- as expected / as predicted
- in contrast to / contrary to / unlike / differ from
- compare well with / corroborate / support / confirm / validate
- contradict / deviate from / refute

**"高兴词"(积极评价)**
- accurate / precise / reliable / robust
- effective / efficient / feasible / viable
- improved / superior / satisfactory / successful
- useful / valuable / worthwhile / advantageous

**问题与议题**
- 淡化:negligible / minor deficit / of no consequence / not significant / less than ideal
- 去责:unfortunately / inevitably / unavoidable / it was not possible to ... / limited by ... / not within the scope of this study
- 转向好的方面:nevertheless / despite this / reasonably robust / fairly well
- 给出方向:future work should ... / further work is required / is currently underway / a further study will ...

**含义与解释(按确定性)**

## 可直接转化为 skill 规则的条目(每条一句,可检查)

1. 结果部分开头三句内必须出现以下至少一项:整体趋势概述、研究目标重述、方法要点回顾;不得以第一个原始数据点开头。
2. 结果不按实验时间顺序排列,而按叙述逻辑(总体 → 关键 → 次要 → 问题 → 含义)组织。
3. 每张图/表在正文中被引用时,必须附一句作者对其内容的评价或解读,不得只写 "X is shown in Fig. n"。
4. 有多种解读可能的图表,评论句要放在引导读者看图的句子之前或同一句内。
5. 关键结果必须用评价性语言固定读者判断(striking / only / as many as / much higher),不得只给裸数字或裸比较级。
6. 每个用于评价数量的词都要能归入"放大 / 缩小 / 强调 / 相近 / 中性"五组之一,且与作者要传达的方向一致。
7. 陈述某现象发生时必须带频率修饰词(always / generally / often / sometimes / rarely 等十级之一),或给出具体比例。
8. 至少有一处将本文结果与前人结果、预测或模型进行显式比较(consistent with / in contrast to 等)。
9. 转折、评价、遗憾类信号词(However, Unfortunately, Interestingly)放在句首。
10. 不用感叹号;惊喜用 striking / remarkable / unexpected 等词表达。
11. 图中可见内容用现在时,数据如何获得用过去时;本文发现默认过去时,只有作者有意将其提升为普遍事实时才用现在时。
12. 每个因果陈述的动词强度(cause / lead to / contribute to / be associated with)必须与证据强度匹配;相关性数据不得用 cause。
13. 每个"含义"陈述必须落在确定性连续统的明确位置,并通过动词、时态、降险短语、情态/范围限定至少两个杠杆表达;不得出现无任何限定的 "proves"。
14. 陈述含义用 suggest / indicate + may / could;完整展开含义留给讨论部分,结果部分只点到为止。
15. 结果中的问题、缺口、异常值必须在结果部分承认,并同时使用淡化、去责或给出解决方向中的至少一种措辞。
16. 结果部分应能独立成篇:直接从摘要跳过来的读者仅凭结果部分即可理解研究做了什么、发现了什么。
17. 结果的应用/含义句应回应引言中的目标用词(引言说 improve accuracy,结果说 more accurate)。
18. a cause / the cause、a result / the result 的冠词选择须与"是否唯一"一致。
19. 得到结果后回头核对引言的目标陈述,必要时修改引言使目标与结果对应。
20. 小节数量、小标题形式(短语式或陈述句式)、图表顺序向目标期刊近期论文看齐。

## 疑问 / 与书B可能冲突处

1. **结果部分是否允许解读**:书 A 明确反对"结果只写事实"的教条,主张评价性语言与简短含义句是常规做法;书 B 若沿用传统"Results 客观 / Discussion 解读"分工,两者冲突。建议 skill 规则:结果部分允许评价与一句式含义(suggest/indicate),深入解释与外推留给讨论。
2. **评价性语言的度**:书 A 鼓励用 striking / as many as 等引导读者;书 B(中国作者常见错误)可能警告过度夸大(overclaiming)。折中:评价词必须与数据方向一致且不超过证据强度——可用连续统作为检查尺。
3. **"高兴词"与谦逊**:书 A 把 excellent / superior 列为常规;若书 B 建议避免自我评价性形容词,需在 skill 中限定为"有比较基准时可用"。
4. **时态**:书 A 允许结果部分用现在时表达"永久事实";书 B 若规定结果一律过去时,冲突。建议默认过去时,现在时作为有意为之的信心表达并需能自圆其说。
5. **确定性连续统 vs 书 B 的动词/情态章节**:书 B 第 6 章讲动词,可能有自己的强弱分级;合成 references 时应把两套分级对齐成一张表,避免两种术语并存。
6. **Results and Discussion 合写**:书 A 只说"看目标期刊";医学 SCI 多数分写,但工程/材料常合写。skill 应按目标期刊路由,不给单一答案。
7. **统计结果的报告格式**(P 值、置信区间、效应量):书 A 几乎不涉及,是 skill 必须从其他来源补充的缺口。
