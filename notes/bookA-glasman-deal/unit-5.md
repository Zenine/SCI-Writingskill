# 书A 第五单元 怎么写结论

> 来源:书A 第五单元(PDF 页 372–398;正文自 374 页起,399 页为空白页)

## 核心主张(3–7 条,自己的话)

1. 结论的功能不是重复或总结,而是传递一条聚焦于"结果 + 影响"的明确关键信息。审稿人、编辑和读者都把结论当作关键部分来读,作者必须满足这一期待。
2. 结论与摘要、引言、讨论以及新出现的 Synopsis / Highlights 模块在内容上有重叠,但功能各不相同;尤其不能把摘要拿来当结论的主要素材。
3. 大多数读者会直接跳到结论(像翻到推理小说最后一页看凶手是谁),因此结论必须独立可读,并且要让读者一眼分清"哪些是本研究得出的",不能默认读者已经读过前文。
4. 作者对自己项目的熟悉是一种风险:熟悉让人看不见歧义。用非人称主语 + 一般现在时写的句子("动力学分析表明……")读起来像背景知识而不是本研究的发现,必须用语法手段"认领"贡献。
5. 结论的长度和形态取决于期刊的结构选项(独立结论 / 讨论末段 / 结果与讨论合并后的结论 / 长结论),除长结论外通常 100–200 词、一两段,有时用要点列表;应以目标期刊的平均字数为准。
6. 结论的所有语言组件都已在前四个单元出现,结论没有专属词汇;它的难点在于选择与归属,而不是措辞。

## 结构模型 / 模板

作者给出四种论文结构选项下的结论形态:

- 选项 1:Results / Discussion / Conclusion 分立 → 独立结论,1–2 个短段。
- 选项 2:Results / Discussion,无独立结论 → 讨论的最后 1–2 段在形式和内容上承担结论功能。
- 选项 3:Results and Discussion 合并 + Conclusion → 独立结论,1–2 个短段。
- 选项 4:Results + 一个很长的 Conclusion → 前半像讨论,末尾 1–2 段像结论。

通用结论模板共 11 个组件(顺序大体如下,各组件所占比例因学科而异,需对照目标期刊统计):

1. **论文里有什么**——本文呈现/描述了什么。一般现在时或现在完成时。
2. **论文/研究取得了什么**——用与引言目标相同的动词认领成就。现在完成时(We have developed...)或一般现在时(This study demonstrates...)。
3. **相关背景信息**——只在读者需要时用最少的词给出。一般现在时。
4. **空白/目标/需求**——一句回顾即可,措辞与引言呼应。
5. **方法/途径**——只提关键特征,不重复细节。一般过去时(was measured)或现在完成时(has been investigated)。
6. **带评价的关键结果**——结果 + 评价性副词/形容词(clearly、significantly、as expected)。一般过去时或一般现在时。
7. **结果的含义**——用 suggest / indicate / it is apparent that 等引出。一般现在时。
8. **潜在或实际的局限性**——通常一句,常与未来工作合并。
9. **潜在或实际的应用**——面向外部世界。一般现在时 + 情态动词。
10. **该研究如何推进知识**——fill key gaps / pave the way for / improve understanding。一般现在时。
11. **未来研究方向**——区分"正在进行"(work is in progress)与"建议"(should be explored)。

信息流:本文做了什么 → 得到了什么 → 这意味着什么 → 对领域和应用意味着什么 → 下一步。与摘要的区别在于:摘要要给足背景和方法让读者决定是否读全文;结论假定读者要的是"去向",所以背景与方法只做最少回顾,重心放在成就、含义、应用与后续。

书中六个来自不同学科的结论示例(化学探针、光电化学、建筑材料、核材料腐蚀、热力学相平衡、新生儿 fMRI)显示:

- 有的结论以"我们已合成并表征了……"式的现在完成时开头,直接认领成就;
- 有的以"某反应的级数已在……上被研究"式的被动现在完成时开头,再逐句给结果与解释;
- 工程类结论常以"本文已证明……的潜力"开头,随后给定量收益和推荐参数;
- 医学/仪器类结论以"我们设计、构建并实现了……"开头,再说安全性、可重复性和应用前景;
- 几乎所有示例都以应用、知识推进或未来工作收尾,没有一个以局限性收尾。

## 语法与语言要点

### 时态

- 一般现在时和现在完成时是结论的主时态,用于三件事:论文里有什么、结果意味着什么、研究取得了什么。
- 一般过去时较少,但用于重述方法的关键方面或关键结果(测量了什么、观察到了什么)。
- 现在完成时(have + 过去分词)是"认领成就"的默认形式,它同时表达"已完成"和"现在仍有效"。

### 认领贡献(ownership)的四个手段

结论中最容易出问题的是归属歧义:非人称主语 + 一般现在时的句子(如"X 分析表明 Y")既可能是本研究的结论,也可能是背景事实或研究需求。作者提出四个手段,可单独或组合使用:

1. 改用一般过去时或现在完成时(indicated / has been investigated);
2. 改被动为主动,用 we 做主语;
3. 用人物或研究作为语法主语(this study、our results);
4. 在句首放明确指向本文的短语(in the present paper、here、from the results of the current study)。

注意"It is argued that..."这类句子可能被读成"其他人认为",若是作者自己的观点应改成 we argue 或 it is argued here。

### 措辞

- 评价性语言(clearly demonstrates、significantly、highly sensitive)是结论中"关键结果 + 评价"组件的标志,要用但要有数据支撑。
- 结论与前文的回声原则同讨论:引言说 identify,结论就说 have identified,不换同义词。
- 结论不引入新数据、新论证,但可以引入前文没有明说的含义和应用。

## 高频通用短语(英文,按功能分组)

**认领成就(现在完成时)**
- We have developed / designed / synthesised / implemented ...
- In this paper, we have shown / demonstrated that ...
- ... has been investigated / evaluated / introduced in this work
- This study has identified / established ...
- Some shortcomings of ... have been highlighted, and ... has been introduced as an alternative

**论文里有什么 / 本研究表明**
- This paper has demonstrated the potential of ...
- This study clearly demonstrates ...
- The present work provides ...
- It is shown here that ...
- From the results of the current study it is apparent that ...

**关键结果 + 评价**
- ... was found to ...
- This was confirmed by ...
- As expected, ...
- ... gave the most promising overall performance
- ... exhibits high selectivity / sensitivity
- ... is approximately ... more ... than ...

**含义与知识推进**
- These data suggest that ...
- Our results fill key gaps in ...
- ... pave the way for ...
- ... highlights the potential to ...
- ... increases our understanding of ...
- It is suggested that ... may be attributable to ...

**应用与未来工作**
- ... is therefore suitable for ...
- Our findings will help to tailor the design of ...
- Further application of ... will accelerate ...
- Further work is currently in progress to ...
- ... now offers the opportunity to ...
- ... should be considered when ...

## 可直接转化为 skill 规则的条目(每条一句,可检查)

1. 结论第一句必须认领本文成就或说明本文做了什么,使用现在完成时或 this paper / this study 作主语。
2. 结论中每个陈述发现的句子必须能被读者辨认为"本研究得出",检查手段:过去时/现在完成时、we 主语、this study 主语、或 here / in the present paper 句首短语,至少满足一项。
3. 结论中禁止出现"非人称主语 + 一般现在时"且无归属标记的发现句(如"Analysis shows that...")。
4. 结论不得直接复制摘要句子;摘要不是结论的素材来源。
5. 结论长度以目标期刊平均值为准,默认 100–200 词、1–2 段;超过时检查是否混入了讨论内容。
6. 结论必须至少包含:成就/贡献、关键结果 + 评价、含义或应用三类组件。
7. 结论中的方法回顾只允许一句关键特征,不重复参数细节。
8. 结论结尾必须落在应用、知识推进或未来工作之一,不得以局限性或否定陈述收尾。
9. 结论中的动词与引言目标、讨论成就中的动词保持一致(回声原则),不做同义替换。
10. 未来工作句必须区分"本团队正在做"(is underway / in progress)与"建议领域去做"(should be investigated)。
11. 结论中若出现 It is argued / suggested that,检查是否会被读成他人观点;是本文观点则改为 we 或加 here。
12. 期刊要求 Highlights / Synopsis 时,它们与结论分别写,不得互相复制。

## 疑问 / 与书B可能冲突处

- 书A把结论定义为"关键信息 + 影响",允许含背景、方法回顾;书B可能把结论限定为"回答引言问题"的更窄口径,需比较后取更可检查的版本。
- 书A对"结论能否有局限性"持开放态度(模板第 8 项),书B若规定局限性只放讨论,skill 中按期刊结构选项分情况处理。
- 书A强调 we 主语和主动语态用于认领贡献;若书B(或某些中国作者习惯)主张结论多用被动,应以书A的"归属可辨认"作为检查标准,被动句需补 here / in this study。
- 书A的四种结构选项中"讨论末段即结论"的情形,与书B可能默认的"必有独立结论"不一致,skill 需先问用户目标期刊结构。
- 书A没有明确给出结论与摘要在"含义强度"上的差别,第六单元提到摘要含义有时比正文更强;结论是否也允许更强表述,书中未说明。
- 现在完成时在结论中的高频使用是英美期刊惯例,书B若建议少用完成时,以书A为准但在 reference 中注明。
