# 书A 第0单元 第二版前言与引言:为读者写作、逆向工程法

> 来源:书A 第二版前言 + 引言(PDF 页 18–39;前言 18–23,引言 24–39)

说明:本单元不是原书正式编号的单元,而是前言和引言两部分的合并笔记。它不讲某一节该怎么写,而是交代全书的方法论前提:为什么要"为读者包装信息"、什么是"逆向工程"、模板从哪里来、怎样挑选目标文章。后面各单元的规则都建立在这些前提上。

## 核心主张(3–7 条,自己的话)

1. **科研写作正在快速变化,模板不是死规矩。** 全球化、互联网阅读、发表速度三股力量在松动传统 IMRaD(引言—方法—结果—讨论)结构:标题和摘要越来越要能独立阅读,方法节的位置在漂移,在线论文出现 Highlights、Research in Context 之类的新板块。作者需要的不是一套固定格式,而是一种能随平台变化自我更新的写作策略。
2. **写作的核心问题对母语者与非母语者是共通的。** 第二版把读者群从"非英语母语作者"扩大到所有 STEMM(科学、技术、工程、数学、医学)作者:语法正确不保证论文好;组织混乱的完美英语照样读不懂,而组织清楚、有少量语言错误的文本反而能通过评审。
3. **信息本身是中性的,作者必须替读者标出信息的功能。** 好论文不是信息仓库,而是一件"为读者制作的工艺品":目标不仅是让读者能懂,而是让读者不可能不懂。作者对自己课题太熟,容易高估读者的背景,尤其在跨学科阅读越来越普遍的今天。
4. **"叙述性包装"= 围绕信息搭的脚手架。** 标题、小标题、段落功能与顺序、图表数量与位置、段首句、动词时态,都是包装手段;有的显性(直接点明信息作用),有的隐性(靠时态和句首暗示)。
5. **逆向工程是全书唯一的方法。** 不问"这句说了什么",而问"这句在做什么";拆解本领域成功论文的功能结构、词汇、语法,做成自己的模板,再用新文章不断校准。书中所有模板来自对 2500 余篇近期发表论文的分析,但作者强调它是描述性的(告诉你别人怎么做),不是规定性的(不告诉你必须怎么做)。
6. **校对、翻译软件解决不了写作问题。** 它们改不了时态传达错误的事实地位(把"我们发现 X 发生了"写成"X 是公认事实")、改不了漏掉的结构环节(如结论没有回扣原问题)、改不了被翻译放大的结论强度;而且把未发表材料交给在线工具还有所有权风险。
7. **科研英语是一套有限的"代码"。** 大多数读者也不是母语者,所以论文只需要一小套通用的非技术词汇和短语;不追求优雅,不用同义词替换来"避免重复",同一概念全篇用同一个词。

## 结构模型 / 模板(用自己的话描述各步骤的功能与顺序、信息流、每步常用时态,不抄例文)

引言部分给出的是一张"规划—写作"两层的自检图,可以当作任何科研文本的通用工作流:

### 第一层:规划(叙述脚手架的地基)

按下面顺序回答,每一步都是"我为读者做了什么决定":

1. **定文体与读者。** 研究论文、综述、申请书、快报、海报、会议摘要各有各的结构;不同文体之间剪贴拼凑必然散乱。动笔前先对同文体的成功样本做逆向工程。同时问:谁会读?能默认他们知道多少?多快能把他们带到细节?读者以后会不会更跨学科?
2. **定小节划分。** 本领域这类论文通常几个小节、各多长?我的内容能否自然装进去?装不进去有没有更好的切法?
3. **定图表的数量、顺序、位置。** 每张图都能说出存在理由;图表出现在读者刚好想看它的地方,不打断叙述。
4. **定段落的功能与顺序。** 每段有且只有一个明确功能,顺序对读者合乎逻辑。
5. **定句子在段内的功能与顺序。** 每句都有功能、都服务于段落功能、都与下一句逻辑相接。

### 第二层:写作(主动的叙述性包装)

规划完成后,写每一句时再做六项检查:

- 我是否在替读者**评论**信息(而不是假设它不言自明)?
- 我是否**点明**了信息的功能?
- 每句的**时态**是否表达了我想要的事实地位,是否消除(而非制造)歧义?
- **词汇**是否照顾全球读者、是否前后一致?
- 每段的**首句**是否让读者看出段落走向,句与句之间的意义间隙是否已缩小?
- **标题与小标题**是否预告内容、长度是否合本领域惯例、小节内容是否全部"归属"于该标题?

### 逆向工程的四步循环

1. 建立句子级/段落级的**功能**模型(这句在指出空白、这段在把贡献映射到文献上……)。
2. 从成功文本中挖出实现各功能的**词汇**。
3. 识别并掌握实现功能的**语法与写作技巧**(首先是时态选择)。
4. 持续读本领域文章,**更新**前三项。第四步不可省略,因为文体本身在演变。

### 目标文章(target articles)的筛选标准

至少 4 篇,并定期更新;应满足:来自英语国家机构(最好母语作者)、主题尽量贴近自己的研究、篇幅精练(含图表不超过约 15 页 A4)、来自自己想投的期刊、5 年以内、自己认为写得好、IMRaD 各部分边界清楚(小节名可能叫 Procedure / Model / Materials and Methods / Methodology / Experimental / Data Collection 等,不必拘泥于字面)。

### 写作顺序与阅读顺序不等于 IMRaD 顺序

作者通常先写方法,再写结果、讨论/结论,然后写引言,最后写摘要和标题;读者通常从标题/摘要跳到结果或方法。书按 IMRaD 排单元只是为了查阅方便。

### 校对与翻译工具的四个盲区(动笔者必须自己把关)

书中列举了外部润色解决不了的问题,可直接作为 skill 自检项:

1. **事实地位错位。** 时态把"本研究的发现"写成了"公认事实"(或反过来),语法完全正确,意思却错了。
2. **结构环节缺失。** 例如没有解释为什么选这种方法、结论没有回到最初的问题;润色者不了解本领域惯例,看不出缺了什么,但审稿人会据此判断"不专业"。
3. **结论被放大。** 翻译常把留有余地的措辞译得更肯定;审稿人在结果里找不到支撑这种肯定的证据就会拒稿。
4. **文化写作规范错配。** 词汇选择、段落组织方式都有英语学术圈的隐含规范;直译中文段落逻辑,读者会觉得莫名其妙,尤其是作者想强调研究价值的地方会被低估。

另有一条与工具无关的风险:把未发表材料交给在线工具后,作者难以控制其所有权。

### 全书各单元的组织方式(读后面笔记时的地图)

- 第一、二单元(引言、方法)结构相同:先用一篇真实引言做逆向工程得出模板 → 用更多引言验证模板 → 给出词汇表和例句 → 语言与写作技巧问答 → 写一篇练习并对照参考答案。
- 第三到第六单元(结果、讨论、结论、摘要)鼓励读者先对自己的目标文章做逆向工程,再拿书中的通用模板校正。
- 第七单元讲标题,第八单元是清单和提示(第二版新增,汇总各单元的写作问题)。
- 每单元末尾的语言技巧部分不是语法练习,目标是"避免歧义",不是"确认正确语法"。
- 作者强调:只读不做练习,得到的是理论认识;能否落笔取决于是否真的做过逆向工程,"知道该做什么"与"知道怎么做"是两回事。

## 语法与语言要点

- **时态承担"事实地位"标记。** 同一条信息,过去时表示"当时的发现",一般现在时表示"公认事实",现在完成时表示"与现在仍相关"。这是全书反复出现的第一原则,引言里先以"X occurred vs. X occurs"提出。
- **重复优于同义替换。** 同一概念换词(framework → methodology → approach → model)会让读者误以为出现了新东西;学术写作靠重复同一术语来维持概念稳定。
- **语法正确 ≠ 意思正确。** 校对能抓语法错,抓不到"时态把你的新发现写成了旧常识"这类语义错误。
- **结论强度要与证据匹配。** 翻译或润色把结论写得比证据更肯定,是评审阶段被拒的常见原因。
- **有限词汇即可。** 论文中的非技术性语言是一套小而稳定的常用词,不需要掌握"全部英语"。

## 高频通用短语(英文,按功能分组,每组 ≤ 8 条,只收通用学术短语,不收书中例文的具体句子)

前言与引言本身几乎不给短语表(短语表从第一单元开始),这里只收引言中作为功能示例出现的通用表达:

**标记句子/段落功能(逆向工程时给自己用的标签)**
- This sentence identifies a gap in the research.
- This paragraph maps the contribution of this study onto the literature.
- This sentence establishes the importance of the topic.
- This sentence provides background facts.

**区分事实地位的时态对照**
- X occurs (accepted fact) vs. X occurred (a finding at that time)
- It is known / thought that ... (when "we" would be ambiguous)

## 可直接转化为 skill 规则的条目(每条一句,可检查)

1. 动笔前先要求用户指明文体(研究论文/综述/申请书/会议摘要等)和目标期刊,不同文体不得套用同一模板。
2. 任何一节在写句子之前先列出"段落功能清单",每段只允许一个功能。
3. 每句话必须能回答"这句在为读者做什么";答不出的句子删除或合并。
4. 同一概念全篇使用同一个术语,禁止为"避免重复"而换同义词;检查方式:抽取关键术语,统计其变体数是否为 1。
5. 对每个描述已有知识的句子,检查时态是否与所声称的事实地位一致:公认事实用一般现在时,某研究当时的发现用一般过去时,仍影响现状的工作用现在完成时。
6. 结论性语句的强度不得超过结果所支持的强度;润色或翻译后需重新核对情态动词和程度副词是否被无意加强。
7. 图表只在读者刚好需要时出现,每张图必须在正文中有对应的功能说明,不得只是"堆上去"。
8. 每段首句必须让读者预见该段走向;检查方式:只读每段首句能否复述全文脉络。
9. 建议用户维护至少 4 篇 5 年内、同期刊、同主题的目标文章,并在需要判断"本领域惯例"时优先参照它们而非通用规则。
10. 写作顺序建议:方法 → 结果 → 讨论/结论 → 引言 → 摘要 → 标题;不要先写引言。
11. 涉及未发表材料时,提醒用户不要把全文交给在线翻译或编辑工具。
12. 方法选择的理由和结论对最初问题的回应这两个结构环节不得缺失;润色前先检查结构,再检查语言。
13. 小节标题必须能覆盖小节全部内容,且长度与语法形式符合目标期刊惯例;检查方式:小节内任一段落都能归属到该标题下。

## 疑问 / 与书B可能冲突处

- **描述性 vs. 规定性。** 书A自称只描述"别人怎么写",让作者自己从目标文章归纳;书B(实战教程)更可能直接给规定性清单。skill 落地时需要可检查的硬规则,会不可避免地把书A的描述转成规定,应在 references 中注明"此规则来自对惯例的归纳,以目标期刊为准"。
- **同义替换。** 书A明确反对用同义词避免重复;中文写作教学(包括书B可能出现的"避免重复用词"建议)常鼓励换词,需要核对书B是否有相反主张。若冲突,倾向书A(可检查、且与全球读者理解一致)。
- **目标文章的"母语作者"要求。** 书A建议优先选英语国家机构、最好母语作者写的样本;对中国作者而言,这一条可操作性一般(很难判断作者母语),skill 中可放宽为"目标期刊近 5 年高被引/编辑推荐文章"。
- **IMRaD 松动的具体形态。** 前言提到 Highlights、Research in Context、独立可读的摘要等新板块,但没有展开;书B(2024)可能有更贴近中国作者投稿实际的描述,合成时以书B补充。
- **段落长度、句长等量化数字**在引言里没有给出,出现在第一单元(见 unit-1.md);书B 若给出不同数值,需要标注两说。
