# 书A 第八单元 清单和提示

> 来源:书A 第八单元(PDF 页 466–488;正文 468–488,含 8.1 组织信息 469–472、8.2 创建句子 473–476、8.3 语法和词汇 476–486、8.4 常规 487–488;附录A 前缀表 498–500、附录B 研究动词表 502–505 仅作索引参考,未摘录)

## 核心主张(3–7 条,自己的话)

1. **写作的目标不是"让读者能懂",而是"让读者不可能不懂"。** 作者与同事都懂,恰恰是发现歧义的最大障碍;所有清单项都是为了替读者堵住误读的可能。
2. **数据和信息本身没有功能,功能来自叙述。** 每一条信息都要被包装进"它在这里做什么"(引出问题?正例?反例?)的叙述里,并指向论文的"南磁极"——全文最终要落到的结论点。
3. **组织好、写得好可以弥补语言错误;语言零错误弥补不了组织和写作的糟糕。** 因此清单的顺序是:先规划(8.1),再造句(8.2),最后才是语法词汇(8.3)和习惯(8.4)。
4. **规划先于打字。** 先按重要性排出结果清单,并确定研究对知识、对研究领域、对现实世界的贡献,以此锚定每一节(包括标题)的写法;段落先定功能再落笔。
5. **句子层面的核心是可读性与无歧义**:已知信息在前、新信息在后;句首决定读者的处理框架;句长 20–26 词为常态;and/or、which、介词、名词过多是长句失控的风险信号。
6. **语法词汇层面反复出现的一个主题是"所有权"**:被动、非人称主语、we 的泛指、it is argued 一类句式都会让读者分不清这是作者的贡献还是他人/公认的知识。
7. **全书压轴建议:对任何文体都用逆向工程**——分析近期发表的同类范文,生成自己的模板。

## 结构模型 / 模板(用自己的话描述各步骤的功能与顺序,不抄例文)

本单元本身就是一个四层自检流程,可按"写前 → 写中 → 改稿 → 终检"使用。

### 8.1 组织信息(写前规划)
1. **列结果、定贡献**:按重要性排列结果;分别写出对知识/对研究/对现实世界的贡献与影响。这是全篇的锚。
2. **明确研究价值**:结果不会自己说话。用积极词点明成就(如一种更省成本的方法),尽量具体说明对领域或社会的贡献,并说明潜在影响。成就与贡献可以重叠,有的研究没有明显应用,但关于价值的信息必须明确一致。
3. **分小节并起小标题**:检查分节是否帮到读者,小标题是否准确代表内容;小节开头尽早出现小标题里的关键词。
4. **排序信息**:不要从很宽泛直接跳到很具体,尤其在小节开头;两句之间的"句号空白"是读者最容易掉链子的地方,用 8.2 的句首技巧把信息链起来。
5. **把信息包进叙述**:告诉读者这条信息"在做什么"而不只是"在说什么";给数据加评价性修饰(只有 43%、高达 43%),让读者知道数字在研究语境里意味着什么。
6. **相关性**:预判读者读完每句后的"那又怎样",用 suggesting that / which means that 之类补上含义。
7. **假设读者**:跨学科读者可能没读前面的节,也不共享你的背景知识;想清楚能假设他们知道什么,否则论文只在自己的小圈子里流通。
8. **分段**:先规划每段功能再按逻辑排序;避免整页一段或连续短段(期刊常态约 150–170 词);一段一功能;尽量以表明段落功能的叙述句开头;不要把要看到段尾才明白的陈述放在段首;删掉与段落功能无关的"游离句",或给它建一个叙述框架。

### 8.2 创建句子(写中)
1. **信息顺序**:已知在前、新信息在句尾;句尾的新信息成为下一句的已知,句子由此链接。
2. **句首三法**:重叠重复、This/These + 名词的替代指代、However 一类信号词;重要信息用 Interestingly / It is noteworthy that 等句首标记。避免用 -ing 形式或介词(尤其 for、with)开头。
3. **句长与密度**:眼睛的速度要跟得上脑子;多数期刊句长 20–26 词;句越长越难控制语法与歧义,重点会被淹没;名词和介词短语过密会让主动词模糊。风险信号:多于一个 and、多于一个 which、介词和名词过多。
4. **and/or 的拖拽歧义**:并列结构会把不该并列的成分一起带上,或者抓不住该并列的成分;"X 的增加和 Y"到底是 X、Y 都增加还是只有 X 增加,读者无法判断。
5. **信号连接词是有约束的承诺**:therefore 必须真是前句的直接结果;for example 必须真是前句概括语的实例;in other words 必须真是换一种说法表达同一意思。用错会把读者引向错误方向。

### 8.3 语法和词汇(改稿)
1. **时态即功能选择**:一般过去时只报告你的发现;一般现在时把发现当作事实——风险更高、影响更大。换时态时要自己和读者都知道为什么。
2. **所有权与被动/非人称主语**:无施动者被动要用 here / in this study / in our model 等锚定主体;被动动词别放在长句末尾让读者等太久;we 既指作者又指"本领域所有人"会歧义,泛指时改用 It is now possible to ...;非人类主语(Modelling suggests ...)和 It is argued that ... 会让读者以为是别人的工作,在摘要里尤其危险。
3. **冠词**:a 与 the 都合语法但含义不同的"隐形错误";the 表达共享知识;检查被当可数用的不可数名词是否需要冠词。
4. **介词**:介词会改变意思(evidence of / evidence for;improved up to / improved by up to);不要让介词干实词的活,句首尤其如此;从本领域最新文献里挖"动词 + 介词"固定搭配;with 含义太宽,可换成 using / having / in combination with / as a result of / at the same time as;一串介词短语是严重歧义源;"for the first time"的位置决定新颖性落在哪个成分上。
5. **主谓一致**:主语与动词不相邻时检查单复数;检查主语在逻辑上能否执行该动作。
6. **指代**:this/these/that/those 后加名词;it/which/this 有多个可能所指时改为名词;检查所指范围的起止是否清楚。
7. **副词位置**:only / just / simply 放在不同位置意思完全不同(书中用同一句在六个位置放 only 来演示:限定"我们"、限定"分析"、限定"模型"、限定"模拟"、限定"反应"、限定"唯一反应");写完检查 only 是否紧贴它要限定的成分。
8. **-ing 的歧义**:-ing 不带时态、不带单复数,读者不知道谁在做这个动作、也不知道它是"通过""因而""当……时""能够"还是"如果"(书中列了 A–J 十种可能解读);把 -ing 改成带主语的从句或明确的连接词。
9. **弱动词**:have / get / bring / keep / spread 各有多种含义,换成 obtain、provide、retain、distribute 一类精确动词。
10. **术语一致性**:同一事物不要在 tool / device / approach / method / framework / technique 之间来回换;同义词典是敌人——没有两个词在所有语境下等义,替换词可能范围更宽或褒贬不同,非母语作者尤其易选偏;为了易读,不怕重复同一个词。
11. **术语核实**:用 Google Scholar 先带引号再不带引号搜索术语,比较出现的时间、领域、频次,确认术语准确且未被新命名取代。
12. **易混词**:comprise / consist of / be composed of 后接全部成分,include 后接部分成分;respectively 按前文顺序一一对应;连字符把多个词绑成一个修饰概念(five centimetre-wide 与 five-centimetre wide 数量不同);alternately/alternatively、beside/besides、criterion/criteria、different/various、e.g./i.e.、effective/efficient、phenomenon/phenomena、adapt/adopt、affect/effect、imply/infer 需逐对分清。

### 8.4 常规(终检)
1. **谁在说话**:每个陈述是作者假设、作者解释、还是公认事实?读者分得清吗?要不要引用?
2. **确定性连续统**:措辞的确定程度必须与结果的支撑强度一致——从"确定"到"推测"之间选准位置。
3. **引文位置**:引文放在句中对应位置;全堆在句尾会让"谁做了什么"模糊。
4. **口头禅**:indeed / in fact / basically / clearly 一类填充词要清理。
5. **标点习惯**:破折号对的含义对全球读者不透明,考虑改成文字;括号里的内容要么重要到该进正文、要么不重要到该删;逗号过多是句子超载的信号,拆成几个紧密相连的短句。
6. **收官**:任何文体都用逆向工程从近期范文生成模板。

## 语法与语言要点

- **时态**:过去时 = 报告本研究的动作与发现;现在时 = 主张为普遍事实;转换必须有理由。
- **语态与主语**:被动无施动者 → 加地点/研究锚定;长句被动动词前移;避免 we 的泛指与专指混用;It is argued that 在摘要中避免。
- **冠词**:a/the 的隐形语义差;the 表共享知识;不可数名词(steel、technology、environment 等)误作可数。
- **介词**:evidence of vs for;up to vs by up to;句首介词短语改为分词/实词;with 的六种替换;for the first time 紧贴其修饰对象。
- **一致**:远距离主谓一致;逻辑一致(抽象名词能否"决定"某事)。
- **指代**:this/these 后必须有名词;it/which 唯一可指。
- **副词**:only/just/simply 紧贴被限定成分。
- **-ing**:不用 -ing 开头句子;句中 -ing 若主语不唯一或含义不唯一,改从句。
- **动词**:弱动词 → 精确动词;动词 + 介词从本领域文献取搭配。
- **词汇**:术语一致不换词;综合/包含动词分全部与部分;respectively 对应顺序;连字符改变修饰范围;十对易混词。
- **句法**:20–26 词;已知→新;句首信号词有约束语义;and/or 并列范围要唯一;which 不超过一个。
- **标点**:破折号对、括号、逗号三种习惯的检查法。

## 可直接转化为 skill 规则的条目(每条一句,可检查)

### 组织信息
1. 动笔前先列出按重要性排序的结果清单,并分别写出对知识、对研究、对现实世界的贡献;每一节的写法都要能回溯到这份清单。
2. 每一节/每一段先写一句"本段功能",再填内容;写不出功能句的段落不得保留。
3. 每个小标题必须准确代表小节内容,且小节开头前两句要出现小标题里的关键词。
4. 小节开头不得从宏观背景直接跳到具体技术细节,中间必须有过渡句。
5. 每个数据必须带评价性修饰或解释(只有/高达/相当于……),不得出现"裸数字"。
6. 每句写完自问"那又怎样",无法回答的句子要补 suggesting that / which means that 或删除。
7. 每段一个功能;段长约 150–170 词,禁止整页一段或连续单句段。
8. 段落以表明功能的叙述句开头,不以要读到段尾才能理解的陈述开头。
9. 与段落功能无关的句子(笔记残留、同事建议)一律删除或另建叙述框架。
10. 假设跨学科读者没读过前面的节;关键概念在本节首次出现时要可独立理解。
11. 研究的成就、贡献、影响三者在全文的表述必须一致,不得在摘要、引言、结论中各说一套。

### 句子
12. 句内信息顺序:已知在前、新信息在句尾;下一句以上一句句尾的新信息开头。
13. 句首只允许三类:重复/替代指代(This + 名词)、信号连接词、重要性标记;不得以 -ing 或介词短语(尤其 for/with)开头。
14. 句长控制在 20–26 词;超过 30 词的句子必须拆分或说明理由。
15. 一句中出现多于一个 and、多于一个 which、或名词与介词短语堆叠时,视为超载句,必须重写。
16. and/or 并列结构必须让并列范围唯一;若有两种读法,拆句或重复动词。
17. 用 therefore/thus 开头时,前句必须是其直接原因;用 for example 时,前句必须有被举例的概括语;用 in other words 时,必须真是同义改述。
18. 主动词不得被名词化结构淹没;每句能一眼找到主语和主动词。

### 语法词汇
19. 时态是功能选择:报告本研究发现用过去时,主张普遍事实用现在时;每处时态切换要有可说明的理由。
20. 无施动者被动句必须有 here / in this study / in our model 等锚定语,让读者知道是谁做的。
21. 被动动词不得放在超过 20 词的句子末尾;长主语要拆分或改主动。
22. we/our 只用于指作者;泛指"本领域"或"人类"时改用 It is now possible to ... 一类非人称表达。
23. 摘要中禁止 It is argued/suggested that ... 一类无主语句式;改为 We argue/suggest that ...。
24. 非人类主语(Modelling suggests ...)描述作者自己的工作时,要加 our/here 表明所有权。
25. 所有 this/these/that/those 后面必须跟名词。
26. it/which/this 若有两个以上可能所指,改为具体名词。
27. only/just/simply 必须紧贴其限定的成分;写完逐个检查。
28. 句中 -ing 形式若施动者或逻辑关系(通过/因而/当/能够/如果)不唯一,改为带主语的从句或明确连接词。
29. have/get/bring/keep/spread 等弱动词一律替换为精确动词。
30. 同一概念全文只用一个术语,不在 method/approach/technique/framework/tool 之间轮换。
31. 不用同义词典换词求"变化";为清晰可重复同一词。
32. 关键术语用 Google Scholar 带引号/不带引号各搜一次,确认仍是当前通用说法。
33. comprise/consist of/be composed of 后必须是全部成分;只列部分成分时用 include。
34. respectively 前后两组成分数量必须相等且顺序一一对应。
35. 多词修饰语作前置定语时加连字符,并检查连字符位置是否改变数量或范围。
36. with 若可被 using/having/in combination with/as a result of 等替换,则替换。
37. for the first time 必须紧贴它所修饰的成分,让新颖性落点唯一。
38. 主语与动词相隔较远时逐句核对单复数;抽象名词不得充当只有人才能执行的动作的主语。
39. 检查 a/the 的选择是否改变了句义;首次提及且非共享知识用 a,共享知识或已提及用 the;不可数名词不加不定冠词。
40. 逐对核对 affect/effect、adapt/adopt、imply/infer、e.g./i.e.、effective/efficient、criterion/criteria、phenomenon/phenomena、alternately/alternatively、beside/besides、different/various。

### 常规
41. 每个陈述必须能被读者判定为"作者假设 / 作者解释 / 公认事实 / 他人结论(带引用)"四者之一。
42. 确定性措辞(is / is likely to / may / might)必须与证据强度匹配,不得高于结果支撑的程度。
43. 引文放在句中被引内容旁边,不堆在句尾。
44. 删除 indeed / in fact / basically / clearly 一类无信息量的填充词。
45. 破折号对改写为文字;括号内容要么并入正文要么删除;逗号超过三个的句子拆分。
46. 写任何新文体前,先取近期 5–10 篇范文做逆向工程生成模板,再动笔。

## 疑问 / 与书B可能冲突处
