## skill 的真实增量集中在

1. **不编造 / 不越权**:四份基线里三份把作者没给的事实写进正文(报告规范声明、结局定义、修订稿承诺),skill 侧全部进「建议补充」或方括号待确认。这是硬规则 3/4 与 12 号"待作者确认"档的直接效果。
2. **篇幅与收尾**:摘要方法+结果占比、不以局限收尾、回复信开头段编号列表、签名位置。裸代理在这四点上全部按"自然写法"走。
3. **引用占位要说明该引什么**:裸代理只给编号。
4. **自检输出**:裸代理没有;这是 skill 独有的形态要求,本身不是写作质量,但让作者能核对。

## 裸代理本来就能过的要点(skill 无增量,规则属"护栏"而非"增值")

时态一致、语态与所有权、纳入排除数字、结局定义、模型与调参齐全、SHAP 五项、大部分缩写全称、避险词强度、逐条不漏、三类处理分明、拒绝有据、数字准确。

这些要点保留在评审要点里作回归护栏,但对应 reference 中的细则可以在下一轮减重时优先压缩(它们是模型已掌握的常识,重复写只耗 token)。按 writing-skills 的口径,单次基线只有 1 个样本,判定"无增量"前应再跑 4 次以上。

## 结论

skill 在四份样例上的净增量为 +2 / +3 / +3 / +4 分,全部落在"纪律"类要点(不编造、篇幅、收尾、格式、自检),不在"语言能力"类要点。后续维护方向:纪律类规则保持强形态(硬规则 + 结构槽位),语言能力类细则可缩。

## 判定(≥5 次样本后可以下结论的)

**skill 有稳定增量(5/5 或 4/5 裸代理挂)**,对应规则保持强形态:
- 不编造 / 不越权(SKILL 硬规则 3、4;12 号"待作者确认"档)。裸代理的模式高度一致:把领域惯例(TRIPOD、Helsinki、去标识、全因/非计划、测试集只用一次)当成事实写进正文,再在末尾加"若不属实请删"。
- 引用占位要说明该引什么(硬规则 4)。
- 摘要方法+结果 ≤ 60%、单句 ≤ 40 词、不以局限收尾(05 细则 5、18;09a)。
- 回复信签名位置、开头段编号列表、承诺句待确认(12 号「回复信的结构」)。
- 自检输出(输出格式第 5 项)。

**裸代理 5/5 本来就过、skill 无增量**,对应细则是护栏,可压缩:
- 时态一致、语态与所有权(Methods/Intro/Abstract 全部过)。
- 纳入排除数字、结局定义、模型与调参齐全、SHAP 五项、数字准确(全部过)。
- 术语一致、大部分缩写全称(仅 CI 一项 4/5 漏)。
- 空白句用现在完成时 / remains unclear + 转折词(Intro 5/5 过)。
- 回复信逐条不漏、三类处理分明、拒绝有据、数字准确(5/5 过)。

## 对减重的指引

上面"无增量"清单对应的 reference 内容(01 的时态细则、02 的功能步逐步解释、03/04 的时态说明、08 总表中与裸代理一致的格子、12 的 C/D 组里"数字准确/逐条不漏"类条目)可以从"细则 + 模板 + 例句"压成"一句可检查规则",预计再省 20–30%。"有增量"清单对应的内容不动,且形态维持"硬规则 + 结构槽位",不改成软建议。
