# 回归评审要点:Discussion 与 Conclusion(对应 discussion-draft-zh.md)

1. **开头**:讨论第一段用一到两句概括主要发现(不重复具体数字与图号),或直接回应引言问题;不以背景重述开头超过一句。
2. **镜像引言目标**:引言四项目标(建模、对比基线、SHAP 解释、中国人群)在讨论中各有一处显式回应,用相同关键词。
3. **与文献比较放讨论且带 [REF]**:LACE/HOSPITAL 0.6–0.7、欧美 ML 0.75–0.82、中国两篇约 0.70 的对比全部出现并各带 `[REF]` 占位;不生成文献条目。
4. **不复述结果**:讨论中不再逐条报 AUC/CI/P 值;可引用一个关键数字支撑论点,但不出现 "as shown in Table 2" 式图表导览。
5. **特征解释的强度匹配**:每个解释句一个避险成分;胰岛素使用与低血糖的推测明确标为推测且说明数据缺低血糖记录;不写 cause。
6. **局限集中一处**:六条局限集中在一段或一个 Limitations 小节;每条一句;"本院再入院未含外院"这类只有作者知道的局限如实保留;讨论不以局限段收尾,局限后接未来工作或含义。
7. **结论独立成节**:100–200 词(04 口径);有归属标记(this study / we);包含 take-home(常规数据可识别高风险、可解释)与“需外部验证”的限定;不以局限句收尾,末句落在应用、知识推进或未来工作;不复制摘要句子。
8. **强度**:结论强度不高于结果节;不出现 novel / first / significantly improves / robust 无据词;"模型只是筛查,不能替代临床判断"保留。
9. **不编造**:不添加材料没有的机制、数字、文献结论;不承诺未说的后续研究细节。
10. **自检结果**:五项核心 + 04 号清单 ✗/N/A + 10 号扫描 + 建议补充 + 衔接提示(引言/结果对应)。
