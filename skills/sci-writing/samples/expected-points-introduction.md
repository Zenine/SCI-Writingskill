# 回归评审要点:Introduction(对应 introduction-draft-zh.md)

合格输出必须同时满足以下各条。逐条打 ✓/✗,任一 ✗ 需回写对应 reference 或 SKILL.md 路由。

1. **四组功能可标出且顺序正确**:重要性/背景 → 研究地图(已有工具与方法) → 空白/动机 → 本文做什么;输出的「结构」部分能把每段对应到这四组,第一组在开头、第四组在结尾。
2. **开头是公认事实而非本文问题**:第一句用一般现在时陈述糖尿病负担或再入院的普遍事实,不以"本研究"或具体模型起手。
3. **Why-Why-Why 倒序**:从疾病负担 → 再入院问题 → 现有工具不足 → 中国人群缺口,层层推到本文问题;不跳层。
4. **空白句时态与信号**:空白用否定 + 现在完成时或 remains unclear 类句式,并由 however / although 一类转折词引出;不用问句。
5. **文献引用占位**:凡提到 LACE、HOSPITAL 评分、既往机器学习研究、中国患病人数等具体前人结论处用 `[REF]` 占位并说明该引什么;不生成任何文献条目;不把"AUC 0.6–0.7"当无出处事实。
6. **本文句所有权与时态**:最后一组用 In this study, we / Here we,目的句用现在时或过去时但全段统一;不预先给出结果数字(草稿没给),可预告将做比较与 SHAP 解释。
7. **不编造**:不添加草稿没有的数据(如具体再入院率、患病人数、研究年份、医院名);需要数字支撑处进「建议补充」并注明该查什么。
8. **句间承接显式**:每句开头与上句有重叠、指代、信号词之一;this/these 后跟概括名词;不用 and / so / but 起句。
9. **避险与评价词**:对既往研究的评价(效果一般、临床医生不信任)用可核查的中性表述(limited discriminative performance、limited interpretability),每句最多一个避险词。
10. **自检结果**:五项核心 + 01 号清单中 ✗ 的条目,含「建议补充」与衔接提示(引言立下的问题在讨论中须回应)。
