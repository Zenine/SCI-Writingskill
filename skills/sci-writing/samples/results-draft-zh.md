# 测试输入:中文结果材料(医疗 AI)

> 用途:回归测试输入。让 agent 按 SKILL.md 把下面的材料写成英文 Results 节(含二级标题),并附自检结果。对照 `expected-points-results.md` 判定。与前几份样例属同一篇论文。

基线:最终纳入 1,563 例,训练集 1,094 例、测试集 469 例。全队列 90 天再入院 292 例(18.7%),训练集 205 例(18.7%)、测试集 87 例(18.6%)。再入院组年龄更大(中位 68 vs 63 岁,P<0.001)、糖化血红蛋白更高(中位 9.1% vs 8.2%,P<0.001)、既往一年住院次数更多(中位 1 vs 0 次,P<0.001),性别无差异(P=0.41)。基线特征见表 1。

模型表现(测试集):XGBoost AUC 0.84(95% CI 0.80–0.88),逻辑回归 0.76(0.71–0.81),随机森林 0.81(0.77–0.85)。XGBoost 灵敏度 0.79(0.73–0.85)、特异度 0.77(0.72–0.82),阈值按训练集 Youden 指数取 0.21。DeLong 检验 XGBoost 优于逻辑回归(P=0.003),与随机森林差异不显著(P=0.12)。ROC 曲线见图 2,三模型指标见表 2。

校准:XGBoost 校准曲线接近对角线,Brier score 0.118;逻辑回归 0.139,随机森林 0.124。校准曲线见图 3。

SHAP:前五特征依次为糖化血红蛋白、住院天数、既往一年住院次数、eGFR、胰岛素使用;糖化血红蛋白越高、住院越久、既往住院越多、eGFR 越低、使用胰岛素者预测风险越高。SHAP 汇总图见图 4。

亚组:65 岁以上 AUC 0.82(0.76–0.88),65 岁及以下 0.85(0.79–0.91);男性 0.83,女性 0.85。

注意:文献里 LACE 评分在糖尿病人群 AUC 0.6–0.7,我们的模型明显更好——这个对比是作者写在材料里的,但该放在哪一节由 agent 判断。
