# 测试输入:中文讨论与结论材料(医疗 AI)

> 用途:回归测试输入。让 agent 按 SKILL.md 把下面的材料写成英文 Discussion 与 Conclusion(分立两节),并附自检结果。对照 `expected-points-discussion.md` 判定。与前几份样例属同一篇论文;引言承诺的目标是:建 XGBoost 模型预测 90 天再入院、与逻辑回归和随机森林对比、用 SHAP 解释、面向中国人群。

主要发现:XGBoost 在测试集 AUC 0.84,优于逻辑回归(0.76,DeLong P=0.003),与随机森林(0.81)差异不显著;校准好(Brier 0.118);前五特征是糖化血红蛋白、住院天数、既往一年住院次数、eGFR、胰岛素使用。

与前人比较:LACE 和 HOSPITAL 评分在糖尿病人群文献报告 AUC 0.6–0.7;欧美的机器学习再入院模型 AUC 多在 0.75–0.82,样本 500–3,000 例;针对中国 2 型糖尿病住院患者的再入院预测研究我们只查到两篇,都是传统回归,AUC 约 0.70。

对特征的解释:糖化血红蛋白高提示血糖控制差,与再入院关系文献一致;既往住院次数多是各类再入院模型公认的强预测因子;eGFR 低提示肾功能受损,糖尿病肾病患者再入院风险高有文献支持;胰岛素使用可能反映病程更长、病情更重,也可能与低血糖事件有关,但我们的数据里没有低血糖记录,不能下结论;住院天数长可能反映病情复杂。

临床意义:入院 24 小时内的常规数据就能算,可以嵌到电子病历里出院前提示高风险患者,让医生安排随访、药师做用药教育;但模型只是筛查,不能替代临床判断。

局限:单中心;回顾性;没有外部验证;缺失值用中位数填补;没有社会经济、家庭支持等变量;再入院只统计了本院,去外院的没算;没有做前瞻性干预试验证明用了模型能降低再入院。

未来:多中心外部验证;前瞻性研究看嵌入工作流后再入院率是否下降;加入社会因素。

结论想表达:模型能用常规数据较准确识别高风险患者,可解释,有潜力支持出院前决策,但要外部验证。
