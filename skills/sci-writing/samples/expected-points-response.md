# 回归评审要点:Response to Reviewers(对应 reviewer-comments.md)

合格输出必须同时满足以下各条。逐条打 ✓/✗,任一 ✗ 需回写对应 reference 或 SKILL.md 路由。

1. **结构**:给编辑的开头段(感谢、总述修改范围、说明标注方式)→ 每位审稿人一节 → 每条意见按「审稿意见原文(或摘述)→ 回复 → 修改位置与修改后文字摘录」三段式;编号与原意见一致(R1-1 … R2-3)。
2. **逐条不漏**:6 条意见全部回复,没有合并跳过;每条都有明确的修改位置(节号/表号/页行占位)。
3. **三类处理分明**:接受并修改(R1-3、R2-1、R2-3)、部分接受并说明限制(R1-1、R1-2)、无法执行并给出理由与替代(R2-2);语气一致礼貌,不争辩审稿人的动机。
4. **不编造**:回复内容只用作者说明里给的事实与数字;不添加新的分析、数字、文献;R2-2 的"引用已发表表现"处用 `[REF]` 占位;不写"我们做了外部验证"之类作者没做的事。
5. **数字准确**:填补方法(训练集中位数)、敏感性分析结果(住院天数中位数 9 vs 7 天,P=0.01;年龄性别无显著差别)、bootstrap 1000 次 CI、逻辑回归 AUC 0.76→0.78、XGBoost 0.84 全部正确出现。
6. **弱化表述落实**:R1-1 的回复中给出修改后的结论句摘录,强度明显低于原稿(has the potential / warrants external validation),且摘要、讨论、局限三处都点到。
7. **拒绝有据**:R2-2 说明缺哪些变量(急诊就诊次数、肿瘤诊断)导致无法计算,提供替代(讨论中间接比较 + 写入局限),不含歉意堆叠。
8. **英文质量**:美式拼写、ASCII;不用 So / And 起句;每条回复主体不超过约 150 词;标准礼貌句式(We thank the reviewer for …、We agree that …、We have revised …)不重复到机械。
9. **不越权**:不代作者承诺未说明的后续实验;不修改作者的立场(如把 R2-2 改成同意加实验)。
10. **自检结果**:按 SKILL.md 五项核心 + 12 号文件审稿回复相关条目中 ✗ 的项;附「建议补充」(如需要作者提供修改稿页行号)。
