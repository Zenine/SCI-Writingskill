# 回归评审要点:Abstract(对应 abstract-draft-zh.md)

合格输出必须同时满足以下各条。逐条打 ✓/✗,任一 ✗ 需回写对应 reference 或 SKILL.md 路由。

1. **功能步完整且顺序对**:背景 → 已知但未知式问题陈述(陈述句,不用问句)→ 本文做了什么(Here we / In this study, we)→ 方法要点 → 主要结果 → 含义/价值;输出的「结构」部分能把每句对到功能步。
2. **字数与句长**:200–250 词;平均句长 ≤ 25 词、单句 ≤ 40 词;结果句单独不超过一半,方法与结果句合计不超过 60%。
3. **时态按功能**:背景与问题用现在时;本研究所做与所见用过去时;含义与主张用现在时;一句内不混用。
4. **关键数字齐全且格式规范**:样本量 1,563、划分 7:3、XGBoost AUC 0.84 (95% CI 0.80–0.88)、与两个基线的 AUC 对比、灵敏度与特异度;不遗漏、不改数字、不新增数字。
5. **SHAP 前五特征**:全部出现(HbA1c、住院天数、既往一年住院次数、eGFR、胰岛素使用),用英文标准术语与首次全称。
6. **强度匹配**:含义句一个避险成分(may / could 或 suggest 二选一);不出现 novel / first / significantly improves 一类无据强词;结论强度不超过结果("比较准确"→ accurately / with good discrimination,不夸大)。
7. **局限一句并入含义**:单中心、无外部验证在摘要中以一句或半句带出,并与后续工作合并,不作结尾;或按 05 规则说明摘要可省局限时写明理由。
8. **缩写**:SHAP、HbA1c、eGFR 首次给全称(或用全称不缩写);AUC、CI 等临床公认缩写可直接用(05 细则 11);XGBoost 可不展开但需一致。
9. **无主语危险句式**:不出现 It is argued that / It is shown that 一类无归属句;每个发现句有 we / this study / 过去时归属。
10. **不编造**:不添加草稿没有的信息(P 值、随访方式、具体干预措施);医院名用占位或省略。
11. **自检结果**:五项核心 + 05 号清单中 ✗ 的条目;附 3–5 条 Highlights 属加分项,不作必需。
