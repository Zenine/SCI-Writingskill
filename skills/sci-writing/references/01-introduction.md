# Introduction(引言)写法

## 何时读本文件

- 用户要写、改写或润色英文论文的 Introduction / Background 部分。
- 用户已有中文引言草稿,需要转成符合英文期刊惯例的结构。
- 审稿意见指出"motivation 不清""文献综述像清单""不知道本文贡献是什么"。
- 写讨论或结论时需要回头核对引言立下的问题(引言与讨论是镜像;另见 `04-discussion-conclusion.md`)。
- 本文件提到的其它 reference 只是出处指引;执行时以 SKILL.md 路由表的「先读 / 再读」为必读范围。

前置约定:写作顺序、文体与目标期刊的确认属总流程前置约定(引言不宜第一个写;另见 `00-workflow.md`);模板是对已发表论文惯例的归纳,目标期刊近 5 年同类文章的做法优先于本文件(`SKILL.md` 硬规则 8);每句都要能回答"这句在为读者做什么",答不出的删除或合并。

## 结构与规则

引言的信息流是"由宽到窄":领域 → 已有研究 → 空白 → 本文。四组功能是一份菜单,第 1 组必须在开头、第 4 组必须在结尾,第 2、3 组的显隐程度按领域惯例调整。

| 步骤 | 功能 | 信息流 | 典型信号 |
|---|---|---|---|
| 1 进入领域 | 主题为何重要;理解全文所需的背景事实;领域当前的一般性问题 | 从最多读者共享的知识起步,每句只比上句具体一步 | has attracted / plays a key role / is widely used |
| 2 研究地图 | 串联已有研究,让读者看到本文在领域中的坐标 | 组织模式三选一:一般到具体(最常用)/ 按方法或理论分组 / 按时间 | were the first to / was further developed by |
| 3 转向本文 | 指出空白、缺陷、矛盾,或提出动机、假设、机会 | 由 However / Although / Despite 引出;必要时插入第二轮更具体的背景 | however / remains unclear / few studies have |
| 4 介绍本文 | 本文做什么;可选:目的、方法概要、主要结果(默认不预告,只写目标与做了什么;目标期刊近 5 年惯例明确预告时才加一句不带数字的主要结果)、文章结构 | 收口;方法与结果只做一句概述 | this paper presents / the aim of this work is |

时态(展开见 `08-verbs-tense-voice.md`):

| 内容 | 时态 |
|---|---|
| 公认事实、背景、描述本文自身;研究目的默认现在时(可过去时,全篇统一) | 一般现在时 |
| 某研究当时的发现 | 一般过去时 |
| 带时间短语的重要性声明(in recent years);空白句(little attention has been paid;或 remains unclear 类现在时) | 现在完成时 |

细则:

1. 第一句是宽泛而公认的事实或重要性声明,不是本文的具体问题。第一段按 Why-Why-Why 倒序展开(最宏观的先写,每层背景附引用,末句落到本文问题;另见 `11-ethics-and-readers.md`);综合性期刊强制宏观入口,专业期刊可从关键术语定义或事实起步(另见 `05-abstract.md`)。
2. 开头几句之间不得"很宽 → 很窄"跳跃;背景宁多勿少。
3. 重要性声明依赖"当前"状态或具体数字时加年份;原稿无年份用 `[year]` 占位并进「建议补充」,不自行编造年份。
4. 研究地图只收"能通向本文动机"的研究。
5. 同类研究归为一组,不逐句 however / on the other hand 来回转折。
6. 引文紧贴它支持的那部分内容,不统一堆在句尾(句尾引文会被读成"整句都来自这些文献")。
7. 空白用陈述句(待验证的假设、建议、机会)表达,不用问句;目标期刊惯例允许时可列研究问题清单。
8. 批评前人客观、克制。
9. 介绍本文的主语策略三选一:we / 被动 / 非人称主语(This paper, This study),检查标准是所有权可辨认,被动句能靠 here / in this study 辨认归属(另见 `08-verbs-tense-voice.md`);全篇 we 只指本文作者。
10. 本文介绍句中的评价词须能由结果节证据支撑(如 interpretable、diabetes-specific、externally validated 这类可指到具体结果的词),强度不得超过结果所能支撑的程度;novel / robust / first 无据不用,有据可用(另见 `10-chinese-author-pitfalls.md` W3、`09-academic-style.md` 规则 7、9 与 `05-abstract.md`)。
11. 引言立下的问题或空白,讨论和结论必须逐一回应,用相同的关键动词和名词(回声原则);二级标题层面一一对应(另见 `00-workflow.md` 步 3 与 `06-title-keywords.md`)。
12. 一段一功能,首句预告该段走向;不得连续单句段落。
13. 句长与段长数字见 `09a-metrics-table.md`,本文件不另立数字。
14. 句间连接四法:重叠(下一句开头重复上一句结尾的概念)、替代指代(This method,名词与首次出现时相同)、分号、信号词;不必每句以信号词开头。
15. 同一概念全篇用同一术语,不为"避免重复"换同义词。

## 英文模板与短语

**确立重要性 / 开篇**
- X has attracted considerable attention in recent years
- X has been extensively studied
- X plays a key role in Y
- X is widely used in Y
- a central problem in X is
- an emerging technology for

**串联已有研究**
- [ref] were the first to
- a pioneering study by [ref] demonstrated that
- a similar approach was adopted by [ref], who
- an alternative approach was proposed by [ref]
- this approach was further developed by [ref]
- taken together, these studies suggest that

**报告前人工作的精确动词**(替代 did / showed / found)
- investigated / examined / analyzed / evaluated
- developed / proposed / put forward
- demonstrated / established / confirmed
- identified / characterized / reported / reviewed

**指出缺陷**(由 however / although / despite 引出)
- a major drawback of X is
- X suffers from / X fails to
- X is limited by / X is not sufficiently
- X is time-consuming and costly
- X remains controversial

**指出空白 / 研究机会**(否定 + 现在完成时;may / could)
- little is known about / little attention has been paid to
- few studies have
- X remains unclear / poorly understood
- X has not been addressed
- to the best of our knowledge / there is a need for
- 例:Few studies have examined whether X holds in Y, and its effect on Z remains unclear.

**介绍本文**(目的默认现在时,可过去时,全篇统一;评价词见细则 10,信号词见 `07-paragraph-logic.md`)
- in this paper, we present / propose / report
- this study focuses on
- the aim of this work is / was to
- to address this question, we investigated
- here, we describe / we show that
- 例:Here, we present a method that combines X with Y to improve Z.

## 常见错误

| 错误模式 | 修正原则 |
|---|---|
| 第一句直接抛本文要解决的具体问题 | 先给公认事实或重要性声明作"集合点",再逐句收窄 |
| 第二句就从领域跳到本文的具体材料/算法 | 每句只比上句具体一步;补中间层背景 |
| 文献综述是按年份或按作者排列的清单 | 选一种组织模式,每条文献都指向本文动机 |
| 逐句 however 来回打乒乓 | 同类研究归堆,再用一次转折引出空白 |
| 用问句抛出研究问题 | 改为待验证的假设或建议的陈述句 |
| 引文统一堆在句尾 | 引文紧贴它支持的那部分内容 |
| we 一会儿指作者、一会儿泛指领域 | we 只指作者;泛指改用 It is known that |
| 引言里把方法和结果展开写 | 各只保留一句概述,细节留给对应章节 |
| 引言与讨论/结论的目标措辞对不上 | 用相同的动词和名词造回声;得到结果后回头改引言 |
| 正面评价词强度超过结果 | 评价词强度与证据匹配;润色或翻译后重新核对 |

## 自检清单

1. 能标出第 1 组(重要性/背景)在开头、第 4 组(本文)在结尾;第 2、3 组若弱化能说明领域惯例。✓/✗
2. 第一句是宽泛的公认事实或重要性声明;第一段按 Why-Why-Why 倒序,每层背景附引用。✓/✗
3. 开头几句之间没有"很宽 → 很窄"的跳跃。✓/✗
4. 背景事实用一般现在时;带时间短语的重要性声明用现在完成时。✓/✗
5. 每处时态切换都能说出前后功能有何不同。✓/✗
6. 每一项被引研究都能回答"它如何通向本文动机"。✓/✗
7. 文献综述采用了明确的组织模式,同类研究归为一组。✓/✗
8. 引文位置紧贴其支持的内容,没有整句堆在句尾。✓/✗
9. 空白句用否定 + 现在完成时或 remains unclear 类现在时,由转折词引出。✓/✗
10. 空白用陈述句表达,没有问句。✓/✗
11. 介绍本文用一般现在时;目的句默认现在时,可用过去时,全篇统一一种;方法和结果各只有一句概述。✓/✗
12. 评价词都能由结果节证据支撑,强度不超过结果支撑的程度;无据的 novel / robust / first 已删。✓/✗
13. we 全篇只指本文作者;This / It / They 开头时所指唯一。✓/✗
14. 同一概念全篇只用一个术语。✓/✗
15. 每段只承担一个功能,只读各段首句能复述引言脉络。✓/✗
16. 没有连续的单句段落;段长数字见 `09a-metrics-table.md`;从短草稿改写时段落均值不作硬指标,只看 80–230 词区间。✓/✗
17. 句长数字见 `09a-metrics-table.md`,超阈值的句子已拆分或说明理由;从短草稿改写时同第 16 条。✓/✗
18. 引言立下的每个空白/目标在讨论或结论中都有对应回应,措辞一致;只写引言、讨论与结论尚无稿时标 N/A。✓/✗/N/A
