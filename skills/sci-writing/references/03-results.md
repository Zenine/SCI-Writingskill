# Results(结果)写法

> 来源:书A 第3单元

## 何时读本文件

- 用户要写、改写或润色 Results 或 Results and Discussion 中"报告发现"的部分。
- 用户把结果写成了图表清单或数字罗列,需要改成有导览、有轻重、有评价的叙述。
- 审稿意见指出"overclaiming""结果与结论脱节""因果表述超出数据支撑"。
- 需要把某条发现的"确定程度"表达到位(动词、时态、hedging、情态动词的组合)。
- 本文件提到的其它 reference 只是出处指引;执行时以 SKILL.md 路由表的「先读 / 再读」为必读范围。

前置约定:结果、讨论、结论分写还是合写由目标期刊和研究本身决定,本文件按分写讲;合写时"含义"部分按讨论节处理(另见 `04-discussion-conclusion.md`)。结果节允许评价性语言和一句式含义,深入解释与外推留给讨论。结果节只与本文的预测、模型、假设比较;与前人文献的比较默认放讨论(另见 `12-submission-checklist.md` 第 22 条);Results and Discussion 合写或目标期刊惯例允许时例外,并在「理解确认」注明。

## 结构与规则

结果节是"读结果的导览",不是结果的仓库。信息流主线:回顾 → 展示 → 评论 → 含义。四个层次、九种句子功能是菜单,不必全用。

| 层次 | 组件功能 | 信息流作用 |
|---|---|---|
| 1 开场 | (a) 回顾目的 / 预测 / 假设 / 空白;(b) 回顾或概述本研究方法;(c) 对结果整体模式的宽泛陈述;(d) 引导读者看图并说明图里是什么 | 让从摘要直接跳来的读者与通读者站在同一起点;先搭"墙"再给"砖" |
| 2 主体 | (e) 关键结果 + 评价性语言;(f) 与本文的预测 / 模型 / 假设比较(与前人文献的比较留给讨论,见前置约定);(g) 用已知事实或方法细节解释结果为何如此 | 挑关键结果重点写、其余略写;比较把结果定位到本文的预期;解释限于对数据的直接说明 |
| 3 问题 | (h) 结果中的问题 / 缺陷 ± 原因 | 显示作者掌控全局;埋下未来工作 |
| 4 收束 | (i) 结果的可能含义或应用,用积极词回应引言目标 | 把焦点从"报告"转向"讨论";一个避险成分(suggest / indicate 类汇报动词或 may / could 类情态,二选一) |

细则:

1. 开头三选一:概述整体趋势(Overall / In general)并引导看汇总图表;重述研究目标;回顾方法要点。不得以第一个原始数据点开头。
2. 不按实验时间顺序罗列;按研究问题分块,块内:总体 → 关键 → 次要 → 问题 → 含义。每块内的单条结果按下面"四要素段落"写。
3. 图表放置:数据清晰无歧义时可先给图后评论;有多种解读可能时,评论放在引导看图的句子之前或同一句内。
4. 每张图/表被引用时必须附一句作者的评价或解读,不得只写 X is shown in Fig. n。
5. 轻重处理:不对所有结果同等详细;用 Importantly / Notably 标记重要结果;先给总体判断,再用 for example 引出典型数值。
6. 客观 vs 主观:A 比 B 高是事实(higher),A 本身"高"是评价(high);裸比较级对读者没有增量,加评价修饰(slightly / much lower),方向须与数据一致且有对比基准(另见 `08-verbs-tense-voice.md`、`05-abstract.md`)。
7. 陈述某现象发生时带频率修饰词或具体比例;频率相对预期而言(前人认为不会发生的事出现 22% 可称 frequent)。
8. 至少一处把本文结果与本文的预测、模型或假设显式比较;与前人文献的比较已留给讨论(合写例外)。
9. 结果中的问题、缺口、异常值在结果节承认,并用淡化 / 去责 / 给方向至少一种措辞。
10. 转折、评价、遗憾类信号词(However / Unfortunately / Interestingly)放句首。
11. 不用感叹号;惊喜用 striking / remarkable / unexpected 表达。
12. 时态:本文发现默认过去时(有意提升为普遍事实时才用现在时);图中可见现在时,数据获得过去时;背景事实现在时(展开见 `08-verbs-tense-voice.md`)。
13. 含义句只保留一个避险成分(suggest / indicate 类汇报动词,或 may / could 类情态,二选一),点到为止;档位与证据匹配,尺子是下文确定性连续统(另见 `08-verbs-tense-voice.md`,其阶梯表引用本表)。strongly suggest 不算叠加。
14. 含义或应用句回应引言目标的用词(引言说 improve accuracy,结果说 more accurate);得到结果后回头核对引言,必要时改引言。
15. 结果节应能独立成篇:直接从摘要跳来的读者仅凭结果节即可理解做了什么、发现了什么。
16. 小节数量、小标题形式、图表顺序向目标期刊近期论文看齐;小标题优先用动词说出关系,期刊只允许短语式时用含关系的名词短语(Effects of X on Y / Association between X and Y),两种形式下都不得只给主题名词(另见 `06-title-keywords.md` 规则 3)。

局限性位置链式规则(02 / 03 / 04 三处同文):方法、结果中已知的问题在各自节首次提及;只有"需进一步工作才能下结论"与"研究期间的非正式证据"两类可在讨论首次出现;讨论中后段集中一处(医学期刊常单列 Limitations 小节);结论最多一句并与未来工作合并;讨论与结论都不以局限收尾。

### 单条结果的四要素段落

每个结果段(或一个研究问题下的一块)按四要素写(另见 `12-submission-checklist.md` 第 22 条):

1. 目标句:这块结果回答哪个问题或检验哪个假设(To test whether ... / To assess ...)。
2. 位置句:数据在哪张图表(Fig. n / Table n),可与下一要素合为一句。
3. 核心发现:带评价修饰与具体数值的关键结果,次要结果略写。
4. 总结/含义句:一句,一个避险成分,回应引言目标用词。
- 例:To assess whether pretraining improved robustness, we compared the two models on the external test set (Table 3). The pretrained model retained an AUC of 0.88, whereas the baseline dropped to 0.79, a markedly larger decline. Pretraining thus appears to reduce the loss of performance across sites.

### 数量与频率的评价词

| 读者应感到 | 位置 | 词例 |
|---|---|---|
| 差异大 | 比较级前 | markedly, substantially, considerably, far, well |
| 差异小或可忽略 | 比较级前或数值前 | approximately, roughly, nearly, virtually, negligible |
| 数量多 | 数值前 | as many as, well over, numerous, substantial |
| 数量少 | 数值前 | only, as few as, barely, marginal, minimal |
| 不表态 | 任意 | some, somewhat, relatively, fairly, moderate |

频率四档(高 → 低):always / invariably;usually / generally / in most cases;sometimes / occasionally / in some cases;rarely / seldom / hardly ever。频率副词或具体比例二选一,不两者都省。

### 因果动词的强弱谱

强 → 弱:直接因果(cause / result in / give rise to,只在证据支持因果时用)→ 部分原因或因果过程(contribute to / lead to / drive)→ 因果链起点(originate in / arise from / result from,方向与 result in 相反)→ 产出(yield / generate)→ 间接不指方向(be associated with / correlate with,相关性数据只能用这一档)。方向由动词决定:X produced Y(X 因);X originated in Y(Y 因)。冠词决定唯一性:a cause of(多因之一)/ the cause of(唯一)。

### 确定性连续统(certainty continuum)

结果节要传达两种信心:"我做的事导致了这个结果"有多确定;"这个结果意味着什么"有多确定。先定位信心在连续统上的位置,再用下表匹配语言。本表是本 skill 的母表,`08-verbs-tense-voice.md` 的阶梯表与 `04-discussion-conclusion.md` 的情态说明只引用本表、不另立档位。一句只在一个杠杆上选一个点,其余杠杆保持中性;不为保险而叠加。

| 杠杆 | 强 | 中 | 弱 |
|---|---|---|---|
| 汇报动词 | demonstrate / show / establish(prove 仅限数学证明) | indicate / suggest / support | (无弱档;弱化改用降险短语或情态) |
| 因果动词 | causes / results in | leads to / contributes to | is related to / is associated with |
| 时态 | 现在时(永久事实:is related to) | — | 过去时(本研究所见:was related to) |
| 降险短语(hedging) | 无 | appears to / seems to / tends to(固定为中档) | it is possible that / there is some evidence that |
| 情态与范围限定 | 无 | may / could;in most cases | might / perhaps / presumably(正规弱档用法);in some cases / under certain conditions |

含义 / 解释的引导结构按强弱:

| 档位 | 表达 |
|---|---|
| 强 | this provides strong evidence for / it is evident that / it may be concluded that |
| 中 | this suggests that / these results indicate that / it is likely that / we propose that |
| 弱 | it appears that / it is possible that / this may imply that / we speculate that |

### 统计与模型指标的报告格式

医学与数据驱动结果的一句式骨架(医学期刊通行格式,不出自两书);格式须与方法节统计小节的声明一致,每个主指标带 CI 或 P 值:

- The model achieved an AUC of [x] (95% CI [a] to [b]) on the external test set, compared with [y] (95% CI [a] to [b]) for [baseline].
- At the prespecified threshold, sensitivity was [x]% (95% CI [a] to [b]) and specificity was [y]% (95% CI [a] to [b]).
- [Outcome] occurred in [n] of [N] patients ([%]) in group A versus [n] of [N] ([%]) in group B (OR [x], 95% CI [a] to [b]; P = [p]).
- The mean difference between groups was [x] units (95% CI [a] to [b]; P = [p]).

## 英文模板与短语

**回顾与过渡(开场)**
- Previous studies have reported that
- As described in Section 2,
- The aim of this experiment was to
- Overall, / In general, / In most cases,

**邀请看图表**(in = 图里直接可见;from = 可由图中数据推断)
- Fig. 1 shows(全篇图表引用只选一个动词;另见 `08-verbs-tense-voice.md` 规则 4)
- As can be seen in / from Fig. 1,
- Results are given in Table 2
- X is apparent from Fig. 1 / X is clearly visible in Fig. 1
- (see Fig. 1) / (data not shown)

**评价性评论与信号**
- Importantly, / Notably, / Interestingly, / Surprisingly,
- It is noteworthy that
- striking / marked / pronounced / remarkable
- subtle / minor / modest / negligible

**与本文预测 / 模型 / 假设比较**(与前人文献比较的短语另见 `04-discussion-conclusion.md`)
- consistent with / in line with / in good agreement with
- comparable to / broadly similar to
- as expected / as predicted / as hypothesized
- in contrast to / contrary to / deviate from
- 例:The observed decline is in good agreement with the model prediction, but the effect was smaller than we had hypothesized.

**问题与议题**
- 淡化:negligible / minor / not significant / less than ideal
- 去责:unfortunately / inevitably / it was not possible to / not within the scope of this study
- 转向好的方面:nevertheless / despite this / reasonably robust
- 给出方向:future work should / further work is required / is currently underway
- 例:Unfortunately, the sample size in this subgroup was too small to draw firm conclusions; nevertheless, the trend was consistent with the main cohort.

## 常见错误

| 错误模式 | 修正原则 |
|---|---|
| 以第一个原始数据点开头 | 前三句内给整体趋势概述、目标重述或方法回顾之一 |
| 只写 X is shown in Fig. 3,不评论 | 每次引用图表都附一句评价或解读 |
| 所有结果同等详细 | 关键结果展开并标记(Importantly),其余略写 |
| 裸数字、裸比较级(X was higher) | 加评价修饰(slightly / markedly higher; only / as many as 23%) |
| 主指标只给点估计 | 补 95% CI 或 P 值,格式与方法节一致 |
| 相关性数据用 cause / result in | 降到 be associated with / correlate with 一档 |
| 含义句叠加 suggest + may + possibly;或无限定的 proves | 只留一个避险成分,在连续统上定一个档位;不用 prove |
| 结果节与前人文献逐条比较 | 与本文预测 / 模型比较;文献比较留给讨论(合写例外) |
| 问题和异常值只字不提 | 在结果节承认,并用淡化 / 去责 / 给方向措辞 |
| 结果的应用句与引言目标用词对不上 | 用引言的关键词造回声 |

## 自检清单

1. 开头三句内有整体趋势概述、目标重述或方法回顾之一。✓/✗
2. 结果按研究问题分块、块内按叙述逻辑组织,不是按实验时间顺序;每个结果段含目标句、结果句、总结句。✓/✗
3. 每张图/表被引用时都有一句评价或解读。✓/✗
4. 多解读的图表,评论在引导看图之前或同一句内。✓/✗
5. 关键结果都带评价性语言,没有裸数字或裸比较级。✓/✗
6. 每个数量评价词都能归入差异大 / 差异小 / 多 / 少 / 不表态之一,方向与数据一致且有对比基准。✓/✗
7. 每个"发生"陈述都带频率修饰或具体比例。✓/✗
8. 至少一处与本文预测、模型或假设显式比较;与前人文献的比较已留给讨论(合写例外)。✓/✗
9. 转折、评价、遗憾类信号词在句首。✓/✗
10. 没有感叹号。✓/✗
11. 图中可见用现在时,数据获得用过去时;本文发现默认过去时。✓/✗
12. 每个因果动词的强度与证据匹配;相关性数据没有用 cause。✓/✗
13. 每个含义句只有一个避险成分,档位与证据匹配;没有无限定的 prove。✓/✗
14. 结果中的问题、异常值已承认,并有淡化 / 去责 / 给方向之一。✓/✗
15. 直接从摘要跳来的读者仅凭结果节能理解做了什么、发现了什么。✓/✗
16. 应用/含义句回应了引言目标的用词。✓/✗
17. a cause / the cause 等冠词与"是否唯一"一致。✓/✗
18. 已回头核对引言目标,必要时改了引言。✓/✗
19. 小节数、小标题形式、图表顺序与目标期刊近期论文一致。✓/✗
20. 每个主指标带 CI 或 P 值,格式与方法节统计小节声明一致。✓/✗
