# Results(结果)写法

> 来源:书A 第3单元

## 何时读本文件

- 用户要写、改写或润色 Results 或 Results and Discussion 中"报告发现"的部分。
- 用户把结果写成了图表清单或数字罗列,需要改成有导览、有轻重、有评价的叙述。
- 审稿意见指出"overclaiming""结果与结论脱节""因果表述超出数据支撑"。
- 需要把某条发现的"确定程度"表达到位(动词、时态、hedging、情态动词的组合)。

前置约定:结果、讨论、结论分写还是合写由目标期刊和研究本身决定,本文件按分写讲;合写时把"含义"部分交给 `04-discussion-conclusion.md`。"结果只写事实、不许解读、只用过去时"与已发表论文的实际做法不符;结果节允许评价性语言和一句式含义,深入解释与外推留给讨论。

## 结构与规则

结果节是"读结果的导览",不是结果的仓库。信息流主线:回顾 → 展示 → 评论 → 含义。四个层次、十种句子功能是菜单,不必全用。

| 层次 | 组件功能 | 信息流作用 | 常用时态 |
|---|---|---|---|
| 1 开场 | (a) 回顾目的 / 预测 / 假设 / 空白;(b) 回顾或概述本研究方法;(c) 对结果整体模式的宽泛陈述;(d) 引导读者看图并说明图里是什么 | 让从摘要直接跳来的读者与通读者站在同一起点;先搭"墙"再给"砖" | 回顾前人:过去时 / 现在完成时;本文方法:过去时;图中内容:现在时 |
| 2 主体 | (e) 关键结果 + 评价性语言;(f) 与其他研究结果比较;(g) 与模型 / 模拟 / 预测比较;(h) 用已知事实或方法细节解释结果为何如此 | 挑关键结果重点写、其余略写,以此传达轻重;比较把结果定位到文献;解释限于对数据的直接说明 | 本文发现:过去时;图中可见:现在时;背景事实:现在时;归因于方法:过去时 |
| 3 问题 | (i) 结果中的问题 / 缺陷 ± 原因 | 显示作者掌控全局;埋下未来工作 | 过去时;去责 / 淡化词 |
| 4 收束 | (j) 结果的可能含义或应用,用积极词回应引言目标 | 把焦点从"报告"转向"讨论",打开通往讨论的路 | suggest / indicate + may / could;现在时 |

细则:

1. 开头三选一:概述整体趋势(Overall / In general)并引导看汇总图表;重述研究目标为评估结果设背景;回顾方法要点(方法在补充材料或很长时尤其常用)。不得以第一个原始数据点开头。
2. 不按实验发生的时间顺序罗列;按叙述逻辑组织:总体 → 关键 → 次要 → 问题 → 含义。先用基础性图表铺垫,再引出最重要的结果。
3. 图表放置:读者读到 Fig. 1 shows 会停下看图、形成自己的解释再回来。数据清晰无歧义时可先给图后评论;有多种解读可能时,评论放在引导看图的句子之前或同一句内。
4. 每张图/表被引用时必须附一句作者的评价或解读,不得只写 X is shown in Fig. n。
5. 轻重处理:不对所有结果同等详细;用 Importantly / Notably 显式标记重要结果;常见手法是先给总体判断,再用 for example 引出典型数值。
6. 客观 vs 主观:说 A 比 B 高是事实(higher),说 A 本身"高"是评价(high);已发表论文几乎总带评价修饰(slightly lower / much lower),因为裸比较级对读者没有增量。
7. 陈述某现象发生时带频率修饰词或具体比例;频率是相对预期而言的:前人认为不会发生的事出现 22% 可称 frequent,前人认为必然发生的事只出现 22% 可称 rare。
8. 至少一处把本文结果与前人结果、预测或模型显式比较。
9. 结果中的问题、缺口、异常值在结果节承认,并用淡化 / 去责 / 给方向至少一种措辞。
10. 转折、评价、遗憾类信号词(However / Unfortunately / Interestingly)放句首,不放句末。
11. 不用感叹号;惊喜用 striking / remarkable / unexpected 表达。
12. 时态:本文发现默认过去时,只有作者有意将其提升为普遍事实时才用现在时;图中可见用现在时,数据如何获得用过去时;背景事实现在时,归因于本研究方法过去时。
13. 含义句用 suggest / indicate + may / could,点到为止。
14. 含义或应用句回应引言目标的用词(引言说 improve accuracy,结果说 more accurate);得到结果后回头核对引言的目标陈述,必要时改引言。
15. 结果节应能独立成篇:直接从摘要跳来的读者仅凭结果节即可理解做了什么、发现了什么。
16. 小节数量、小标题形式(短语式或陈述句式)、图表顺序向目标期刊近期论文看齐。

### 数量与频率的评价词

| 组别 | 用途 | 词例 |
|---|---|---|
| 放大数量 | 让读者觉得多 | considerable, substantial, as many as, numerous, well over |
| 缩小数量 | 让读者觉得少 | only, barely, as few as, marginal, minimal, hardly |
| 强调程度 | 放比较级前 | considerably, markedly, substantially, far, even, well |
| 接近 / 相近 | 表示差异不重要 | approximately, roughly, close to, nearly, virtually, negligible |
| 中性 | 不想表态 | some, somewhat, relatively, fairly, moderate, to some extent |

频率十级(高 → 低):always / invariably → generally / usually / normally → often / frequently / commonly → more often than not → as often as not → sometimes / at times → occasionally / from time to time → rarely / seldom / infrequently → hardly ever / almost never → never / at no time。

### 因果动词的强弱谱

| 强度 | 动词 | 说明 |
|---|---|---|
| 直接因果 | cause, produce, be due to, result in, give rise to | 只在证据支持因果时用 |
| 部分原因 | contribute to, be a factor in | 多因之一 |
| 因果过程 | lead to, drive, initiate | 有链条 |
| 因果链起点 | originate in, arise from, result from | 方向与 result in 相反 |
| 产出而非效果 | yield, generate | 产物 |
| 间接 / 不指方向 | be related to, be linked to, be associated with, correlate with, accompany | 相关性数据只能用这一档 |

方向由动词决定:X produced Y(X 因 Y 果);X originated in Y(Y 因 X 果)。冠词决定唯一性:a cause of(还有其他因素)/ the cause of(唯一)。

### 确定性连续统(certainty continuum)

结果节要传达两种信心:"我做的事导致了这个结果"有多确定;"这个结果意味着什么"有多确定。先定位信心在连续统上的位置,再用下面四个可叠加的杠杆匹配语言;每个含义陈述至少动用两个杠杆。

| 杠杆 | 强 | 中 | 弱 |
|---|---|---|---|
| 因果动词 | causes / results in | leads to / contributes to | is related to / is associated with |
| 时态 | 现在时(永久事实:is related to) | — | 过去时(本研究所见:was related to) |
| 降险短语(hedging) | 无 | appears to / seems to / tends to | it could be inferred that / there is evidence to suggest that / the evidence points to the possibility that |
| 情态与范围限定 | 无 | may / could | might;in some cases / under certain conditions;加频率与数量修饰 |

自拟示范梯度(同一结构句,从绝对确定到高度保留;每条都是「例:」):
1. 例:We found that A causes B.
2. 例:We found that A may cause B.
3. 例:We found evidence to suggest that A may be related to B.
4. 例:It appears that, in some cases, A may have been related to B.
5. 例:The evidence points to the possibility that, in some cases, A may have contributed to B.

含义 / 解释表达按强弱:

| 档位 | 表达 |
|---|---|
| 强 | this provides strong evidence for / it is evident that / it may be concluded that / we are confident that |
| 中 | this suggests that / these results indicate that / it is likely that / this is indicative of / we propose that |
| 弱 | it appears that / it seems that / it could be inferred that / it is possible that / this may imply that / we speculate that / presumably / perhaps |

## 英文模板与短语

**回顾与过渡(开场)**
- Previous studies have reported that
- As described in Section 2,
- In the present study, X was measured using
- The aim of this experiment was to
- Overall, / In general, / In most cases,
- 例:Overall, the model performed consistently across all three cohorts (Table 2).

**邀请看图表**(in = 图里直接可见;from = 可由图中数据推断)
- Fig. 1 shows / illustrates / summarises
- As can be seen in / from Fig. 1,
- Results are given in Table 2
- X is apparent from Fig. 1 / X is clearly visible in Fig. 1
- (see Fig. 1) / (data not shown)
- Inspection of Fig. 1 indicates that

**客观结果动词**
- increased / decreased / rose / fell
- peaked at / reached a maximum of
- remained constant / was unchanged / remained stable
- exceeded / preceded / coincided with
- was present / was absent / was detected
- varied with / was identical to

**评价性评论与信号**
- Importantly, / Notably, / Interestingly, / Surprisingly,
- It is noteworthy that / It is important to note that
- striking / marked / pronounced / dramatic / remarkable
- subtle / minor / modest / negligible
- broadly / essentially / virtually / effectively
- 例:Notably, the improvement was most pronounced in the smallest subgroup.

**与其他结果 / 模型 / 预测比较**
- consistent with / in line with / in good agreement with
- comparable to / broadly similar to / essentially identical to
- as expected / as predicted
- in contrast to / contrary to / unlike / differ from
- compare well with / corroborate / support / confirm
- contradict / deviate from
- 例:This value is in good agreement with that reported by [ref], but differs from the model prediction.

**积极评价词**
- accurate / precise / reliable / robust
- effective / efficient / feasible
- improved / superior / satisfactory
- useful / valuable / advantageous

**问题与议题**
- 淡化:negligible / minor / of no consequence / not significant / less than ideal
- 去责:unfortunately / inevitably / unavoidable / it was not possible to / limited by / not within the scope of this study
- 转向好的方面:nevertheless / despite this / reasonably robust / fairly well
- 给出方向:future work should / further work is required / is currently underway
- 例:Unfortunately, the sample size in this subgroup was too small to draw firm conclusions; nevertheless, the trend was consistent with the main cohort.

## 常见错误

| 错误模式 | 修正原则 |
|---|---|
| 以第一个原始数据点开头 | 前三句内给整体趋势概述、目标重述或方法回顾之一 |
| 按实验时间顺序罗列 | 按叙述逻辑:总体 → 关键 → 次要 → 问题 → 含义 |
| 只写 X is shown in Fig. 3,不评论 | 每次引用图表都附一句评价或解读 |
| 有多种解读的图先让读者看,再评论 | 评论放在引导看图之前或同一句内 |
| 所有结果同等详细 | 关键结果展开并标记(Importantly),其余略写 |
| 裸数字、裸比较级(X was higher) | 加评价修饰(slightly / markedly higher; only / as many as 23%) |
| 说"X occurred"不带频率 | 加频率十级之一或具体比例 |
| 相关性数据用 cause / result in | 降到 be associated with / correlate with 一档 |
| result in 与 result from 方向写反 | 确认动词方向:X results in Y(X 因);X results from Y(Y 因) |
| 无任何限定的 proves / demonstrates conclusively | 用连续统至少两个杠杆定位;不用 prove |
| 满篇 may / might,结果其实很强 | 升级到 likely / probable;强弱与证据匹配 |
| 含义在结果节展开成整段机制讨论 | 结果节只一句 suggest / indicate,展开留给讨论 |
| 本文发现用现在时,读者以为是公认事实 | 默认过去时;现在时只用于有意提升为普遍事实 |
| However / Unfortunately 放句末 | 放句首,免得读者回读 |
| 用感叹号或口语化惊叹 | 用 striking / remarkable / unexpected |
| 问题和异常值只字不提 | 在结果节承认,并用淡化 / 去责 / 给方向措辞 |
| a cause / the cause 混用 | 唯一原因用 the,多因之一用 a |
| 结果的应用句与引言目标用词对不上 | 用引言的关键词造回声 |

## 自检清单

1. 开头三句内有整体趋势概述、目标重述或方法回顾之一。✓/✗
2. 结果按叙述逻辑组织,不是按实验时间顺序。✓/✗
3. 每张图/表被引用时都有一句评价或解读。✓/✗
4. 多解读的图表,评论在引导看图之前或同一句内。✓/✗
5. 关键结果都带评价性语言,没有裸数字或裸比较级。✓/✗
6. 每个数量评价词都能归入放大 / 缩小 / 强调 / 相近 / 中性之一,且方向与意图一致。✓/✗
7. 每个"发生"陈述都带频率修饰或具体比例。✓/✗
8. 至少一处与前人结果、预测或模型显式比较。✓/✗
9. 转折、评价、遗憾类信号词在句首。✓/✗
10. 没有感叹号。✓/✗
11. 图中可见用现在时,数据获得用过去时;本文发现默认过去时。✓/✗
12. 每个因果动词的强度与证据匹配;相关性数据没有用 cause。✓/✗
13. 每个含义陈述至少用了连续统的两个杠杆;没有无限定的 prove。✓/✗
14. 含义句只用 suggest / indicate + may / could 点到为止。✓/✗
15. 结果中的问题、异常值已承认,并有淡化 / 去责 / 给方向之一。✓/✗
16. 直接从摘要跳来的读者仅凭结果节能理解做了什么、发现了什么。✓/✗
17. 应用/含义句回应了引言目标的用词。✓/✗
18. a cause / the cause 等冠词与"是否唯一"一致。✓/✗
19. 已回头核对引言目标,必要时改了引言。✓/✗
20. 小节数、小标题形式、图表顺序与目标期刊近期论文一致。✓/✗

## 待与书B对照的点

- 结果节是否允许解读:书A主张评价语言和一句式含义是常规做法;书B若沿用"Results 客观 / Discussion 解读"分工,本文件采用"结果允许评价与一句含义,深入解释留给讨论"的折中。
- 评价性语言的度:书A鼓励 striking / as many as 引导读者;书B若警告 overclaiming,以连续统为检查尺:评价词方向与数据一致且不超过证据强度。
- 积极评价词(excellent / superior)与谦逊:书A视为常规;书B若建议避免自评形容词,限定为"有比较基准时可用"。
- 时态:书A允许结果节用现在时表达"永久事实";书B若规定结果一律过去时,本文件默认过去时,现在时作为需能自圆其说的有意选择。
- 确定性连续统与书B的动词/情态分级:书B第 6 章若有自己的强弱分级,合并时应对齐成一张表,避免两套术语并存。
- Results and Discussion 合写:书A只说看目标期刊;医学 SCI 多分写、工程/材料常合写,按目标期刊路由。
- 统计结果的报告格式(P 值、置信区间、效应量):书A几乎不涉及,是需从书B或其他来源补充的缺口。
