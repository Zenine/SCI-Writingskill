# Results(结果)写法

> 来源:书A 第3单元

## 何时读本文件

- 用户要写、改写或润色 Results 或 Results and Discussion 中"报告发现"的部分。
- 用户把结果写成了图表清单或数字罗列,需要改成有导览、有轻重、有评价的叙述。
- 审稿意见指出"overclaiming""结果与结论脱节""因果表述超出数据支撑"。
- 需要把某条发现的"确定程度"表达到位(动词、时态、hedging、情态动词的组合)。

前置约定:结果、讨论、结论分写还是合写由目标期刊和研究本身决定,本文件按分写讲;合写时把"含义"部分交给 `04-discussion-conclusion.md`。结果节允许评价性语言和一句式含义,深入解释与外推留给讨论。结果节只与本文的预测、模型、假设比较;与前人文献的比较默认放讨论(`12-submission-checklist.md` 第 22 条同此);Results and Discussion 合写或目标期刊惯例允许时例外,并在「理解确认」注明。

## 结构与规则

结果节是"读结果的导览",不是结果的仓库。信息流主线:回顾 → 展示 → 评论 → 含义。四个层次、九种句子功能是菜单,不必全用。

| 层次 | 组件功能 | 信息流作用 | 常用时态 |
|---|---|---|---|
| 1 开场 | (a) 回顾目的 / 预测 / 假设 / 空白;(b) 回顾或概述本研究方法;(c) 对结果整体模式的宽泛陈述;(d) 引导读者看图并说明图里是什么 | 让从摘要直接跳来的读者与通读者站在同一起点;先搭"墙"再给"砖" | 回顾前人:过去时 / 现在完成时;本文方法:过去时;图中内容:现在时 |
| 2 主体 | (e) 关键结果 + 评价性语言;(f) 与本文的预测 / 模型 / 假设比较(与前人文献的比较留给讨论,见前置约定);(g) 用已知事实或方法细节解释结果为何如此 | 挑关键结果重点写、其余略写,以此传达轻重;比较把结果定位到本文的预期;解释限于对数据的直接说明 | 本文发现:过去时;图中可见:现在时;背景事实:现在时;归因于方法:过去时 |
| 3 问题 | (h) 结果中的问题 / 缺陷 ± 原因 | 显示作者掌控全局;埋下未来工作 | 过去时;去责 / 淡化词 |
| 4 收束 | (i) 结果的可能含义或应用,用积极词回应引言目标 | 把焦点从"报告"转向"讨论",打开通往讨论的路 | 一个避险成分(suggest / indicate 类汇报动词或 may / could 类情态,二选一);现在时 |

细则:

1. 开头三选一:概述整体趋势(Overall / In general)并引导看汇总图表;重述研究目标为评估结果设背景;回顾方法要点(方法在补充材料或很长时尤其常用)。不得以第一个原始数据点开头。
2. 不按实验发生的时间顺序罗列;按研究问题分块,块内按叙述逻辑组织:总体 → 关键 → 次要 → 问题 → 含义。先用基础性图表铺垫,再引出最重要的结果。每块内的单条结果按下面"四要素段落"写。
3. 图表放置:读者读到 Fig. 1 shows 会停下看图、形成自己的解释再回来。数据清晰无歧义时可先给图后评论;有多种解读可能时,评论放在引导看图的句子之前或同一句内。
4. 每张图/表被引用时必须附一句作者的评价或解读,不得只写 X is shown in Fig. n。
5. 轻重处理:不对所有结果同等详细;用 Importantly / Notably 显式标记重要结果;常见手法是先给总体判断,再用 for example 引出典型数值。
6. 客观 vs 主观:说 A 比 B 高是事实(higher),说 A 本身"高"是评价(high);已发表论文几乎总带评价修饰(slightly lower / much lower),因为裸比较级对读者没有增量;评价修饰的方向须与数据一致,且有对比基准(裁决见 `08-verbs-tense-voice.md` 两书分歧第 8 条、`05-abstract.md` 两书分歧第 6 条)。
7. 陈述某现象发生时带频率修饰词或具体比例;频率是相对预期而言的:前人认为不会发生的事出现 22% 可称 frequent,前人认为必然发生的事只出现 22% 可称 rare。
8. 至少一处把本文结果与本文的预测、模型或假设显式比较;与前人文献的比较已留给讨论(合写例外)。
9. 结果中的问题、缺口、异常值在结果节承认,并用淡化 / 去责 / 给方向至少一种措辞。
10. 转折、评价、遗憾类信号词(However / Unfortunately / Interestingly)放句首,不放句末。
11. 不用感叹号;惊喜用 striking / remarkable / unexpected 表达。
12. 时态:本文发现默认过去时,只有作者有意将其提升为普遍事实时才用现在时;图中可见用现在时,数据如何获得用过去时;背景事实现在时,归因于本研究方法过去时。
13. 含义句只保留一个避险成分(suggest / indicate 类汇报动词,或 may / could 类情态,二选一),点到为止;档位与证据匹配,尺子是下文确定性连续统(`08-verbs-tense-voice.md` 的阶梯表引用本表)。strongly suggest 不算叠加。
14. 含义或应用句回应引言目标的用词(引言说 improve accuracy,结果说 more accurate);得到结果后回头核对引言的目标陈述,必要时改引言。
15. 结果节应能独立成篇:直接从摘要跳来的读者仅凭结果节即可理解做了什么、发现了什么。
16. 小节数量、小标题形式(短语式或陈述句式)、图表顺序向目标期刊近期论文看齐;小标题优先用动词说出关系,形式受限时按 `06-title-keywords.md` 规则 3 的兜底写法。

局限性位置链式规则(02 / 03 / 04 三处同文):方法、结果中已知的问题在各自节首次提及;只有"需进一步工作才能下结论"与"研究期间的非正式证据"两类可在讨论首次出现;讨论中后段集中一处(医学期刊常单列 Limitations 小节);结论最多一句并与未来工作合并;讨论与结论都不以局限收尾。

### 单条结果的四要素段落

每个结果段(或一个研究问题下的一块)按四要素写,`12-submission-checklist.md` 第 22 条按此检查:

1. 目标句:这块结果回答哪个问题或检验哪个假设(To test whether ... / To assess ...)。
2. 位置句:数据在哪张图表(Fig. n / Table n),可与下一要素合为一句。
3. 核心发现:带评价修饰与具体数值的关键结果,次要结果略写。
4. 总结/含义句:一句,一个避险成分,回应引言目标用词。
- 例:To assess whether pretraining improved robustness, we compared the two models on the external test set (Table 3). The pretrained model retained an AUC of 0.88, whereas the baseline dropped to 0.79, a markedly larger decline. Pretraining thus appears to reduce the loss of performance across sites.

### 数量与频率的评价词

按"想让读者感到什么"分组(自拟分组,不与任何词表逐组对应):

| 读者应感到 | 位置 | 词例 |
|---|---|---|
| 差异大 | 比较级前 | markedly, substantially, considerably, far, well |
| 差异小或可忽略 | 比较级前或数值前 | approximately, roughly, nearly, virtually, negligible |
| 数量多 | 数值前 | as many as, well over, numerous, substantial |
| 数量少 | 数值前 | only, as few as, barely, marginal, minimal |
| 不表态 | 任意 | some, somewhat, relatively, fairly, moderate |

频率四档(高 → 低):总是(always / invariably)/ 通常(usually / generally / in most cases)/ 有时(sometimes / occasionally / in some cases)/ 罕见(rarely / seldom / hardly ever)。用频率副词或具体比例二选一,不两者都省。

### 因果动词的强弱谱

| 强度 | 动词 | 说明 |
|---|---|---|
| 直接因果 | cause, produce, be due to, result in, give rise to | 只在证据支持因果时用 |
| 部分原因 | contribute to, be a factor in | 多因之一 |
| 因果过程 | lead to, drive, initiate | 有链条 |
| 因果链起点 | originate in, arise from, result from | 方向与 result in 相反 |
| 产出而非效果 | yield, generate | 产物 |
| 间接 / 不指方向 | be related to, be linked to, be associated with, correlate with, accompany | 相关性数据只能用这一档 |

方向由动词决定:X produced Y(X 因 Y 果);X originated in Y(Y 因 X 果)。冠词决定唯一性:a cause of(还有其他因素)/ the cause of(唯一)。

### 确定性连续统(certainty continuum)

结果节要传达两种信心:"我做的事导致了这个结果"有多确定;"这个结果意味着什么"有多确定。先定位信心在连续统上的位置,再用下表匹配语言。本表是本 skill 的母表,`08-verbs-tense-voice.md` 的阶梯表与 `04-discussion-conclusion.md` 的情态说明只引用本表、不另立档位。一句只在一个杠杆上选一个点,其余杠杆保持中性;不为保险而叠加。

| 杠杆 | 强 | 中 | 弱 |
|---|---|---|---|
| 汇报动词 | demonstrate / show / establish(prove 仅限数学证明) | indicate / suggest / support | (无弱档;弱化改用降险短语或情态) |
| 因果动词 | causes / results in | leads to / contributes to | is related to / is associated with |
| 时态 | 现在时(永久事实:is related to) | — | 过去时(本研究所见:was related to) |
| 降险短语(hedging) | 无 | appears to / seems to / tends to(固定为中档) | it is possible that / there is some evidence that |
| 情态与范围限定 | 无 | may / could;in most cases | might / perhaps / presumably(正规弱档用法);in some cases / under certain conditions |

含义 / 解释的引导结构按强弱:

| 档位 | 表达 |
|---|---|
| 强 | this provides strong evidence for / it is evident that / it may be concluded that |
| 中 | this suggests that / these results indicate that / it is likely that / we propose that |
| 弱 | it appears that / it is possible that / this may imply that / we speculate that |

- 例(强):These data show that pretraining improved cross-site robustness.
- 例(中):Pretraining appears to improve cross-site robustness.
- 例(弱):Pretraining might improve cross-site robustness in smaller cohorts.

### 统计与模型指标的报告格式

医学与数据驱动结果的一句式骨架(来源为医学期刊通行格式,不出自两书);格式须与方法节统计小节的声明一致,每个主指标带 CI 或 P 值:

- The model achieved an AUC of [x] (95% CI [a] to [b]) on the external test set, compared with [y] (95% CI [a] to [b]) for [baseline].
- At the prespecified threshold, sensitivity was [x]% (95% CI [a] to [b]) and specificity was [y]% (95% CI [a] to [b]).
- [Outcome] occurred in [n] of [N] patients ([%]) in group A versus [n] of [N] ([%]) in group B (OR [x], 95% CI [a] to [b]; P = [p]).
- The mean difference between groups was [x] units (95% CI [a] to [b]; P = [p]).
- Performance was consistent across subgroups, with AUCs ranging from [x] to [y] (Table [n]).
- 例:The model achieved an AUC of 0.91 (95% CI 0.88 to 0.94) on the external test set, compared with 0.84 (95% CI 0.80 to 0.88) for the logistic regression baseline.

## 英文模板与短语

**回顾与过渡(开场)**
- Previous studies have reported that
- As described in Section 2,
- In the present study, X was measured using
- The aim of this experiment was to
- Overall, / In general, / In most cases,
- 例:Overall, the model performed consistently across all three cohorts (Table 2).

**邀请看图表**(in = 图里直接可见;from = 可由图中数据推断)
- Fig. 1 shows(全篇图表引用只选一个动词,见 `08-verbs-tense-voice.md` 规则 4)
- As can be seen in / from Fig. 1,
- Results are given in Table 2
- X is apparent from Fig. 1 / X is clearly visible in Fig. 1
- (see Fig. 1) / (data not shown)
- Inspection of Fig. 1 indicates that

**客观结果动词**
- increased / decreased / rose / fell
- peaked at / reached a maximum of
- remained constant / was unchanged / remained stable
- exceeded / preceded / coincided with
- was present / was absent / was detected
- varied with / was identical to

**评价性评论与信号**
- Importantly, / Notably, / Interestingly, / Surprisingly,
- It is noteworthy that / It is important to note that
- striking / marked / pronounced / dramatic / remarkable
- subtle / minor / modest / negligible
- broadly / essentially / virtually / effectively
- 例:Notably, the improvement was most pronounced in the smallest subgroup.

**与本文预测 / 模型 / 假设比较**(与前人文献比较的短语见 `04-discussion-conclusion.md`)
- consistent with / in line with / in good agreement with
- comparable to / broadly similar to / essentially identical to
- as expected / as predicted / as hypothesized
- in contrast to / contrary to / differ from
- support / confirm / deviate from
- 例:The observed decline is in good agreement with the model prediction, but the effect was smaller than we had hypothesized.

**积极评价词**(有比较基准时可用,须能指到数据;裁决见 `05-abstract.md` 两书分歧第 6 条)
- accurate / precise / reliable / robust
- effective / efficient / feasible
- improved / superior / satisfactory
- useful / valuable / advantageous

**问题与议题**
- 淡化:negligible / minor / of no consequence / not significant / less than ideal
- 去责:unfortunately / inevitably / unavoidable / it was not possible to / limited by / not within the scope of this study
- 转向好的方面:nevertheless / despite this / reasonably robust / fairly well
- 给出方向:future work should / further work is required / is currently underway
- 例:Unfortunately, the sample size in this subgroup was too small to draw firm conclusions; nevertheless, the trend was consistent with the main cohort.

## 常见错误

| 错误模式 | 修正原则 |
|---|---|
| 以第一个原始数据点开头 | 前三句内给整体趋势概述、目标重述或方法回顾之一 |
| 按实验时间顺序罗列 | 按叙述逻辑:总体 → 关键 → 次要 → 问题 → 含义 |
| 只写 X is shown in Fig. 3,不评论 | 每次引用图表都附一句评价或解读 |
| 有多种解读的图先让读者看,再评论 | 评论放在引导看图之前或同一句内 |
| 所有结果同等详细 | 关键结果展开并标记(Importantly),其余略写 |
| 裸数字、裸比较级(X was higher) | 加评价修饰(slightly / markedly higher; only / as many as 23%) |
| 说"X occurred"不带频率 | 加频率档位之一或具体比例 |
| 主指标只给点估计 | 补 95% CI 或 P 值,格式与方法节一致 |
| 相关性数据用 cause / result in | 降到 be associated with / correlate with 一档 |
| result in 与 result from 方向写反 | 确认动词方向:X results in Y(X 因);X results from Y(Y 因) |
| 无任何限定的 proves / demonstrates conclusively | 在连续统上定一个档位;不用 prove |
| 含义句叠加 suggest + may + possibly | 只留一个避险成分,档位按证据定 |
| 结果节与前人文献逐条比较 | 与本文预测 / 模型比较;文献比较留给讨论(合写例外) |
| 满篇 may / might,结果其实很强 | 升级到 likely / probable;强弱与证据匹配 |
| 含义在结果节展开成整段机制讨论 | 结果节只一句 suggest / indicate,展开留给讨论 |
| 本文发现用现在时,读者以为是公认事实 | 默认过去时;现在时只用于有意提升为普遍事实 |
| However / Unfortunately 放句末 | 放句首,免得读者回读 |
| 用感叹号或口语化惊叹 | 用 striking / remarkable / unexpected |
| 问题和异常值只字不提 | 在结果节承认,并用淡化 / 去责 / 给方向措辞 |
| a cause / the cause 混用 | 唯一原因用 the,多因之一用 a |
| 结果的应用句与引言目标用词对不上 | 用引言的关键词造回声 |

## 自检清单

1. 开头三句内有整体趋势概述、目标重述或方法回顾之一。✓/✗
2. 结果按研究问题分块、块内按叙述逻辑组织,不是按实验时间顺序;每个结果段含目标句、结果句、总结句。✓/✗
3. 每张图/表被引用时都有一句评价或解读。✓/✗
4. 多解读的图表,评论在引导看图之前或同一句内。✓/✗
5. 关键结果都带评价性语言,没有裸数字或裸比较级。✓/✗
6. 每个数量评价词都能归入差异大 / 差异小 / 多 / 少 / 不表态之一,方向与数据一致且有对比基准。✓/✗
7. 每个"发生"陈述都带频率修饰或具体比例。✓/✗
8. 至少一处与本文预测、模型或假设显式比较;与前人文献的比较已留给讨论(合写例外)。✓/✗
9. 转折、评价、遗憾类信号词在句首。✓/✗
10. 没有感叹号。✓/✗
11. 图中可见用现在时,数据获得用过去时;本文发现默认过去时。✓/✗
12. 每个因果动词的强度与证据匹配;相关性数据没有用 cause。✓/✗
13. 每个含义句只有一个避险成分,档位与证据匹配;没有无限定的 prove。✓/✗
14. 结果中的问题、异常值已承认,并有淡化 / 去责 / 给方向之一。✓/✗
15. 直接从摘要跳来的读者仅凭结果节能理解做了什么、发现了什么。✓/✗
16. 应用/含义句回应了引言目标的用词。✓/✗
17. a cause / the cause 等冠词与"是否唯一"一致。✓/✗
18. 已回头核对引言目标,必要时改了引言。✓/✗
19. 小节数、小标题形式、图表顺序与目标期刊近期论文一致。✓/✗
20. 每个主指标带 CI 或 P 值,格式与方法节统计小节声明一致。✓/✗
