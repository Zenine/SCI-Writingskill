## 结构与规则

### 句长与段长统一口径

数字见 `09a-metrics-table.md`(全 skill 唯一数字源),本文件不重复。

### 风格规则

1. **run-on 结尾**:正文不得出现 etc. / and so on / and so forth / and the like;列举不完整时前置 including / such as 或结尾换 and other + 类别名,全列出用 namely;et al. 只用于作者列表。
2. **疑问句**:实证论文正文不得出现问号句,改 investigate / test / assess + how / whether 或 it remains unclear whether;计算机、社科领域引言末的研究问题列表按目标期刊惯例例外。
3. **副词位置**:方式副词紧贴被修饰动词(主动放动词前,被动放助动词与分词之间:was originally developed;then / subsequently 同样入句);评价与连接类句子副词(Interestingly / However)允许句首;句中 ≥ 2 个动词时检查副词归属;only / just / simply 逐个核对是否紧贴其限定成分。
4. **代词**:正文不得出现 you(改被动或以图表、研究作主语);we 只指作者团队,As we all know / we can see 一类泛指删除;单作者不想用 I 时用 This paper / This study + 动词;it / they 只允许作形式主语(仅 it)或所指唯一——这是本 skill 唯一口径,`07-paragraph-logic.md` 与 `10-chinese-author-pitfalls.md` E3 均指向本条;this / these 后必须跟名词。
5. **缩写**:正文不得出现动词缩写(don't / it's / can't),所有格 's 允许;展开后若出现 did not + 动词 + any / much / many,改动词 + no / little / few;缩略语首次出现给全称,摘要与标题尽量不用。
6. **习语与隐喻**:不用 a double-edged sword / the tip of the iceberg / in a nutshell 一类比喻、俚语、谚语、双关,换字面表达;领域惯用短语(gold standard、bottleneck、state of the art)经本领域数据库确认通用即可用。
7. **简洁**:删空转开头(There are ... that / 非强调的 It is ... that);删无信息强化语(very / really / indeed / quite / rather / of course / obviously / basically / actually / in fact);clearly 与 it is worth noting / it is noteworthy that 条件保留——作评价副词紧贴比较(clearly higher)或作句首重要性标记时可用,每段 ≤ 1 处且后接具体内容(数字、对比、机制),作口头禅或填充时删(`07-paragraph-logic.md` 与 `04-discussion-conclusion.md` 同此口径);删反义不成立的修饰词(plausible / robust / novel / sophisticated / carefully / dramatically),只保留改变操作含义的修饰;of + 抽象名词可改形容词时改形容词(materials of inorganic origin → inorganic materials),in the process of → while / during;一句一个事实。
8. **口语程度词**:a lot of / big / huge / get / really / a little bit / bigger and bigger 换学术等价词(considerable / substantial / obtain / slightly / is increasing)。
9. **评价词强度**:Results / Discussion 中报告发现的数字要带评价性修饰(only 23% / as many as 23%)而不是裸数字,方向与数据一致且不超证据;Methods 中的参数与样本量(n = 120 / batch size 32)豁免,回复信、投稿信、方法节不适用本条;unprecedented / striking / remarkable 一类"感叹号替代词"必须有数据支撑,superior / excellent 只在有比较基准时用;不用感叹号。 情绪副词(Unfortunately / Interestingly / Surprisingly)不进 Results;缺数据只陈述事实并进「建议补充」。
10. **标点**:破折号对改写为文字;括号内容要么并入正文要么删除(统计量括号如 (95% CI 0.80-0.88)、回复信中的位置括号 (Section 2.3, page 6) 不在此列);引文放在句中被引内容旁,不堆在句尾。
11. **术语一致**:同一概念全文一个词,不用同义词典换词求"变化";关键术语用 Google Scholar 带引号 / 不带引号各搜一次确认仍是通用说法。
12. **拼写变体**:英式 / 美式(analyse / analyze)按目标期刊统一,全文一致;期刊未知时默认美式(见 `SKILL.md` 硬规则 9)。

## 英文模板与短语

**口语程度词的学术替换**
- a lot of / lots of → considerable / numerous(能给数字就给数字;另见 `10-chinese-author-pitfalls.md` W3)
- big / huge → substantial / marked / large;a little bit → slightly / marginally
- get → obtain / yield / become;really / very → substantially / markedly(或删除)
- bigger and bigger → is increasing / has risen steadily
- 例:The sensors yielded a substantial volume of valid data, and the error decreased progressively.

**替代 run-on 结尾**
- ..., including A, B, and C / ..., such as A and B
- A, B, and other + 类别名 / ..., namely A, B, and C(全列出)
- 例:The model was tested on several lesion types, including lung nodules, liver lesions, and kidney cysts.

**间接疑问句引导语**
- We investigated / assessed / tested whether ... / We asked how / why ...
- It remains unclear whether ... / Little is known about how ...
- It is important to understand how ... / A central question is whether ...
- 例:We tested whether the pretrained encoder improves detection of sub-centimeter lesions.

**单作者或不用 we 时的主语**
- This paper discusses / argues / proposes ... / This study aims to ...
- This review concludes that ... / The present analysis shows ...

**评价数据的修饰(方向须与数据一致)**
- only 23% / as many as 23%;a marked / modest increase in
- comparable to / well below / well above / within the range of
- slightly / considerably lower than

**副词入句的固定位置**(规则 3)
- was originally developed / were then segmented / was subsequently fine-tuned
- automatically extracted / manually annotated
- 例:The images were then segmented, and the features were automatically extracted.

**句首标记重要信息**(替代句末副词;规则 7 口径)
- Interestingly, ... / Notably, ... / Of particular interest is ...
- It is noteworthy that ...(每段 ≤ 1 处,后接具体内容)

## 常见错误

| 错误模式 | 修正原则 |
|---|---|
| 方式副词孤悬句首(Then, ...)或句尾(... successfully.);only 位置随意 | 紧贴动词,被动放 be 与分词之间;only 逐个核对(句子副词 Interestingly, 不在此列) |
| we 泛指"大家";单作者用 I 或硬用 we | we 只指作者,泛指改 It is well established that;This paper / This study + 动词 |
| 缩略语首次出现无全称;摘要里用缩略语 | 首次给全称;摘要与标题避免缩略语 |
| carefully designed a robust and novel pipeline | 删修饰词,给数字(increased sensitivity from 0.71 to 0.86) |
| 一句串四五个 thus / leading to / suggesting that | 按"结果 → 结论"拆成 2–3 句 |
| Results / Discussion 中裸数字无评价;striking / unprecedented 无数据支撑 | 加 only / as many as / comparable to(Methods 参数豁免);降级或补数据 |
| 破折号对;括号里塞重要信息;引文全堆句尾 | 改文字;并入正文或删除;引文紧贴被引内容 |
| 单句 > 40 词;逗号 ≥ 4;整页一段或连续单句段 | 数字与处置见 `09a-metrics-table.md` |
| etc. 收尾、问号句、副词位置、you / we 泛指、动词缩写、习语、There are ... that、very / obviously、in the process of、拼写混用 | 逐句识别信号与例见 `10-chinese-author-pitfalls.md` E18 / E23 / E17 / E16 / W9 / W3 / W16 与本文件规则 2、6、7,本表不重复 |

## 自检清单

1. 全文无 etc. / and so on / and so forth / and the like。✓/✗
2. 实证正文无问号句(期刊明确允许的研究问题列表除外)。✓/✗
3. 每个副词紧贴被修饰动词;only / just / simply 位置已逐个核对。✓/✗
4. 正文无 you;we 只指作者;单作者用 This paper / This study。✓/✗
5. 无动词缩写;did not ... any 已改 no / little / few。✓/✗
6. 缩略语首次出现给全称;摘要与标题不含非必要缩略语。✓/✗
7. 无习语、隐喻、俚语;领域惯用短语已确认通用。✓/✗
8. 无 There are ... that / It is ... that 空转开头。✓/✗
9. 无 very / really / indeed / obviously / in fact 一类强化语与填充词;clearly / it is noteworthy that 每段 ≤ 1 处且后接具体内容。✓/✗
10. 无反义不成立的修饰词;保留的修饰词都改变操作含义。✓/✗
11. 平均句长 20–26 词(摘要 ≤ 25);无 > 40 词句子;> 30 词句子已检查。✓/✗
12. 逗号 ≥ 4 的句子已逐句检查;连接链 < 3;and、which 各 ≤ 1。✓/✗
13. 段落均值 150–170 词,80–230 词区间外的段落不占多数;无整页一段、无连续单句段。✓/✗
14. Results / Discussion 中报告发现的数字带评价性修饰,方向与数据一致,强度不超证据(Methods 参数豁免)。✓/✗
15. 强评价词都有数据支撑;无感叹号。✓/✗
16. 无破折号对;括号内容已并入或删除;引文紧贴被引内容。✓/✗
17. 同一概念全文一个术语;关键术语已确认为通用说法。✓/✗
18. 拼写变体全文一致。✓/✗
19. 风格改写作为独立一轮完成,未与内容写作混做。✓/✗
