# 学术风格与简洁

> 来源:书A 第1单元 1.5.4、第3单元、第8单元 8.2–8.4;书B 第7章、附录十

## 何时读本文件

- 总流程(`00-workflow.md`)进入第 7 步:逻辑与动词已通,做一轮独立的"语言与风格改写"。
- 审稿意见说 "informal""wordy""colloquial""sentences too long",或编辑要求 language editing。
- 用户问句子多长合适、段落多长合适、能不能用 you / we / I、能不能写问句、etc. 能不能用。
- 与 `10-chinese-author-pitfalls.md` 配合:本文件给风格原则与统一口径,10 号给逐句扫描清单。

前置约定:

- 学术风格只服务四个指标:清晰、精确、合逻辑、简洁。判断一个写法可不可以,先问它是否让读者少猜。
- 凡是要求读者"自己补全"的表达都要清除:run-on 结尾、缩写、含糊代词、习语隐喻、位置不明的副词。
- 风格改写在初稿完成后作为独立一轮;初稿阶段不因风格问题阻塞内容写作。
- 已发表论文不都是范本;不以"文献里见过"为由保留不规范表达。目标期刊近 5 年高被引同类文章 ≥ 4 篇作为范本。

## 结构与规则

### 句长与段长统一口径

两书数字不同,本 skill 统一如下;本表是全 skill 唯一数字源,01 / 05 / 12 等处只写"见 09"或逐字同步(取更严者作触发阈值,拆不拆由句意决定):

| 项目 | 口径 | 来源与说明 |
|---|---|---|
| 平均句长 | 20–26 词 | 书A 统计值(STEMM 论文均值约 23 词);书B 无词数、用"超过 4 行"或"逗号极多" |
| 单句上限 | > 30 词触发拆句检查;> 40 词必须拆分或说明理由 | 书A:约 90% 读者首读能懂 20 词内句子,只有约 10% 能懂 40 词以上 |
| 逗号 | 单句逗号 ≥ 4 触发拆句检查,拆不拆由句意定 | 书A"超过三个"与书B"≥ 5"取更严者 |
| 连接链 | 一句中 thus / resulting in / leading to / suggesting that 类连接 ≥ 3 必须拆 | 书B;按"结果 → 结论"切成 2–3 句 |
| 超载信号 | 一句中 and > 1、which > 1、名词与介词短语堆叠 | 书A;视为超载句,重写 |
| 段长 | 均值 150–170 词;80–230 词为正常区间;少于 80 或多于 230 的段落不得占多数 | 书A;书B 无数字 |
| 段落形态 | 禁止整页一段;禁止连续单句段落 | 两书一致 |
| 摘要特例 | 平均句长 ≤ 25 词;单句 ≤ 40 词 | 摘要读者最广、无上下文,取更严;细则见 `05-abstract.md` |

### 风格规则

1. **run-on 结尾**:正文不得出现 etc. / and so on / and so forth / and the like。列举不完整时列表前加 including / such as,或结尾换 and other + 类别名;全部列出时用 namely。et al. 只用于作者列表。
2. **疑问句**:实证论文正文不得出现问号句;改为 investigate / test / assess + how / whether,或 it remains unclear whether。计算机、社科领域在引言末列研究问题为例外,按目标期刊惯例。同一研究问题可用三种引导语分别放在引言(Several studies have investigated whether)、引言末或讨论(It is important to understand how)、讨论或结论(It remains unclear whether)。
3. **副词位置**:方式副词紧贴被修饰的动词——主动语态放动词前,被动语态放助动词与分词之间(was originally developed);then / subsequently 同样进入句中;评价与连接类句子副词(Interestingly / Notably / However)允许句首,不属此条;句中含 ≥ 2 个动词时必须检查副词归属。only / just / simply 位置不同意思完全不同,写完逐个核对是否紧贴其限定成分。
4. **代词**:正文不得出现 you;改被动或以图表、研究作主语(Fig. 2 shows)。we 只指作者团队,用于陈述作者动作或发现;As we all know / we can see 一类泛指删除。单作者不想用 I 时用 This paper / This study / This review + 动词。it / they 只允许作形式主语(仅 it)或所指唯一——这是本 skill 唯一口径,`07-paragraph-logic.md` 与 `10-chinese-author-pitfalls.md` E3 均指向本条;this / these 后必须跟名词。
5. **缩写**:正文不得出现动词缩写(don't / it's / can't / there's);所有格 's 允许。展开后若出现 did not + 动词 + any / much / many,改为动词 + no / little / few。缩略语(abbreviation)首次出现给全称,摘要与标题尽量不用缩略语。
6. **习语与隐喻**:不用 a double-edged sword / the tip of the iceberg / in a nutshell 一类比喻、俚语、谚语、双关;换字面表达。领域惯用短语(gold standard、bottleneck、state of the art)可用,前提是在本领域数据库中确认为通用;只有少数作者用的不用。
7. **简洁**:
   - 删空转开头:There are / is ... that;It is ... that(非强调时)。
   - 删无信息强化语:very / really / indeed / quite / rather / of course / obviously / basically / actually / in fact。clearly 与 it is worth noting / it is noteworthy that 是条件保留:作评价副词紧贴比较(clearly higher)或作句首重要性标记时可用,每段 ≤ 1 处且后面必须跟具体内容(数字、对比、机制);作口头禅(Clearly, ...)或句中填充时删。`07-paragraph-logic.md` 与 `04-discussion-conclusion.md` 同此口径。
   - 删无反义可能的修饰词:plausible / robust / novel / sophisticated / carefully / dramatically(问"反义词成立吗",没人会写 implausible model 就是废词);只保留确实改变操作含义的修饰(为避免损伤而"小心"转移、洗涤三次)。
   - of + 抽象名词可改形容词时改形容词(materials of inorganic origin → inorganic materials);in the process of → while / during。
   - 一句一个事实。
8. **口语程度词**:a lot of / lots of / big / huge / get / really / a little bit / bigger and bigger 换学术等价词(considerable / substantial / obtain / slightly / is increasing)。
9. **评价词强度**:Results / Discussion 中报告发现的数字要带评价性修饰(only 23% / as many as 23%)而不是裸数字,但方向与数据一致且不超过证据;Methods 中的参数与样本量(n = 120 / 1 mm voxels / batch size 32)豁免;unprecedented / striking / remarkable 一类"感叹号替代词"必须有数据支撑;superior / excellent 只在有比较基准时用。不用感叹号。
10. **标点**:破折号对改写为文字;括号内容要么并入正文要么删除;引文放在句中被引内容旁,不堆在句尾。
11. **术语一致**:同一概念全文一个词;不用同义词典换词求"变化";关键术语用 Google Scholar 带引号 / 不带引号各搜一次确认仍是通用说法。
12. **拼写变体**:英式 / 美式(analyse / analyze)按目标期刊统一,全文一致;期刊未知时默认美式(见 `SKILL.md` 硬规则 9)。

## 英文模板与短语

**口语程度词的学术替换**
- a lot of / lots of → considerable / numerous(能给数字就给数字,见 `10-chinese-author-pitfalls.md` W3)
- big / huge → substantial / marked / large
- a little bit → slightly / marginally
- get → obtain / yield / become
- really / very → substantially / markedly(或删除)
- bigger and bigger → is increasing / has risen steadily
- 例:The sensors yielded a substantial volume of valid data, and the error decreased progressively.

**替代 run-on 结尾**
- ..., including A, B, and C
- ..., such as A and B
- A, B, and other + 类别名
- ..., namely A, B, and C(全列出)
- 例:The model was tested on several lesion types, including lung nodules, liver lesions, and kidney cysts.

**间接疑问句引导语**
- We investigated / assessed / tested whether ...
- We asked how / why ...
- It remains unclear whether ...
- It is important to understand how ...
- A central question is whether ...
- Little is known about how ...
- 例:We tested whether the pretrained encoder improves detection of sub-centimeter lesions.

**单作者或不用 we 时的主语**
- This paper discusses / argues / proposes ...
- This study aims to ...
- This review concludes that ...
- The present analysis shows ...

**否定的学术化写法**
- yielded no ... / produced no ...
- has few / allocated little ...
- little research has been conducted on ...
- failed to detect ...
- 例:The classifier produced few false positives on the external set.

**评价数据的修饰(方向须与数据一致)**
- only 23% / as many as 23%
- a marked / modest increase in
- comparable to / well below / well above
- within the range of
- slightly / considerably lower than

**副词入句的固定位置**
- was originally developed / were then segmented / was subsequently fine-tuned
- automatically extracted / manually annotated
- 例:The images were then segmented, and the features were automatically extracted.

**句首标记重要信息(替代句末副词)**
- Interestingly, ... / Notably, ... / Remarkably, ...
- It is noteworthy that ...(每段 ≤ 1 处,后接具体内容;见规则 7)
- Of particular interest is ...

## 常见错误

| 错误模式 | 修正原则 |
|---|---|
| 列举后用 etc. / and so on 收尾 | including / such as 前置,或 and other + 类别名;全列出用 namely |
| 正文出现问号句 | investigate / test whether;it remains unclear whether |
| 方式副词孤悬句首(Then, ...)或句尾(... successfully.) | 紧贴动词;被动放 be 与分词之间;句子副词(Interestingly,)不在此列 |
| only 位置随意 | 紧贴其限定成分,逐个核对 |
| you 指读者 | 改被动或图表作主语 |
| we 泛指"大家" | we 只指作者;泛指删除或改 It is well established that |
| 单作者用 I 或硬用 we | This paper / This study + 动词 |
| don't / can't / it's | 展开;did not ... any → yielded no |
| 缩略语首次出现无全称;摘要里用缩略语 | 首次给全称;摘要与标题避免缩略语 |
| a double-edged sword / in a nutshell | 字面表达 |
| There are a number of X that ... | Several X ... |
| very / really / indeed / obviously | 删除 |
| carefully designed a robust and novel pipeline | 删修饰词,给数字(increased sensitivity from 0.71 to 0.86) |
| in the process of / of inorganic origin | during / inorganic |
| 一句串四五个 thus / leading to / suggesting that | 按"结果 → 结论"拆成 2–3 句 |
| 单句 > 40 词 | 拆句或说明理由 |
| 单句逗号 ≥ 4 | 触发检查,拆不拆由句意定 |
| 整页一段;连续单句段落 | 段长回到 80–230 词区间 |
| Results / Discussion 中裸数字无评价 | 加 only / as many as / comparable to;Methods 参数豁免 |
| striking / unprecedented 无数据支撑 | 降级或补数据 |
| 破折号对;括号里塞重要信息 | 改文字;并入正文或删除 |
| 引文全堆句尾 | 引文紧贴被引内容 |
| analyse / analyze 混用 | 按目标期刊统一;未知默认美式 |

## 自检清单

1. 全文无 etc. / and so on / and so forth / and the like。✓/✗
2. 实证正文无问号句(期刊明确允许的研究问题列表除外)。✓/✗
3. 每个副词紧贴被修饰动词;only / just / simply 位置已逐个核对。✓/✗
4. 正文无 you;we 只指作者;单作者用 This paper / This study。✓/✗
5. 无动词缩写;did not ... any 已改 no / little / few。✓/✗
6. 缩略语首次出现给全称;摘要与标题不含非必要缩略语。✓/✗
7. 无习语、隐喻、俚语;领域惯用短语已确认通用。✓/✗
8. 无 There are ... that / It is ... that 空转开头。✓/✗
9. 无 very / really / indeed / obviously / in fact 一类强化语与填充词;clearly / it is noteworthy that 每段 ≤ 1 处且后接具体内容。✓/✗
10. 无反义不成立的修饰词;保留的修饰词都改变操作含义。✓/✗
11. 平均句长 20–26 词(摘要 ≤ 25);无 > 40 词句子;> 30 词句子已检查。✓/✗
12. 逗号 ≥ 4 的句子已逐句检查;连接链 < 3;and、which 各 ≤ 1。✓/✗
13. 段落均值 150–170 词,80–230 词区间外的段落不占多数;无整页一段、无连续单句段。✓/✗
14. Results / Discussion 中报告发现的数字带评价性修饰,方向与数据一致,强度不超证据(Methods 参数豁免)。✓/✗
15. 强评价词都有数据支撑;无感叹号。✓/✗
16. 无破折号对;括号内容已并入或删除;引文紧贴被引内容。✓/✗

18. 拼写变体全文一致。✓/✗

## 两书分歧的处理

1. **句长与段长数字**(01 待对照点):书A 给句 20–26 词、段 150–170 词;书B 用"超过 4 行""逗号极多"等排版口径。裁决:采书A 的词数口径为唯一数字,书B 的排版信号转为触发阈值(逗号 ≥ 4、连接链 ≥ 3),见统一口径表;目标期刊统计若明显不同,以期刊为准。
2. **谨慎副词 carefully / thoroughly**(02 待对照点):书A 视为建立可信度的手段;书B 归为无信息修饰词。裁决:采"反义词是否成立"判据——只在确实反映操作差异(次数、方式、防护措施)时保留,否则删除。
3. **正面评价词与强词**(01、03、04 待对照点):书A 鼓励 striking / unprecedented / excellent;书B 与国内审稿文化主张克制。裁决:允许但加两个前提——方向与数据一致、强度不超证据;superior / excellent 须有比较基准。
4. **直接疑问句的例外**:书B 给计算机、社科引言末列研究问题的例外;书A 只说专业写作很少用问句引空白但其示例有研究问题列表。裁决:默认禁止问号句;"列研究问题清单"按目标期刊惯例可保留。
5. **同义替换**(01 待对照点):书A 反对为避免重复换词,书B 第 7、8 章同样反对同义词轮换。两书一致,采为硬规则。
6. **加粗 / 斜体突出核心概念**(ch-02):书B 建议用加粗吸引专家读者;多数期刊正文不允许。裁决:不进硬规则,改为"用明确的信号句(Interestingly / It is noteworthy that)突出"。
7. **which 的态度**:书B 主张能不用就不用;书A 允许但要求所指唯一。裁决:不禁止 which;可检查标准是"which 前只有一个候选名词,一句最多一个 which",表结果时改 thereby + -ing。
8. **gold standard 等领域隐喻**:书B 视为可接受但不鼓励;医学影像领域极常见。裁决:列为白名单,条件是本领域数据库确认为通用;同类处理 bottleneck、state of the art。
9. **语感类问题的等级**:书B 说 among / between 等"不是绝对语法错误"。裁决:此类条目在 `10-chinese-author-pitfalls.md` 中标 warning 级,不作 error 报告。
10. **"已发表论文不都是范本"与逆向工程**:书B 提醒低影响因子期刊上的写法不可靠;书A 主张从目标文章逆向工程。裁决:两者合并为范本筛选标准——目标期刊近 5 年高被引或编辑推荐文章 ≥ 4 篇,不以"文献里见过"为由保留不规范表达。
