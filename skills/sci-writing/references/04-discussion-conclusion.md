# Discussion 与 Conclusion(讨论与结论)写法

> 来源:书A 第4单元(讨论)、第5单元(结论)

## 何时读本文件

- 用户要写、改写或润色 Discussion、Conclusion,或 Results and Discussion 中"解释与外推"的部分。
- 用户的讨论只是复述结果,或结论只是摘要的复制。
- 审稿意见指出"讨论没有回应引言的问题""结论看不出哪些是本研究得出的""语言力度与证据不匹配(过度自信或过度保守)"。
- 需要核对情态动词(can / may / could / should / must)是否用对了确定性档位。

前置约定:先问用户目标期刊的结构选项——① Results / Discussion / Conclusion 分立;② Results / Discussion 无独立结论(讨论末 1–2 段承担结论功能);③ Results and Discussion 合并 + Conclusion;④ Results + 长 Conclusion(前半像讨论、末尾像结论)。形态不同,但功能组件相同。

## 结构与规则

### 讨论:由窄到宽

讨论与引言是镜像:引言由宽到窄(领域 → 文献 → 空白 → 本文),讨论由窄到宽(本文 → 对空白的回应 → 文献地图 → 外部世界)。动笔前先用一句话写出本研究的主要价值类型(方法更好 / 结果更准 / 改变领域方向 / 开辟应用),讨论第一段围绕它展开。组件顺序"上松下紧":靠上的多出现在开头,靠下的多出现在结尾,中间可自由流动。

| 步骤 | 功能 | 信息流 | 常用时态 |
|---|---|---|---|
| 1 宣布本节结构 | 可选,讨论中不常见 | — | 一般现在时 |
| 2 陈述成就 / 贡献 | 确认对文献的贡献;"首个 / 最大"须加 to our knowledge | 常作开头 | 一般现在时 |
| 3 回顾背景 / 文献"重启"读者 | 重新定位跳读过来的读者 | 开头附近 | 公认事实现在时;具体研究过去时或现在完成时 |
| 4 回顾空白 / 目标 / 方法 | 用与引言相同的措辞造"回声" | 开头附近 | 目标过去时;方法过去时 |
| 5 回顾关键结果并探讨含义 | 复述允许,但必须延伸:它在已有知识背景下意味着什么 | 中段 | 本文发现过去时;足够可靠可升为现在时 |
| 6 映射到文献 | 证实 / 扩展 / 矛盾 / 补充;引文最密集处,可首次引用新文献 | 中段 | 现在时或过去时视文献地位 |
| 7 局限与未来工作 | 局限多来自方法/结果已提过的问题;未来工作具体到可执行 | 中后段 | should be investigated / would be of interest |
| 8 重申成就 / 贡献 / 影响 | 收束,呼应第 2 步 | 结尾 | 一般现在时 |
| 9 潜在应用 | 为读者退出论文搭接口 | 结尾 | 现在时 + 情态动词 |

细则:

1. 第一句只能是两种之一:声明成就/贡献,或回顾背景/空白/关键结果以重启读者;不以"本节讨论……"开头(除非目标期刊惯例如此)。
2. 引言里的每个空白/目标在讨论里有一处明确回应,且用相同的关键动词和名词;不为文风换同义词。
3. 每条引文所在句通过句首或句中短语(consistent with / in contrast to / as reported by)说明该引文与本研究的关系。
4. 复述关键结果时,同一句或紧邻句必须给出含义或解释。
5. 区分"成就"(内向:引言提出的问题解决了没有)与"贡献"(外向:对知识或应用的影响),两者可分别陈述。
6. 局限与未来工作至少各一处;区分"我们正在做"(work is underway)与"建议他人做"(should be investigated)。
7. 结尾必须落在重申贡献或指出应用,不得以局限性收尾。
8. 语言力度与证据匹配:结果强而语言弱(满篇 may / might)要升级为 likely / probable / almost certain;结果弱而语言强要降级并加软化词(often / appear to / in most cases)。
9. 正面评价词分两级:普通肯定词(robust, reliable, efficient, novel)与"感叹号替代词"(unprecedented, striking, remarkable, compelling);后者必须有数据撑腰。

### 结论:关键信息 + 影响

结论不是重复或总结,而是传递一条聚焦"结果 + 影响"的关键信息。多数读者直接跳到结论,所以它必须独立可读,并让读者一眼分清哪些是本研究得出的。结论没有专属词汇,难点在选择与归属。通常 100–200 词、1–2 段,以目标期刊平均值为准。

| 序号 | 组件 | 常用时态 |
|---|---|---|
| 1 | 论文里有什么(呈现 / 描述了什么) | 一般现在时或现在完成时 |
| 2 | 研究取得了什么(用与引言目标相同的动词认领成就) | 现在完成时(We have developed)或现在时(This study demonstrates) |
| 3 | 相关背景(只在读者需要时,最少的词) | 一般现在时 |
| 4 | 空白 / 目标 / 需求(一句回顾,措辞呼应引言) | 过去时或现在时 |
| 5 | 方法(只提关键特征,不重复参数) | 过去时或现在完成时 |
| 6 | 关键结果 + 评价(clearly, significantly, as expected) | 过去时或现在时 |
| 7 | 结果的含义(suggest / indicate / it is apparent that) | 一般现在时 |
| 8 | 局限(通常一句,常与未来工作合并) | 现在时 |
| 9 | 应用 | 现在时 + 情态动词 |
| 10 | 如何推进知识(fill key gaps / pave the way for) | 一般现在时 |
| 11 | 未来方向(区分"正在进行"与"建议") | is in progress / should be explored |

信息流:做了什么 → 得到了什么 → 意味着什么 → 对领域和应用意味着什么 → 下一步。与摘要的区别:摘要要给足背景和方法让读者决定是否读全文;结论假定读者要的是"去向",背景与方法只做最少回顾。

细则:

10. 第一句认领本文成就或说明本文做了什么,用现在完成时或 this paper / this study 作主语。
11. 每个陈述发现的句子必须能被辨认为"本研究得出",至少满足一项:过去时或现在完成时;we 主语;this study / our results 主语;句首 here / in the present paper / from the results of the current study。
12. 禁止"非人称主语 + 一般现在时 + 无归属标记"的发现句(Analysis shows that ...),它读起来像背景知识。
13. It is argued / suggested that 可能被读成他人观点;是本文观点则改为 we argue 或加 here。
14. 不直接复制摘要句子;摘要不是结论的素材来源。期刊要求 Highlights / Synopsis 时分别写,不互相复制。
15. 至少包含:成就/贡献、关键结果 + 评价、含义或应用三类组件。
16. 结尾落在应用、知识推进或未来工作之一,不以局限性或否定陈述收尾。不引入新数据、新论证;可以引入前文没有明说的含义和应用。
17. 动词与引言目标、讨论成就中的动词一致(回声原则)。

### 情态动词分级表

按确定性由高到低:must(显然)> should(很可能)> may / might / could(可能);cannot(不可能)在最底端。每类都有等价的非情态替代结构,不确定时优先用替代结构以避免歧义。

| 功能 | 现在 | 现在否定 | 过去 | 过去否定 | 替代结构 |
|---|---|---|---|---|---|
| 1 能力 | can | cannot | could | could not | be able to / be capable of |
| 2 可能 | may / might / could | may not / might not(不能用 cannot / could not) | may have / might have / could have | may not have / might not have | it is possible that |
| 3 预期 | should | should not | should have | should not have | is expected to / is likely to |
| 4 显然 / 不可能 | must | cannot | must have | cannot have / could not have | it is obvious that / it is impossible that |
| 5 建议 | should | should not | should have | should not have | it is advisable to |
| 6 必要 | must / need to | do not need to / need not | needed to / had to | did not need to / need not have | it is necessary to |

陷阱:

- can 三义(有能力 / 有时 / 可能):有歧义就换 may、is able to 或 sometimes;can 最适合表达"选项"。
- must 表推断时暗示"无证据";真有证据直接用陈述句。must not = 不允许,"不必要"用 need not / do not need to。
- "可能不"只能用 may not / might not;cannot / could not 表示"不可能"。
- could 双义(过去能力 / 假设可能),不确定时用 was able to;could have 常表示"本可以但没有"。
- should 双义(预期 / 建议)靠上下文区分。
- did not need to(不必要且没做)vs need not have(不必要但做了)。

## 英文模板与短语

**映射到文献 / 比较**
- consistent with / in line with / in agreement with
- in contrast to / contrary to / unlike
- comparable to / analogous to
- to the best of our knowledge
- previously reported / recently described
- These results corroborate / extend / challenge
- This study complements / builds on
- Our data provide support for
- 例:Our findings extend those of [ref] by showing that the effect persists under X.

**推测与含义(降险)**
- It is conceivable that
- It is reasonable to assume that
- We postulate / hypothesise / speculate that
- A tentative explanation is that
- This points to
- We cannot rule out
- 例:A tentative explanation is that X reduces Y, although we cannot rule out an effect of Z.

**成就与贡献**
- This work provides a first step towards
- X provides a framework for / insight into
- X removes the need for
- We were able to demonstrate
- The approach presented here enables
- X outperforms / compares well with
- X offers a robust / cost-effective means of
- 例:To our knowledge, this is the first study to apply X to Y at this scale.

**认领成就(结论,现在完成时)**
- We have developed / designed / implemented
- In this paper, we have shown that
- X has been investigated / evaluated in this work
- This study has identified / established
- This paper has demonstrated the potential of
- It is shown here that

**含义与知识推进**
- These data suggest that
- Our results fill key gaps in
- X paves the way for
- X highlights the potential to
- X increases our understanding of

**局限与未来工作**
- Further work is needed to
- Future studies should investigate / validate / replicate
- It would be of interest to
- X should be explored further
- Work is currently underway to(仅指作者自己)
- A promising direction is
- 例:A limitation of this study is its single-centre design; multi-centre validation is currently underway.

**应用**
- X is applicable to / suitable for
- X could be implemented / generalised / extended to
- X holds promise for
- X may eventually lead to
- X could serve as
- Our findings will help to tailor the design of

## 常见错误

| 错误模式 | 修正原则 |
|---|---|
| 讨论开头"In this section we discuss ..." | 改为声明成就/贡献,或回顾背景/空白/关键结果 |
| 讨论只复述结果,不延伸 | 每次复述紧跟含义或解释 |
| 讨论换词回顾引言目标(引言 identify,讨论 detect) | 用相同的动词和名词造回声 |
| 引文只是堆在句尾,不说关系 | 句首或句中短语点明:consistent with / in contrast to / as reported by |
| 声称"首个 / 最大 / 唯一"无免责语 | 加 to our knowledge,投稿前重新检索 |
| 结果很强却满篇 may / might | 升级为 likely / probable / almost certain |
| 结果弱却用 demonstrates / proves | 降级并加 often / appear to / in most cases |
| 讨论以局限性收尾 | 结尾重申贡献或指出应用 |
| 未来工作空泛(more research is needed) | 具体到可执行的课题,并区分"我们正在做"与"建议他人做" |
| X can occur 读不出是"有能力 / 有时 / 可能" | 换 may / is able to / sometimes |
| 用 must be 表推断 | 有证据直接陈述;无证据用 it is likely that |
| 用 cannot / could not 表"可能不" | 只能用 may not / might not |
| 结论第一句是背景或摘要句 | 认领成就:We have developed / This study demonstrates |
| 结论出现 Analysis shows that ... 无归属 | 加 our / here / in this study,或改过去时、现在完成时、we 主语 |
| It is argued that 读成他人观点 | 改 we argue that 或 it is argued here that |

## 自检清单

讨论:

1. 已用一句话写出主要价值类型,讨论第一段围绕它展开。✓/✗
2. 第一句是声明成就/贡献或回顾重启,不是空泛的"本节讨论"。✓/✗
3. 引言的每个空白/目标在讨论中有明确回应,用相同的关键动词和名词。✓/✗
4. "首个 / 最大 / 唯一"都带 to our knowledge。✓/✗
5. 每条引文所在句都点明了与本研究的关系。✓/✗
6. 每次复述关键结果都紧跟含义或解释。✓/✗
7. 本文发现默认过去时;改现在时处能说明数据足以支撑为普遍事实。✓/✗
8. 每个 can 不存在两义以上;每个 must 不是无证据的推断;"可能不"没有用 cannot / could not。✓/✗
9. 语言力度与证据匹配:没有强结果配弱语言,也没有弱结果配强语言。✓/✗
10. 至少一处局限和一处未来工作,未来工作可执行且区分了"正在做"与"建议做"。✓/✗
11. 讨论结尾是重申贡献或指出应用,不是局限。✓/✗

结论:

12. 第一句认领成就或说明本文做了什么,用现在完成时或 this study 作主语。✓/✗
13. 每个发现句都有归属标记(时态 / we / this study / here)。✓/✗
14. 没有"非人称主语 + 现在时 + 无归属"的发现句。✓/✗
15. 没有直接复制摘要的句子。✓/✗
16. 含成就/贡献、关键结果 + 评价、含义或应用三类组件。✓/✗
17. 方法回顾只一句关键特征;没有新数据。✓/✗
18. 结尾落在应用、知识推进或未来工作之一。✓/✗
19. 动词与引言目标、讨论成就保持一致。✓/✗
20. 长度在目标期刊平均值附近(默认 100–200 词、1–2 段)。✓/✗

## 待与书B对照的点

- 讨论是否复述结果:书A认为复述关键结果是允许甚至必要的(但必须延伸);书B若强调"讨论不重复结果",需注明两说。
- 讨论开头直接声明贡献:书A称是增长中的趋势但仍要看目标期刊;本文件作为默认选项而非硬规则。
- 强评价词(unprecedented / striking):书A鼓励;中国作者写作教程多主张克制;本文件已加"必须有数据支撑"前提。
- 用一般现在时陈述发现:书A视为作者自主判断;书B若给出更机械的规则(结果一律过去时),按"更可检查"取书B,并注明书A的例外情形。
- 情态动词替代结构(it is possible that):书A视为更安全的趋势;书B若主张多用情态动词以求简洁,需权衡。
- 局限性的位置:书A允许局限在讨论首次出现(非正式证据、需进一步工作)也允许出现在结论;书B若要求局限集中在固定位置,按期刊结构选项分情况处理。
- 结论的范围:书A定义为"关键信息 + 影响",允许含背景与方法回顾;书B若限定为"回答引言问题",取更可检查的版本。
- 结论中 we 主语与主动语态:书A用于认领贡献;若书B主张结论多用被动,以"归属可辨认"为检查标准,被动句需补 here / in this study。
- 结论与摘要的含义强度差别:书A未说明结论是否允许比正文更强的表述(第 6 单元提到摘要有时更强),待书B补充。
- 现在完成时在结论中的高频使用:英美期刊惯例;书B若建议少用完成时,以书A为准并注明。
