# Discussion 与 Conclusion(讨论与结论)写法

> 来源:书A 第4单元(讨论)、第5单元(结论)

## 何时读本文件

- 用户要写、改写或润色 Discussion、Conclusion,或 Results and Discussion 中"解释与外推"的部分。
- 用户的讨论只是复述结果,或结论只是摘要的复制。
- 审稿意见指出"讨论没有回应引言的问题""结论看不出哪些是本研究得出的""语言力度与证据不匹配(过度自信或过度保守)"。
- 需要核对情态动词(can / may / could / should / must)是否用对了确定性档位(档位母表另见 `03-results.md`;情态动词六功能另见 `08-verbs-tense-voice.md`)。
- 本文件提到的其它 reference 只是出处指引;执行时以 SKILL.md 路由表的「先读 / 再读」为必读范围。

前置约定:先问用户目标期刊的结构选项——① Results / Discussion / Conclusion 分立;② Results / Discussion 无独立结论(讨论末 1–2 段承担结论功能);③ Results and Discussion 合并 + Conclusion;④ Results + 长 Conclusion(前半像讨论、末尾像结论)。形态不同,但功能组件相同。用户要求直接产出时默认选项 ①,并在「理解确认」标"请确认"(`SKILL.md` 硬规则 10)。

## 结构与规则

### 讨论:由窄到宽

讨论与引言是镜像:引言由宽到窄,讨论由窄到宽(本文 → 对空白的回应 → 文献地图 → 外部世界)。动笔前先用一句话写出本研究的主要价值类型(方法更好 / 结果更准 / 改变领域方向 / 开辟应用),讨论第一段围绕它展开。组件顺序"上松下紧":靠上的多在开头,靠下的多在结尾,中间自由流动。

| 步骤 | 功能 | 位置 | 常用时态 |
|---|---|---|---|
| 1 宣布本节结构 | 可选,讨论中不常见 | — | 现在时 |
| 2 陈述成就 / 贡献 | "首个 / 最大"须加 to our knowledge | 常作开头 | 现在时 |
| 3 回顾背景 / 文献 | 重新定位跳读过来的读者 | 开头附近 | 公认事实现在时;具体研究过去时 |
| 4 回顾空白 / 目标 / 方法 | 用与引言相同的措辞造"回声" | 开头附近 | 过去时 |
| 5 回顾关键结果并探讨含义 | 每模块开头概括发现最多两句,不重复数据与图号,必须延伸到"在已有知识背景下意味着什么" | 中段 | 发现过去时;足够可靠可升为现在时 |
| 6 映射到文献 | 证实 / 扩展 / 矛盾 / 补充;可首次引用新文献 | 中段 | 视文献地位 |
| 7 局限与未来工作 | 可首次出现的局限只有两类(见链式规则);未来工作具体到可执行 | 中后段 | should be investigated / would be of interest |
| 8 重申成就 / 贡献 / 影响 | 收束,呼应第 2 步 | 结尾 | 现在时 |
| 9 潜在应用 | 为读者退出论文搭接口 | 结尾 | 现在时 + 情态动词 |

细则:

1. 第一句只能是两种之一:声明成就/贡献,或回顾背景/空白/关键结果以重启读者;不以"本节讨论......"开头(除非目标期刊惯例如此)。
2. 引言里的每个空白/目标在讨论里有一处明确回应,且用相同的关键动词和名词;二级标题以结果标题为锚逐块镜像(另见 `00-workflow.md` 步 3 与 `06-title-keywords.md`)。
3. 每条引文所在句通过句首或句中短语(consistent with / in contrast to / as reported by)说明该引文与本研究的关系。
4. 每个讨论模块开头概括发现最多两句,不重复数据与图号,同一句或紧邻句必须给出含义或解释;正文持续出现 as shown in Fig. 即判为"讨论写成了结果"(另见 `08-verbs-tense-voice.md` 总表 Discussion 行、`12-submission-checklist.md` 第 24 条)。
5. 区分"成就"(内向:引言问题解决了没有)与"贡献"(外向:对知识或应用的影响),可分别陈述。
6. 局限与未来工作至少各一处;区分"我们正在做"(work is underway)与"建议他人做"(should be investigated)。
7. 结尾必须落在重申贡献或指出应用,不得以局限性收尾;局限的位置按下文链式规则。
8. 语言力度与证据匹配:结果强而语言弱(满篇 may / might)要升级为 likely / probable / almost certain;结果弱而语言强要降级并加软化词(often / appear to / in most cases);每个结论句只留一个避险成分,档位按确定性连续统三档(强 / 中 / 弱)只在一个杠杆上选一个点(另见 `03-results.md`);结论与摘要的强度不得高于结果节(`SKILL.md` 硬规则 6;另见 `05-abstract.md` 规则 7)。
9. 正面评价词分两级:普通肯定词(robust, reliable, novel)与"感叹号替代词"(unprecedented, striking, remarkable);后者必须有数据撑腰;每个评价词须能指到结果节的证据(另见 `05-abstract.md`)。

局限性位置链式规则(02 / 03 / 04 三处同文):方法、结果中已知的问题在各自节首次提及;只有"需进一步工作才能下结论"与"研究期间的非正式证据"两类可在讨论首次出现;讨论中后段集中一处(医学期刊常单列 Limitations 小节);结论最多一句并与未来工作合并;讨论与结论都不以局限收尾。

### 结论:关键信息 + 影响

结论不是重复或总结,而是传递一条聚焦"结果 + 影响"的关键信息。多数读者直接跳到结论,所以它必须独立可读,并让读者一眼分清哪些是本研究得出的。通常 100–200 词、1–2 段,以目标期刊平均值为准。信息流:做了什么 → 得到了什么 → 意味着什么 → 对领域和应用意味着什么 → 下一步;与摘要的区别是背景与方法只做最少回顾。

| 序号 | 组件 | 常用时态 |
|---|---|---|
| 1 | 论文里有什么(呈现 / 描述了什么) | 现在时或现在完成时 |
| 2 | 研究取得了什么(用与引言目标相同的动词认领成就) | 现在完成时(We have developed)或现在时(This study demonstrates) |
| 3 | 相关背景(只在读者需要时,最少的词) | 现在时 |
| 4 | 空白 / 目标 / 需求(一句回顾,措辞呼应引言) | 过去时或现在时 |
| 5 | 方法(只提关键特征,不重复参数) | 过去时或现在完成时 |
| 6 | 关键结果 + 评价(评价副词每段 ≤ 1 处且后接具体内容;另见 `09-academic-style.md` 规则 7) | 过去时或现在时 |
| 7 | 结果的含义(suggest / indicate / it is apparent that) | 现在时 |
| 8 | 局限(通常一句,常与未来工作合并) | 现在时 |
| 9 | 应用 | 现在时 + 情态动词 |
| 10 | 如何推进知识(fill key gaps / pave the way for) | 现在时 |
| 11 | 未来方向(区分"正在进行"与"建议") | is in progress / should be explored |

细则:

10. 第一句认领本文成就或说明本文做了什么,用现在完成时或 this paper / this study 作主语。
11. 每个陈述发现的句子必须能被辨认为"本研究得出",至少满足一项:过去时或现在完成时;we 主语;this study / our results 主语;句首 here / in the present paper。
12. 禁止"非人称主语 + 一般现在时 + 无归属标记"的发现句(Analysis shows that ...),它读起来像背景知识。
13. It is argued / suggested that 可能被读成他人观点;是本文观点则改为 we argue 或加 here。
14. 不直接复制摘要句子;期刊要求 Highlights / Synopsis 时分别写,不互相复制。
15. 至少包含:对引言问题的判断(take-home message,能否 / 多大程度解决)、成就/贡献、关键结果 + 评价、含义或应用四类组件(另见 `12-submission-checklist.md` 第 26 条)。
16. 结尾落在应用、知识推进或未来工作之一,不以局限性或否定陈述收尾。不引入新数据、新论证;可以引入前文没有明说的含义和应用。
17. 动词与引言目标、讨论成就中的动词一致(回声原则)。

### 情态动词

六功能分级、替代结构与陷阱展开见 `08-verbs-tense-voice.md` 情态动词一节;确定性档位见 `03-results.md` 连续统,本文件不另立表。可检查的三条:can 不得两义以上(有能力 / 有时 / 可能,有歧义换 may / is able to / sometimes,不用于描述本研究已观察到的事实);must 表推断暗示"无证据",有证据直接用陈述句;"可能不"只能用 may not / might not,cannot / could not 表示"不可能"。

## 英文模板与短语

**映射到文献 / 比较**
- consistent with / in line with / in agreement with
- in contrast to / contrary to / unlike
- to the best of our knowledge
- These results corroborate / extend / challenge
- This study complements / builds on
- 例:Our findings extend those of [ref] by showing that the effect persists under X.

**推测与含义(降险)**
- It is conceivable that / It is reasonable to assume that
- We postulate / hypothesize / speculate that
- A tentative explanation is that
- This points to
- We cannot rule out

**成就与贡献 / 认领成就(结论用现在完成时)**
- This work provides a first step towards / a framework for
- The approach presented here enables / removes the need for
- We have developed / designed / shown that
- This study has identified / established / demonstrated the potential of
- Our results fill key gaps in / pave the way for
- 例:To our knowledge, this is the first study to apply X to Y at this scale.

**局限与未来工作**
- Further work is needed to
- Future studies should investigate / validate / replicate
- It would be of interest to
- Work is currently underway to(仅指作者自己)
- A promising direction is

**应用**
- X is applicable to / suitable for
- X could be implemented / generalized / extended to
- X holds promise for
- X may eventually lead to

## 常见错误

| 错误模式 | 修正原则 |
|---|---|
| 讨论开头"In this section we discuss ..." | 改为声明成就/贡献,或回顾背景/空白/关键结果 |
| 讨论只复述结果,不延伸;正文持续出现 as shown in Fig. | 开头概括最多两句,不重复数据与图号,紧跟含义或解释 |
| 引文只是堆在句尾,不说关系 | 句首或句中短语点明:consistent with / in contrast to / as reported by |
| 结果很强却满篇 may / might;结果弱却用 demonstrates / proves | 升级为 likely / probable;或降级并加 often / appear to |
| 讨论以局限性收尾 | 结尾重申贡献或指出应用 |
| 局限第一次出现在讨论,却是方法/结果早该提的问题 | 回到方法或结果节首次提及;讨论只首次出现链式规则所列两类 |
| 结论没有回答引言的问题 | 补一句 take-home message:引言问题解决了没有、到什么程度 |
| 结论出现 Analysis shows that ... 无归属;It is argued that 读成他人观点 | 加 our / here / in this study,或改过去时、现在完成时、we 主语 |

## 自检清单

讨论:

1. 已用一句话写出主要价值类型,讨论第一段围绕它展开。✓/✗
2. 第一句是声明成就/贡献或回顾重启,不是空泛的"本节讨论"。✓/✗
3. 引言的每个空白/目标在讨论中有明确回应,用相同的关键动词和名词。✓/✗
4. "首个 / 最大 / 唯一"都带 to our knowledge。✓/✗
5. 每条引文所在句都点明了与本研究的关系。✓/✗
6. 每个讨论模块开头概括发现不超过两句,不重复数据与图号,且紧跟含义或解释;正文没有持续的 as shown in Fig.。✓/✗
7. 本文发现默认过去时;改现在时处能说明数据足以支撑为普遍事实。✓/✗
8. 每个 can 不存在两义以上;每个 must 不是无证据的推断;"可能不"没有用 cannot / could not。✓/✗
9. 语言力度与证据匹配:没有强结果配弱语言,也没有弱结果配强语言;每个结论句一个避险成分;结论与摘要不强于结果节。✓/✗
10. 至少一处局限和一处未来工作,局限集中在中后段一处且首次出现的只属两类例外;未来工作可执行且区分了"正在做"与"建议做"(只写讨论、看不到 Methods/Results 时“首次出现”一项标 N/A)。✓/✗
11. 讨论结尾是重申贡献或指出应用,不是局限。✓/✗

结论:

12. 第一句认领成就或说明本文做了什么,用现在完成时或 this study 作主语。✓/✗
13. 每个发现句都有归属标记(时态 / we / this study / here)。✓/✗
14. 没有"非人称主语 + 现在时 + 无归属"的发现句。✓/✗
15. 没有直接复制摘要的句子。✓/✗
16. 含对引言问题的判断(take-home message)、成就/贡献、关键结果 + 评价、含义或应用四类组件。✓/✗
17. 方法回顾只一句关键特征;局限最多一句并与未来工作合并;没有新数据。✓/✗
18. 结尾落在应用、知识推进或未来工作之一。✓/✗
19. 动词与引言目标、讨论成就保持一致。✓/✗
20. 长度在目标期刊平均值附近(默认 100–200 词、1–2 段)。✓/✗
