# 句长段长与词数口径表(全 skill 唯一数字源)
## 何时读本文件
- 任何节的自检清单出现句长 / 段长 / 词数条目时。
- 用户问“句子多长合适”“段落多长合适”。
- 需要统计词数或判断某句是否超载。
- 本文件提到的其它 reference 只是交叉引用;执行时以 SKILL.md 路由表的「先读 / 再读」为必读范围。

## 口径表

本表统一全 skill 的数字口径;01 / 05 / 12 等处只写"数字见 09a"或逐字同步。触发阈值从严执行,是否拆句仍由句意决定:

| 项目 | 口径 | 使用说明 |
|---|---|---|
| 平均句长 | 20–26 词 | STEMM 成稿通常约 23 词;无词数时用"超过 4 行"或"逗号极多"识别超载 |
| 单句上限 | > 30 词触发拆句检查;> 40 词必须拆分或说明理由 | 词数越高，首读理解负担越大 |
| 逗号 | 单句逗号 ≥ 4 触发拆句检查,拆不拆由句意定 | 作为复杂度触发阈值 |
| 连接链 | 一句中 thus / resulting in / leading to / suggesting that 类连接 ≥ 3 必须拆 | 按"结果 → 结论"切成 2–3 句 |
| 超载信号 | 一句中 and > 1(摘要与方法节中三项以上的列举式 and,以及两项固定搭配或两项对比对象 training and test sets / sensitivity and specificity / logistic regression and random forest 不计)、which > 1、名词与介词短语堆叠 | 视为超载句,重写 |
| 叠加判据 | 一句同时触发 > 30 词与列举式 and 豁免时:列举项 ≥ 3 且句中只有一个主谓结构则保留并在自检写"列举句";否则拆句 | 列举例外优先于机械拆句 |
| 段长 | 均值 150–170 词;80–230 词为正常区间;少于 80 或多于 230 的段落不得占多数 | 均值适用于成稿;从短草稿改写或信息量有限时不作硬指标,只看区间;投稿信与回复信按条目分段,不套段长均值 |
| 段落形态 | 禁止整页一段;禁止连续单句段落 | 统一规则 |
| 结论特例 | 独立结论节 100–200 词,按目标期刊均值校准 | 另见 `04-discussion-conclusion.md` |
| 摘要特例 | 平均句长 ≤ 25 词;单句 ≤ 40 词 | 摘要读者最广、无上下文,取更严;另见 `05-abstract.md` |
| 词数计数口径 | 按空白分隔的 token 计一词:`0.80-0.88`、`(0.76)`、`7:3`、`90-day` 各计 1 词;标题与小标题不计入正文词数;统计表达式 `P < 0.001`、`n = 120`、`95% CI 0.80-0.88` 各整体计 1 词,书写统一带空格 | 全 skill 统一,避免不同 agent 计数不一 |

## 使用规则
- 01、05、12 等文件的句长段长条目一律以本表为准,不另立数字。
- 从短草稿改写或信息量有限时,段落均值不作硬指标,只看 80–230 区间;投稿信与回复信按条目分段,不套段长均值。
- 风格规则、模板与常见错误另见 `09-academic-style.md`。
