# Title、Keywords 与二级标题写法

> 来源:书A 第7单元;书B 第4章(关键词、4.4 二级标题)

## 何时读本文件

- 用户要给论文定正式标题,或要把工作标题(working title,研究开始前的暂定题)改成投稿标题。
- 用户要列关键词,或不确定标题与关键词该如何分工。
- 用户要写或改各节的二级标题(subheading),或审稿意见指出"结构不清""小标题看不出内容"。
- 用户要判断某个标题是否夸大、是否有语法歧义、是否对目标读者可读。
- 本文件提到的其它 reference 只是出处指引;执行时以 SKILL.md 路由表的「先读 / 再读」为必读范围。

前置约定:

- 标题最后定(结果分析完成、核心贡献确定、摘要写完之后);工作标题不得直接当正式标题;标题表达"研究产出"(工具 / 分析 / 机制 / 结论),不是"研究活动"。
- 标题没有万能公式,可操作的做法是逆向工程目标期刊近期同类标题;标题、关键词、摘要、正文结论用同一套核心术语(另见 `05-abstract.md`),分工见关键词规则 2。
- 本文件英文模板按美式拼写与 ASCII 半角字符(见 `SKILL.md` 硬规则 9);投英式期刊时整体替换。

## 结构与规则

### 标题逆向工程六步

输入:目标期刊近 1–2 年 20–30 条同类研究标题,由用户提供或 agent 联网抓取。输出:本刊标题画像 + 自己的标题草案。

样本不足或无联网时的兜底:拿不到 20 条时降为 ≥ 8 条,并在「理解确认」注明样本量不足;一条都没有时按本文件默认值(约 12 词、无缩写、名词短语、不用冒号)起草,画像各项标"默认值,请确认",检索类动作(规则 9–10)进「建议补充」请作者执行。

| 步 | 做什么 | 检查项 |
|---|---|---|
| 1 量长度 | 数样本标题词数,记均值与范围 | 偏离均值超过 50% 要能说明理由;书A 经验值约 12 词,以样本均值为准 |
| 2 查缩写 | 统计缩写频率;列出可能的读者类型(临床、政策、产业、相邻学科) | 每个缩写每类读者不查资料就能懂,否则展开 |
| 3 分工 | 看样本关键词比标题更宽(扩读者面)还是更专(引专家) | 决定关键词走哪一路;塞不进标题的名词卸到关键词 |
| 4 查语法 | 统计介词数量与种类、名词链长度 | 名词修饰链 ≤ 3;介词少且意义唯一;能用 that / using / based on 替代的替代 |
| 5 建画像 | 统计以 A/An 开头、含冒号、含方法、含目的、含评价词、含缩写、面向微型群体的比例 | 得到"本刊标题通常长什么样",据此选结构 |
| 6 兑现 | 只看自己的标题写下预期内容,再对照结论 | 有偏差处改标题 |

期刊标题画像记录表(步 5 的固定产出,每项记数值或比例,并注样本量 n):期刊与年份范围 / 样本量 n / 词数均值与范围 / 含缩写比例 / 以 A/An 开头比例 / 含冒号比例 / 含方法词比例 / 含目的或应用词比例 / 含评价词比例 / 句子式标题比例 / 关键词偏宽还是偏专 / 数据来源(用户提供 / 联网抓取 / 默认值)。

### 标题规则

1. 标题至少包含"贡献"或"应用 / 目的"之一;只命名领域或对象的不算标题。
2. 以 A / An 开头意味着提出了新的方法 / 框架 / 装置 / 模型,论文必须确实提出了它。
3. 冒号只承担"领域 : 本文贡献"或"新术语 : 说明"之一。
4. 评价词(novel、robust、cost-effective、rapid、accurate)每个都要在结果或讨论中找到证据;无对比数据的 novel / new 删除。
5. 不夸大:结论尚不确定时用 may / might / could;标题承诺的每一项正文都要兑现。
6. 名词短语是默认形式;优先含动词或动作名词(X reduces Y / Reduction of Y by X),只命名对象的名词堆叠最弱;完整句子式标题只在目标期刊有先例且结论强而明确时用,否则用情态动词句或退回名词短语。
7. 名词短语的中心名词在最右,左侧名词都在当形容词用,链越长关系越说不清。
8. 介词 for / with / in / of 语义弹性大;with 尤其易歧义,优先换 using / based on / combined with。
9. 关键术语必须是当前通用说法:Google Scholar 带引号与不带引号各搜一次确认未被新命名取代;无联网时进「建议补充」请作者执行。
10. 投稿前把标题与关键词丢进搜索引擎,检查检出论文的读者群是否与目标读者一致;无联网时同上进「建议补充」。
11. 大小写、斜体(物种学名)、化学式格式按目标期刊。

### 关键词规则

1. 数量按期刊要求,常见 3–6 个词或短语。
2. 核心术语可与标题重合,但关键词表中至少一半是标题里没有的词,走两种目的之一:扩大读者面(上位词)或补充技术术语(吸引专家)。
3. 标题名词过多时,把次要名词移入关键词。
4. 医学期刊按受控词表(MeSH 等)选词;其它领域按本领域检索习惯。
5. 关键词与标题、摘要合起来覆盖:研究对象、方法、场景 / 应用、核心结论中的关键概念。

### 二级标题规则

1. 二级标题是导航(读者)、结构判据(审稿人)、路线图(作者)、共识载体(合作者);写正文前先产出到二级标题的提纲并与合作者确认,达不成共识说明研究构思本身有分歧。
2. 方法节:标题必须含动作或方法名(Detection of X / Measurement of Y),不能只是对象、模块或材料名;能对应研究问题时标 RQ1、RQ2。
3. 结果节:优先用动词说出发现的关系(X causes Y / X does not affect Y),形式按目标期刊(另见 `03-results.md` 规则 16);期刊只允许短语式小标题时用含关系的名词短语(Effects of X on Y / Association between X and Y),两种形式下都不得只给主题名词。
4. 引言与讨论节标题无从下手时,先定方法与结果的二级标题再反推:引言按"总览 → 具体对象与机制 → 现有方案 → 本文目标"排;讨论每个标题对应一个结果标题。
5. 引言、结果、讨论三组二级标题应能一一对应;检查方法:只读标题能否画出全文"鱼骨"。
6. 小节开头前两句要出现标题中的关键词;标题必须准确代表小节内容。
7. 小节之间分量均衡;某小节只有一段时考虑合并。
8. 是否允许二级标题、允许几级、是否编号,按目标期刊近期论文。

## 英文模板与短语

**提出新东西的开头与冒号后半句**
- A framework for ... / A method for rapid ... / An algorithm for accurate ...
- A low-cost tool for ...
- : a framework for ... / : evidence from ... / : a multicenter study
- : implications for ... / : design and validation
- 例:A lightweight model for vessel segmentation in hand-held retinal images;Foundation models in radiology: a scoping review of clinical validation

**方法、手段与目的**(替代 with)
- ... using X / ... based on X / ... via X
- ... combined with X / ... derived from X
- ... for the detection of X / ... for evaluating X
- ... in low-resource settings / ... under clinical conditions / ... to guide X
- 例:Predicting readmission using routinely collected laboratory data;Automated triage of chest radiographs to guide referral in rural clinics

**评价词**(须有证据)
- cost-effective / rapid and reliable / robust / efficient / accurate / improved / scalable
- 例:A rapid and reliable assay for X, validated against Y(rapid 的证据在结果节的耗时比较,reliable 的证据在结果节的重复性数据)

**表达关系或发现**(短语式或句子式)
- effects of X on Y / association between X and Y / role of X in Y
- X reflects / controls / regulates Y
- X contributes to Y / X may regulate Y
- 例:Sleep fragmentation predicts next-day glucose variability in adults with type 2 diabetes

**二级标题**(方法节含动作;结果节优先含动词,短语式期刊用含关系的名词短语)
- 方法节:Study design and participants / Data collection / Detection of X / Statistical analysis / Model training and evaluation
- 结果节(动词):X causes / induces Y;X is associated with Y;X outperforms Y on Z;X improves Y without Z
- 结果节(短语):Effects of X on Y / Association between X and Y
- 引言与讨论节:Current approaches to X / Aim of the present study / Comparison with previous methods / Limitations and future work
- 例:2.3 Assessment of retinal image quality;3.2 Image quality, not model size, limits segmentation accuracy;5.1 Comparison of the proposed model with existing methods

## 常见错误

| 错误模式 | 修正原则 |
|---|---|
| 工作标题直接当正式标题(Study of X in Y) | 改为表达产出:X 的什么工具 / 机制 / 结论 |
| 四个以上名词连用(X Y Z W analysis) | 拆成介词短语或分词结构,或把次要名词卸到关键词 |
| 介词堆叠或 with 歧义 | 少用介词;with 换 using / based on / combined with |
| A / An 开头但论文没有提出新东西 | 去掉冠词或改成关系式标题 |
| 冒号前后功能不明 | 只保留"领域 : 贡献"或"新术语 : 说明" |
| 标题承诺强于结论 | 用 may / could 或改为陈述范围更窄的产出 |
| 方法节标题只列对象(Retinal image quality) | 加动作(Assessment of retinal image quality) |
| 结果节标题只列主题(Segmentation accuracy across cameras) | 用动词说出关系(Hand-held cameras reduce segmentation accuracy);短语式期刊用 Effect of camera type on segmentation accuracy |
| 标题、摘要、关键词术语不一致 | 三处统一为同一套术语 |

## 自检清单

1. 标题在结果分析完成、贡献确定后才定稿。✓/✗
2. 已收集目标期刊 20–30 条同类标题(不足时 ≥ 8 条并注明)并填好画像记录表。✓/✗
3. 标题词数在目标期刊均值的 ±50% 内,或偏离有理由。✓/✗
4. 标题表达研究产出(工具 / 分析 / 机制 / 结论),含贡献或应用至少一项。✓/✗
5. 只看标题写下的预期与论文结论一致。✓/✗
6. 每个缩写对所有目标读者类型都可读。✓/✗
7. 连续名词修饰链不超过 3 个。✓/✗
8. 介词少且每个意义唯一;没有歧义的 with。✓/✗
9. 若以 A/An 开头,论文确实提出了新的方法 / 框架 / 装置 / 模型。✓/✗
10. 若含冒号,功能是"领域 : 贡献"或"新术语 : 说明"之一。✓/✗
11. 每个评价词能在结果或讨论中找到证据。✓/✗
12. 标题承诺强度不超过结论;不确定处用情态动词。✓/✗
13. 标题为名词短语或含动词;句子式只在期刊有先例且结论明确时使用。✓/✗
14. 关键词至少一半是标题里没有的词,数量符合期刊要求,走"扩大读者面"或"补技术术语"之一。✓/✗
15. 标题与关键词在搜索引擎中检出的论文读者群与目标读者一致。✓/✗
16. 方法节二级标题含动作或方法名。✓/✗
17. 结果节二级标题说出发现的关系(优先动词句;短语式期刊用含关系的名词短语),没有只列主题名词的。✓/✗
18. 引言、结果、讨论的二级标题能一一对应,只读标题能画出全文骨架。✓/✗
19. 每个小节开头前两句出现标题关键词。✓/✗
20. 标题、关键词、摘要、结论使用同一套核心术语。✓/✗
